# 如何使用本指南

## 1. 目的及范围

如果您只需要快速入口，请使用 [[由此开始]]。

当您需要了解 **Win.Win 人工智能盲点指南** 的各文件如何配合使用时，请使用本页。它说明如何：
- 识别人工智能盲点风险；
- 找出相关控制；
- 使用可用的方法；
- 让问责路径参与；
- 在相关时进入未明说的语境控制详细次序；以及
- 识别普通审核何时不足够。

本页是本指南的操作导航图。它不会：
- 重新界定 [[指南范围及定位]] 中的范围边界；
- 替换 [[术语表]] 中的规范术语；或
- 重复每份工作文件中的详细指示。

当您正在学习本指南的架构、培训审核者、为机构调整本指南，或决定下一步应打开哪份文件时，请阅读本页。

---

## 2. 操作原则

从真实任务及盲点疑虑开始，然后只使用本指南中负责任地处理该疑虑所需的部分。

核心架构关系是：

```text
人工智能盲点风险 → 相关控制 → 适用指引及方法 → 在需要时使用问责路径
```

使用 [[由此开始]] 取得实际首次使用次序。使用 [[人工智能盲点控制图]] 查阅规范控制、方法、问责路径及其多对多关系。

不要在识别风险和选择控制之间自动加入未明说的语境控制。只有当风险及任务显示相关语境可能在任务依据中缺失、不完整或未获充分表述时，才使用它。

人工智能输出仍然是草稿、辅助工具或审核辅助。对于实际使用、发送、批准、发布、依赖或采取行动的内容，负责人及机构仍须承担责任。

## 3. 各文件如何配合使用

在撰写、编辑、自定义、本地化、验证或维护本指南时，请使用 [[作者及编辑指南]]。

| 文件或文件组别 | 在本指南中的角色 | 何时打开 |
|---|---|---|
| [[由此开始]] | 快速首次使用入口 | 您初次使用本指南，或需要进入任务的最短路线 |
| [[人工智能盲点风险库]] | 规范风险登记表及参考 | 您需要某项具名人工智能盲点风险的权威定义、它如何出现，以及负责人必须解决什么 |
| [[人工智能盲点控制图]] | 规范登记表及关联图 | 您需要规范控制、方法和问责路径，或它们之间已记录的关系 |
| [[未明说的语境控制]] | 查找及处理缺失语境 | 相关语境可能在任务依据中缺失、不完整或未获充分表述；其最详尽的指引涉及识别及安全引导提取该语境 |
| [[引导提取技巧]] | 详细安全引导提取指引 | 合适的人可能隐含地掌握相关语境，而且具体、聚焦的问题安全并获允许 |
| [[来源资料包附加项]] | 来源准备支持 | 任务依据可能不完整，或应检索目前已批准来源并提取与任务相关的已批准材料 |
| [[机构情境处理]] | 目前任务情境处理导航 | 您需要简短了解可能缺失什么情境、它可能在哪里、其可表述程度，以及详细处理应继续到哪里 |
| [[当提问仍不足时]] | 适任性及路径指引 | 更好的问题仍不足够，因为事项敏感、受限制、涉及政治、超出适任性，或需要另一流程 |
| [[人工智能盲点审核卡]] | 简短目前任务审核辅助 | 在使用人工智能辅助输出前，您需要精简的风险到控制审核次序 |
| [[模板/审核者适任性核对]] | 支持审核者适任性核对方法的审核者适任性模板 | 您需要判断审核者是否有足够适任性进行审核、批准、引导提取或升级处理 |
| [[模板/人工智能盲点引导提取工作表]] | 工作表 | 未明说的语境控制相关，而且您需要记录有界限的未明说语境核对 |
| [[机构记忆习惯]] 及 [[模板/例外说明模板]] | 选用的安全保留支持 | 安全、可靠、可重用的经验在目前任务后不应丢失 |
| [[指南范围及定位]] | 范围及定位参考 | 您需要了解本指南涵盖什么、目前详细发展什么，以及其边界所在 |
| [[术语表]] | 规范术语参考 | 您需要 本指南的核心模型术语、角色、适任性术语、决策标签或架构概念的受控意思 |

本页提供操作导航图。详细指示属于各个文件。

## 4. 定义及规范登记表

每个受控术语或规范项目都只在一个地方有一个权威定义。

[[术语表]] 定义核心模型术语、角色及适任性、决策标签，以及 **控制**、**方法** 和 **问责路径** 等架构概念。它不会另行定义规范人工智能盲点风险，或个别规范控制、方法或问责路径。

[[人工智能盲点风险库]] 定义规范人工智能盲点风险，并提供各项风险专用的识别及处理指引。

[[人工智能盲点控制图]] 定义个别规范控制、方法及问责路径，并记录它们的多对多关系，包括风险映射。

本页说明这些权威位于哪里；它不会重复其定义或关联登记表。
