# 未明说的语境控制

## 1. 目的及范围

当相关语境可能 **在任务依据中缺失、不完整或未被充分表述** 时，请使用本页。

**未明说的语境控制** 是 Win.Win 人工智能盲点指南目前提供详细指引的控制。其最完整的实用指引集中于识别及安全地引导提取未明说的语境。相关的当前任务指引亦涵盖来源位置、检索及提取、可表述性、安全转换、仅由人处理、核实、问责审核、停止及升级处理。

本页说明如何：
- 识别未明说的语境；
- 识别可能的来源；
- 评估可表述性；
- 在适合时使用安全引导提取方法；及
- 选择当前任务所需的最低程度处理，例如已批准的检索、安全转换、仅由人处理、核实、问责审核、停止或升级处理。

未明说的语境控制可支持多项人工智能盲点风险，但不能解决所有风险。使用 [[人工智能盲点控制图]] 识别其他相关控制、方法或问责路径。

本控制并不提供完整的机构情境、知识管理、记录管理或检索增强生成（RAG）框架。

---

## 2. 未明说的语境是什么

**未明说的语境** 是任何在任务依据中缺失、不完整或未被充分表述的相关语境。

**任务依据** 包括任务可用的来源资料包、提示词、实际使用的已批准材料、审核依据及目前决策记录。

人工智能可以运用提供给它的信息，但它并不身处机构之中。它不知道人们默默记住什么。它感受不到消息的时机。它不具有权限。如果输出被错误使用，它也不承担后果。

一份草稿可以看起来清晰、平衡而完整，但仍然遗漏人工审核者在安全使用前需要知道的事项。

这包括人们知道、记得、感觉到或通常会做，但没有放入来源材料、提示词或审核依据的内容。

---

## 3. 识别角度

### 3.1 语境如何在任务依据中变成缺失、不完整或单薄

- **未成文** — 没有记录在任何地方；
- **未在提示中提供** — 已在某处记录或有人知道，但没有提供给任务依据、没有为任务检索，或未在任务依据中充分表述；
- **部分记录** — 部分相关内容已有记录，但重要限制、理由、例外或后果缺失；
- **分散** — 分散于不同人、记录、先前决定或相关任务中，而不是集中在一个完整来源；
- **当前** — 在目前情况中已知或明显，但尚未反映于任务依据。

---

### 3.2 人们可能如何掌握或表达它

- **默会** — 通过经验知道，但难以按要求列出或解释；
- **累积或经验性** — 通过重复任务、相关工作、先前决定、变通方法、错误、险些出错及真实经验累积而成；
- **难以表达** — 人们能识别或据此行动，但不容易表述成清楚的事实、规则或指令；
- **关系性** — 与信任、历史、角色、受众反应或声誉相关；
- **运营性** — 与任务、场地、供应商、流程或团队实际如何运作相关；
- **跨文化／语域相关** — 与语气、正式程度、语言、文化或社交意思相关。

---

### 3.3 为何可能需要受控处理

- **敏感** — 不适合广泛披露，或放入一般文件或人工智能互动；
- **以权限为基础** — 与谁可以批准、决定、承诺、拒绝、作出承担或发送相关；
- **重要** — 与会改变决定、优先次序、阈值、批准或后果的事项相关；
- **不安全或不适合** — 如没有获准且有问责的路径，不适合放入人工智能或一般记录；
- **无法完整表述以供人工智能使用** — 无法完整表述给人工智能使用，而不丢失重要判断、细微差别或责任。

同一语境可以同时符合多个角度。来源位置是独立核对项。可表述性是另一项独立核对。规范风险名称 **未成文语境差距** 并不限于字面上没有写下的信息。

## 4. 为何有经验的人与人工智能不同

人也可能收到不完整的指示。有经验的人并不会自动完整或正确。

本控制针对的独特问题是：有经验的人通常掌握超出明确任务信息的内容，而人工智能一般只取得任务依据及实际提供给它的其他信息。

```text
有经验的人
= 明确任务信息
+ 累积经验
+ 默会判断
+ 机构记忆
+ 本地及关系层面的认知

人工智能
= 任务依据及实际提供给它的其他信息
```

缺失语境可能来自重复任务、相关任务、先前决定、变通方法、关系、习惯、真实经验、本地做法、偏好、风险承受取向、对时机的敏感度、非正式阈值，或机构实际会批准什么。

---

## 5. 识别可能的来源

核对可能的来源位置：

- 人；
- 已批准记录；
- 两者；
- 不清楚。

如有目前有效的已批准记录，先检索来源并提取与任务相关的已批准材料，再要求人重新凭记忆重述。

如果语境仍然是隐含、部分、难以表达、不安全说明或不清楚，应使用合适路径，而不是强行把它放进人工智能。

---

## 6. 评估可表述性

使用最接近的一项评估可表述性：

- 可清楚表达；
- 可部分表达；
- 难以表达；
- 说明会不安全或不适合；
- 无法完整表述以供人工智能使用。

可表述性有助选择路径。它本身不能决定该语境是否重要、可靠、获授权、可否使用或应否保留。

---

## 7. 为何直接提问往往无效

一个宽泛问题，例如：

```text
还有其他我应该知道的事情吗？
```

可能会诚实地得到：

```text
没有。
```

人们不一定把经验储存成整齐清单。具体而明确的问题可以给记忆一个依附点。

例如，不要问：

```text
有任何例外吗？
```

改问：

```text
我们最近一次对这项规则作出变通、绕过、调整或低调例外是在什么时候？是为谁或为什么？
```

第二个问题给记忆一个具体事件作依附点。

只有在合适的人可能隐含掌握语境，而且问题属安全及获准时，才使用 [[引导提取技巧]] 进行 **安全引导提取方法**。

## 8. 当前任务的最低程度处理

选择一条路径：

- 只有在内容准确、必要、获准、现行且安全时，才把已批准的最少内容加入任务依据；
- 使用安全转换：只向人工智能提供必要而安全的效果。这可以是一项事实或来源、一项限制或措辞规则、一项遗漏或审核指示、一项批准边界或人工撰写要求，或一项升级处理触发条件；
- 把底层语境保留为仅由人处理，并由获授权人士引导撰写、审核、批准、时机或升级处理；
- 以具有足够独立性的已批准来源、工具、记录或适当承担责任的审核者核实；
- 转交承担责任或专门领域的审核者；
- 停止并升级处理；
- 不使用或不记录。

| 语境情况 | 最低程度路径 |
|---|---|
| 准确、必要、获准、现行，而且可安全地用于人工智能辅助工作 | 只把已批准的最少内容加入任务依据。 |
| 底层细节不应进入人工智能，但其效果可以安全表述 | 使用安全转换。 |
| 底层语境应保留在人工智能之外，但必须引导人工判断 | 使用仅由人处理。 |
| 真确性、时效性、适用性或支持依据不确定 | 使用具有足够独立性的核实路径。 |
| 需要权限、能力、适任性或专门领域判断 | 转交承担责任或专门领域的审核者。 |
| 事项不能安全处理或超出权限 | 停止并升级处理。 |
| 语境不相关、不可靠、不必要、未获准或使用／保留并不安全 | 不使用或不记录。 |

不要把敏感、受限制、私人、有争议、过时、未核实或未获准的语境放入人工智能。

如果底层语境应保留在人工智能工具之外：
- 只让审核者或人处理；及
- 如有需要，只提供安全的最低程度效果。

保留是另一项选用决定，并不是第八条当前任务路径。

只有在语境或其安全表述符合以下条件时，才考虑保留：
- 足够可靠；
- 必要；
- 可重用；
- 获准；
- 适合保存；
- 已指定承担责任的所有者及已批准位置；及
- 受合适的访问及审核控制约束。

```text
使用四项核对：
1. 任务依据可能缺少什么？

```
