# 来源资料包附加项

## 1. 目的及范围

当 **提示或审核前的任务依据可能不完整** 时使用本页，尤其是目前已批准来源可能已包含相关信息，而应检索及提取该信息，而不是依赖记忆重新创建。

本附加项通过核对已批准来源、预定用途、受众、排除事项、权限边界、审核依据及相关未明说语境需要，强化来源资料包。它支持多项控制所使用的来源资料包核对方法，以及获批准记录检索及提取方法。

它不创建完整的记录、元数据、保留、保存期、删除、检索或 RAG 框架；而且强大的来源资料包也不替换人工审核、核实、权限或专门领域判断。

## 3. 核对已批准记录

在要求人重新创建语境前，先检查目前已批准记录是否存在。

| 问题 | 备注 |
|---|---|
| 哪份已批准记录可能已包含答案？ |  |
| 谁拥有或批准该记录？ |  |
| 是否已检索目前已批准来源？ |  |
| 是否已为本任务妥善提取相关部分？ |  |
| 该记录对本任务而言是否足够现时有效？ |  |
| 该记录是否获允许用于此用途？ |  |

如已批准材料存在，检索目前已批准来源，并只提取与任务相关的材料。不要迫使人重新陈述机构已经批准的内容。

---

## 4. 未明说语境附加项

核对任务依据在以下方面是否缺失或不足：

- 本地做法；
- 未成文例外；
- 先前决定；
- 关系历史；
- 近期事件；
- 受众敏感度；
- 权限讯号；
- 重要性阈值；
- 本地要求；
- 语言、语气或语域；
- 运营记忆；
- 信任、声誉或机构政治。

不要在依赖人工智能前自动使用引导提取。只有当合适的人可能隐含地掌握相关语境，而且问题安全、获允许并在其适任性范围内时，才使用引导提取。

---

## 5. 不应输入人工智能的内容

除非机构有已批准的安全流程，而且该用途必要、获允许、现时有效及安全，否则不要把以下内容放入普通人工智能工具：

- 私人个人资料；
- 安全保护细节；
- 辅导资料；
- 纪律细节；
- 敏感法律或法规事实；
- 机密关系历史；
- 未经核实的指控；
- 保留给获授权负责人的材料。

按需要使用安全转换、仅由人处理、核实、责任负责人审核、专门领域审核或升级处理。

如底层细节敏感或不适合人工智能：
- 把这些细节留在人工智能工具之外；以及
- 由获授权的人工审核者只应用必要的安全影响。

只有在语境准确、必要、获允许、现时有效及安全时，才把它加入人工智能。否则，使用安全转换、仅由人处理、具足够独立性的核实路径、须问责或专门领域审核，或升级处理。

---

## 6. 范围边界

来源资料包是目前任务控制。它不会自动成为长期机构记录，也不替换 [[机构情境处理]]、[[机构记忆习惯]]、受限制记录流程或须问责的负责人。
