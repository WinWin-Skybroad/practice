## 這是什麼

**Win.Win 人工智能盲點指南** 協助讀者留意人工智能可能未收到、無法安全推斷，或不應被要求獨自處理的事項。

**人工智能盲點** 是一種情況：人工智能輔助輸出可能看起來清楚、完整、平衡或有信心，但人工智能無法可靠地看見、掌握、判斷、核實、授權，或為負責人必須處理的事項承擔責任。

**如果只記住一個概念：** 人工智能可能說得很有說服力，但重要事項仍可能缺失、未經核實、未獲授權，或仍依賴人工判斷。

如果您之後認出這類情況，但忘記了確切風險或解決方法，請先把它視為可能的 **人工智能盲點**，並回到本指南。使用 [[人工智能盲點風險庫]] (AI Blind Spot Risk Library) 理解及說出風險，再使用 [[人工智能盲點控制圖]] (AI Blind Spot Control Map) 找出相關控制、方法或問責路徑。

本指南與 **Win.Win 人工智能應用案例指南** 配合使用。

```text
Win.Win 人工智能應用案例指南
= 正在做甚麼任務、有哪些風險、需要甚麼審核或升級處理。

Win.Win 人工智能盲點指南
= 人工智能可能看不到甚麼，以及可能需要哪些更深入的核對或控制。
```

一個有用的配套問題是：

```text
人們有哪些隱含知道或使用的內容，尚未放入來源資料包、提示詞或審核依據？
```

未明說的語境是指在任務依據中缺失、不完整或未獲充分表述的相關語境。它可能由人掌握、存在於已批准紀錄、同時存在於兩者，或來源不清楚。

有經驗的人可能會自動使用累積語境：重複任務所得的經驗、默會判斷、機構記憶、本地及關係意識、風險取向、偏好及對時機的敏感度。人工智能只會收到任務依據及其他實際提供的資訊。人的理解本身亦可能不完整、錯誤、未獲授權或帶有偏見。

本指南協助讀者識別人工智能盲點風險、查閱控制圖，並在進入各控制的具體指引前，選擇相關的已認可控制。

**未明說的語境控制** 是目前的詳細控制，但不是所有情況的通用第一項控制。其最詳盡的指引涉及識別及安全引導提取未明說的語境。相關的目前任務指引涵蓋已批准來源的檢索及擷取、可表述性、安全轉換、僅由人處理、核實、由承擔責任或專門領域人士審核、停止及升級處理。

**使用這些材料並不能保證人工智能結果安全、合規或成功。讀者及其機構仍需自行負責所有決定。**

這些材料僅供一般資訊及獨立使用。它們不是諮詢服務、法律意見、合規認證、技術實施指引、財務建議、專業意見、醫療建議、輔導建議、神學建議或牧養諮詢。

| 層次 | 目的 | 包含內容 | 何時使用 |
|---|---|---|---|
| **實用層** | 協助讀者把本指南應用到真實的人工智能輔助任務。 | [[由此開始]] (Start Here)、[[人工智能盲點審核卡]] (AI Blind Spot Review Card)、[[未明說的語境控制]] (Unstated Context Control)、[[引導提取技巧]] (Elicitation Techniques)、[[機構情境處理]] (Organisational Context Handling)、[[來源資料包附加項]] (Source Packet Add-On)、[[當提問仍不足時]] (When Questions Are Not Enough)、[[機構記憶習慣]] (Organisational Memory Habit)，以及各項範本。 | 從這裏開始識別風險、查閱控制圖、選擇相關控制，然後只使用任務需要的實用指引、方法、適任性核對或升級處理步驟。 |
| **參考層** | 說明操作導覽圖、風險、控制、方法、問責路徑、術語、範圍及作者規則，以支援實用層的一致使用。 | [[如何使用本指南]] (How To Use This Guide)、[[指南範圍及定位]] (Guide Scope And Positioning)、[[人工智能盲點控制圖]] (AI Blind Spot Control Map)、[[人工智能盲點風險庫]] (AI Blind Spot Risk Library)、[[詞彙表]] (Glossary) 及 [[作者及編輯指南]] (Author and Editor Guide)。 | 當人工智能盲點、控制、方法、問責路徑、術語、範圍界線、調整或維護問題需要更深入說明時，查閱本層。 |

新讀者在使用本指南前，不需要先閱讀每份參考文件。先從實用層開始，再在審核需要更深入說明時使用參考層。

## 本指南不涵蓋甚麼

本指南不會令人工智能承擔責任、獲得授權、具備本地處境、擁有專業經驗，或能承擔人所面對的後果。

本指南不會把決策、批准、核實、專業判斷或後果的責任轉交人工智能。

本指南不會把提示詞、來源資料包、引導提取回答、核查清單或人工智能生成的說明，變成輸出正確、完整、獲授權、安全或適合使用的證明。

本指南不會取代：

- 獨立核實；
- 來源負責人核對；
- 權限負責人簽核；
- 決策負責人審核；
- 受眾影響審核；
- 雙語／語域核對；
- 營運負責人審核；
- 專業或專門領域審核；
- 就法律、財務、人力資源、私隱、法規、安全保障、輔導、牧養、神學或其他專門領域事項進行升級處理。

本指南可協助審核者識別差距、提出更好的問題、找出合適的控制及方法，並負責任地使用問責路徑。它不能消除承擔責任的人工判斷需要。
