# 如何使用本指南

## 1. 目的及範圍

如果您只需要快速入口，請使用 [[由此開始]]。

當您需要了解 **Win.Win 人工智能盲點指南** 的各檔案如何配合使用時，請使用本頁。它說明如何：
- 識別人工智能盲點風險；
- 找出相關控制；
- 使用可用的方法；
- 讓問責路徑參與；
- 在相關時進入未明說的語境控制詳細次序；以及
- 識別普通審核何時不足夠。

本頁是本指南的操作導覽圖。它不會：
- 重新界定 [[指南範圍及定位]] 中的範圍界線；
- 取代 [[詞彙表]] 中的規範術語；或
- 重複每份工作檔案中的詳細指示。

當您正在學習本指南的架構、培訓審核者、為機構調整本指南，或決定下一步應打開哪份檔案時，請閱讀本頁。

---

## 2. 操作原則

從真實任務及盲點疑慮開始，然後只使用本指南中負責任地處理該疑慮所需的部分。

核心架構關係是：

```text
人工智能盲點風險 → 相關控制 → 適用指引及方法 → 在需要時使用問責路徑
```

使用 [[由此開始]] 取得實際首次使用次序。使用 [[人工智能盲點控制圖]] 查閱規範控制、方法、問責路徑及其多對多關係。

不要在識別風險和選擇控制之間自動加入未明說的語境控制。只有當風險及任務顯示相關語境可能在任務依據中缺失、不完整或未獲充分表述時，才使用它。

人工智能輸出仍然是草稿、輔助工具或審核輔助。對於實際使用、傳送、批准、發布、依賴或採取行動的內容，負責人及機構仍須承擔責任。

## 3. 各檔案如何配合使用

在撰寫、編輯、自訂、本地化、驗證或維護本指南時，請使用 [[作者及編輯指南]]。

| 檔案或檔案組別 | 在本指南中的角色 | 何時打開 |

| [[人工智能盲點風險庫]] | 規範風險登記表及參考 | 您需要某項具名人工智能盲點風險的權威定義、它如何出現，以及負責人必須解決甚麼 |
| [[人工智能盲點控制圖]] | 規範登記表及關聯圖 | 您需要規範控制、方法和問責路徑，或它們之間已記錄的關係 |
| [[未明說的語境控制]] | 尋找及處理缺失語境 | 相關語境可能在任務依據中缺失、不完整或未獲充分表述；其最詳盡的指引涉及識別及安全引導提取該語境 |
| [[引導提取技巧]] | 詳細安全引導提取指引 | 合適的人可能隱含地掌握相關語境，而且具體、聚焦的問題安全並獲允許 |
| [[來源資料包附加項]] | 來源準備支援 | 任務依據可能不完整，或應檢索目前已批准來源並提取與任務相關的已批准材料 |
| [[機構情境處理]] | 目前任務情境處理導覽 | 您需要簡短了解可能缺失甚麼情境、它可能在哪裏、其可表述程度，以及詳細處理應繼續到哪裏 |
| [[當提問仍不足時]] | 適任性及路徑指引 | 更好的問題仍不足夠，因為事項敏感、受限制、涉及政治、超出適任性，或需要另一流程 |
| [[人工智能盲點審核卡]] | 簡短目前任務審核輔助 | 在使用人工智能輔助輸出前，您需要精簡的風險到控制審核次序 |
| [[範本/審核者適任性核對]] | 支援審核者適任性核對方法的審核者適任性範本 | 您需要判斷審核者是否有足夠適任性進行審核、批准、引導提取或升級處理 |
| [[範本/人工智能盲點引導提取工作表]] | 工作表 | 未明說的語境控制相關，而且您需要記錄有界限的未明說語境核對 |
| [[機構記憶習慣]] 及 [[範本/例外說明範本]] | 選用的安全保留支援 | 安全、可靠、可重用的經驗在目前任務後不應遺失 |
| [[指南範圍及定位]] | 範圍及定位參考 | 您需要了解本指南涵蓋甚麼、目前詳細發展甚麼，以及其界線所在 |
| [[詞彙表]] | 規範術語參考 | 您需要 本指南的核心模型術語、角色、適任性術語、決策標籤或架構概念的受控意思 |

本頁提供操作導覽圖。詳細指示屬於各個檔案。

## 4. 定義及規範登記表

每個受控術語或規範項目都只在一個地方有一個權威定義。

[[詞彙表]] 定義核心模型術語、角色及適任性、決策標籤，以及 **控制**、**方法** 和 **問責路徑** 等架構概念。它不會另行定義規範人工智能盲點風險，或個別規範控制、方法或問責路徑。

[[人工智能盲點風險庫]] 定義規範人工智能盲點風險，並提供各項風險專用的識別及處理指引。

[[人工智能盲點控制圖]] 定義個別規範控制、方法及問責路徑，並記錄它們的多對多關係，包括風險映射。

本頁說明這些權威位於哪裏；它不會重複其定義或關聯登記表。
