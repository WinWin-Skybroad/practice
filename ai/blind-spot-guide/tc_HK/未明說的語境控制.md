# 未明說的語境控制

## 1. 目的及範圍

當相關語境可能 **在任務依據中缺失、不完整或未被充分表述** 時，請使用本頁。

**未明說的語境控制** 是 Win.Win 人工智能盲點指南目前提供詳細指引的控制。其最完整的實用指引集中於識別及安全地引導提取未明說的語境。相關的當前任務指引亦涵蓋來源位置、檢索及擷取、可表述性、安全轉換、僅由人處理、核實、問責審核、停止及升級處理。

本頁說明如何：
- 識別未明說的語境；
- 識別可能的來源；
- 評估可表述性；
- 在適合時使用安全引導提取方法；及
- 選擇當前任務所需的最低程度處理，例如已批准的檢索、安全轉換、僅由人處理、核實、問責審核、停止或升級處理。

未明說的語境控制可支援多項人工智能盲點風險，但不能解決所有風險。使用 [[人工智能盲點控制圖]] 識別其他相關控制、方法或問責路徑。

本控制並不提供完整的機構情境、知識管理、紀錄管理或檢索增強生成（RAG）框架。

---

## 2. 未明說的語境是甚麼

**未明說的語境** 是任何在任務依據中缺失、不完整或未被充分表述的相關語境。

**任務依據** 包括任務可用的來源資料包、提示詞、實際使用的已批准材料、審核依據及目前決策紀錄。

人工智能可以運用提供給它的資訊，但它並不身處機構之中。它不知道人們默默記住甚麼。它感受不到訊息的時機。它不具有權限。如果輸出被錯誤使用，它也不承擔後果。

一份草稿可以看起來清晰、平衡而完整，但仍然遺漏人工審核者在安全使用前需要知道的事項。

這包括人們知道、記得、感覺到或通常會做，但沒有放入來源材料、提示詞或審核依據的內容。

---

## 3. 識別角度

### 3.1 語境如何在任務依據中變成缺失、不完整或單薄

- **未成文** — 沒有記錄在任何地方；
- **未在提示中提供** — 已在某處記錄或有人知道，但沒有提供給任務依據、沒有為任務檢索，或未在任務依據中充分表述；
- **部分記錄** — 部分相關內容已有記錄，但重要限制、理由、例外或後果缺失；
- **分散** — 分散於不同人、紀錄、先前決定或相關任務中，而不是集中在一個完整來源；
- **當前** — 在目前情況中已知或明顯，但尚未反映於任務依據。

---

### 3.2 人們可能如何掌握或表達它

- **默會** — 透過經驗知道，但難以按要求列出或解釋；
- **累積或經驗性** — 透過重複任務、相關工作、先前決定、變通方法、錯誤、險些出錯及真實經驗累積而成；
- **難以表達** — 人們能識別或據此行動，但不容易表述成清楚的事實、規則或指令；
- **關係性** — 與信任、歷史、角色、受眾反應或聲譽相關；
- **營運性** — 與任務、場地、供應商、流程或團隊實際如何運作相關；
- **跨文化／語域相關** — 與語氣、正式程度、語言、文化或社交意思相關。

---

### 3.3 為何可能需要受控處理

- **敏感** — 不適合廣泛披露，或放入一般文件或人工智能互動；
- **以權限為基礎** — 與誰可以批准、決定、承諾、拒絕、作出承擔或傳送相關；
- **重要** — 與會改變決定、優先次序、門檻、批准或後果的事項相關；
- **不安全或不適合** — 如沒有獲准且有問責的路徑，不適合放入人工智能或一般紀錄；
- **無法完整表述以供人工智能使用** — 無法完整表述給人工智能使用，而不遺失重要判斷、細微差別或責任。

同一語境可以同時符合多個角度。來源位置是獨立核對項。可表述性是另一項獨立核對。規範風險名稱 **未成文語境差距** 並不限於字面上沒有寫下的資訊。

## 4. 為何有經驗的人與人工智能不同

人也可能收到不完整的指示。有經驗的人並不會自動完整或正確。

本控制針對的獨特問題是：有經驗的人通常掌握超出明確任務資訊的內容，而人工智能一般只取得任務依據及實際提供給它的其他資訊。

```text
有經驗的人
= 明確任務資訊
+ 累積經驗
+ 默會判斷
+ 機構記憶
+ 本地及關係層面的認知

人工智能
= 任務依據及實際提供給它的其他資訊
```

缺失語境可能來自重複任務、相關任務、先前決定、變通方法、關係、習慣、真實經驗、本地做法、偏好、風險承受取向、對時機的敏感度、非正式門檻，或機構實際會批准甚麼。

---

## 5. 識別可能的來源

核對可能的來源位置：

- 人；
- 已批准紀錄；
- 兩者；
- 不清楚。

如有目前有效的已批准紀錄，先檢索來源並擷取與任務相關的已批准材料，再要求人重新憑記憶重述。

如果語境仍然是隱含、部分、難以表達、不安全說明或不清楚，應使用合適路徑，而不是強行把它放進人工智能。

---

## 6. 評估可表述性

使用最接近的一項評估可表述性：

- 可清楚表達；
- 可部分表達；
- 難以表達；
- 說明會不安全或不適合；
- 無法完整表述以供人工智能使用。

可表述性有助選擇路徑。它本身不能決定該語境是否重要、可靠、獲授權、可否使用或應否保留。

---

## 7. 為何直接提問往往無效

一個寬泛問題，例如：

```text
還有其他我應該知道的事情嗎？
```

可能會誠實地得到：

```text
沒有。
```

人們不一定把經驗儲存成整齊清單。具體而明確的問題可以給記憶一個依附點。

例如，不要問：

```text
有任何例外嗎？
```

改問：

```text
我們最近一次對這項規則作出變通、繞過、調整或低調例外是在甚麼時候？是為誰或為甚麼？
```

第二個問題給記憶一個具體事件作依附點。

只有在合適的人可能隱含掌握語境，而且問題屬安全及獲准時，才使用 [[引導提取技巧]] 進行 **安全引導提取方法**。

## 8. 當前任務的最低程度處理

選擇一條路徑：

- 只有在內容準確、必要、獲准、現行且安全時，才把已批准的最少內容加入任務依據；
- 使用安全轉換：只向人工智能提供必要而安全的效果。這可以是一項事實或來源、一項限制或措辭規則、一項遺漏或審核指示、一項批准邊界或人工撰寫要求，或一項升級處理觸發條件；
- 把底層語境保留為僅由人處理，並由獲授權人士引導撰寫、審核、批准、時機或升級處理；
- 以具有足夠獨立性的已批准來源、工具、紀錄或適當承擔責任的審核者核實；
- 轉交承擔責任或專門領域的審核者；
- 停止並升級處理；
- 不使用或不記錄。

| 語境情況 | 最低程度路徑 |
|---|---|
| 準確、必要、獲准、現行，而且可安全地用於人工智能輔助工作 | 只把已批准的最少內容加入任務依據。 |
| 底層細節不應進入人工智能，但其效果可以安全表述 | 使用安全轉換。 |
| 底層語境應保留在人工智能之外，但必須引導人工判斷 | 使用僅由人處理。 |
| 真確性、時效性、適用性或支持依據不確定 | 使用具有足夠獨立性的核實路徑。 |
| 需要權限、能力、適任性或專門領域判斷 | 轉交承擔責任或專門領域的審核者。 |
| 事項不能安全處理或超出權限 | 停止並升級處理。 |
| 語境不相關、不可靠、不必要、未獲准或使用／保留並不安全 | 不使用或不記錄。 |

不要把敏感、受限制、私人、有爭議、過時、未核實或未獲准的語境放入人工智能。

如果底層語境應保留在人工智能工具之外：
- 只讓審核者或人處理；及
- 如有需要，只提供安全的最低程度效果。

保留是另一項選用決定，並不是第八條當前任務路徑。

只有在語境或其安全表述符合以下條件時，才考慮保留：
- 足夠可靠；
- 必要；
- 可重用；
- 獲准；
- 適合保存；
- 已指定承擔責任的擁有人及已批准位置；及
- 受合適的存取及審核控制約束。
