# 例外說明範本

## 1. 目的及範圍

當目前任務產生一項 **小型、有界限、安全、可靠且可重用的經驗**，並應透過已批准負責人及位置加以保留時，使用本選用範本。

例子包括：
- 一項例外；
- 一項本地做法；
- 一項先前決定；
- 一項營運經驗；
- 一項涉及關係敏感性的警告；或
- 其他安全的可重用語境備註。

只有在已決定保留獲允許且適當後才使用。本備註不會自動成為可供人工智能使用的資料，也不能取代已批准紀錄、政策、決定、權限、安全保障流程、專門領域流程或其他所需來源。

如按照機構已批准流程適合保留，本範本可支援一項另外的選用受管治保留決定。

本範本不提供以下完整框架：
- 情境儲存庫；
- 中繼資料；
- 檢索；
- 保留或刪除；
- 紀錄架構；或
- RAG 設計。

---

## 2. 使用本備註前

確認語境符合以下條件：

- 準確；
- 必要；
- 獲允許；
- 現時有效；
- 安全；
- 足夠可靠；
- 可重用；
- 適合保留；
- 已指定須問責的負責人及已批准位置。

如任何答案不清楚，不要在此保留該語境。

---

## 3. 一行備註

```text
當 [觸發條件或情況] 出現時，在 [行動、輸出或批准] 前核對 [已批准語境、來源、人或職能]。
```

## 5. 例子

批准例外：

```text
當發票批准例外看似適用時，在草擬批准措辭前先核對已批准的財務例外路徑。
```

受影響人士通知：

```text
在廣泛發布角色變更公告前，先核對受影響人士是否已獲直接通知。
```

場地進出或設置：

```text
為本場地使用去年的活動核查清單前，先核對進出及設置備註，因為升降機可用情況曾影響時間安排。
```

## 6. 安全警告

不要在本範本記錄敏感、私人、不安全、有爭議、不必要、過時、未經核實、不獲允許或過度個人化的語境。

不要使用本範本繞過已批准紀錄、政策、決策負責人、安全保障流程、私隱流程、法律或法規流程、人力資源流程、專業審核、牧養或神學審核，或其他專門領域路徑。

對於人力資源、牧養、安全保障、紀律、輔導、投訴或調查事項，使用機構適當的受限制流程，並升級交由須問責的負責人處理。
