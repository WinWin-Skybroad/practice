## 1. 目的
> [!note] 请调整此开首句以反映您组织特定的信仰承诺与价值观。

我们相信科技应当服事人并荣耀神。人工智能工具为行政效率、沟通及学习带来真实益处。善用它们，可以腾出时间专注事工；粗心使用，则可能损害信任、破坏保密性，并以似是而非的事物取代真正的人手关怀。

本政策旨在帮助我们的职员及志愿者：

- **明智使用人工智能** — 在清晰且共识的界限内
- **保护隐私** — 尊重我们所服事的每个人的尊严
- **维护诚信** — 确保我们的事工及沟通的完整性
- **牧养关怀保持由人参与** — 灵性指引与神学教导，专属蒙召的牧者
- **履行法律义务** — 遵守香港《个人资料（私隐）条例》（第 486 章）

本政策并不禁止使用人工智能。它确立界限，使人工智能的使用方式符合我们的价值观、法律义务，以及对神托付给我们之人的关顾责任。

## 3. 我们的治理原则

本组织内所有人工智能使用均受以下原则管辖：

| 原则 | 实践中的含义 |
|------|-------------|
| **人工审核属强制性** | 任何人工智能输出在使用、发布、发送或分发前，必须经人手阅读并批准。速度永远不是跳过此步骤的理由。 |
| **牧养关怀保持由人参与** | 人工智能在牧养辅导、祈祷事工、灵性指引或任何形式的人灵魂关顾中没有角色。这些需要真实的人手参与 — 永远如此。 |
| **神学教导保持由人参与** | 人工智能绝不可被定位为神学权威的来源。圣经诠释、教义指引及灵性教导属于蒙召且需负责的牧者。 |
| **个人信息受保护** | 会友、访客或受益人的个人信息在任何情况下均不得输入公共人工智能工具。 |
| **真理优先于速度** | 发送或发布的人工智能辅助内容代表我们组织。准确性比效率更重要。我们不会在未阅读的情况下发布人工智能输出。 |
| **保持诚实** | 我们不使用人工智能创建欺骗性内容 — 包括人工智能生成的语音、图像或文本，误导他人关于我们的领导层、教义或所服事的人。 |

## 6. 禁止的使用案例 — 红线

以下使用在任何情况下均不允许。这些 **「红线」** 旨在保护我们的会众、事工及组织诚信：

- [ ] **透过人工智能进行牧养关怀** — 人工智能绝不可用于提供辅导、祈祷支援、灵性指引或任何形式的牧养关怀。这些需要真实的人手关系。
- [ ] **人工智能进行神学教导** — 人工智能绝不可被呈现为神学权威或圣经诠释的来源。人工智能产生的神学内容必须明确标注为人工智能生成，并在用于任何用途前经合格牧者审阅。
- [ ] **公共人工智能工具中的个人信息** — 会友姓名、联系详情、香港身份证号、健康信息、财务详情、祈祷事项、辅导笔记，或任何关于个人的信息，绝不得输入公共人工智能工具。
- [ ] **机密牧养记录** — 辅导记录、个人披露及牧养关怀档案绝不得与任何人工智能系统分享。
- [ ] **自动化对外通讯** — 人工智能绝不可在未经每则消息人工审阅及批准的情况下，向会友、访客或公众发送任何通讯。
- [ ] **受益人资格决定** — 人工智能绝不可做出或建议关于某人获得关顾、财务协助或事工参与的决定。
- [ ] **欺骗性人工智能生成内容** — 误导我们领导层或捏造真实人士言论的人工智能生成语音、图像或视频均被禁止。
- [ ] **未经批准的工具** — 未列入第 4 节批准清单的人工智能工具，未经政策负责人事先书面批准，不得用于任何组织相关任务。

## 7. 所有批准使用的必需防护措施

以下防护措施适用于所有批准的人工智能使用：

- [ ] **人工审核** — 每项与会众成员、公众或任何外部方分享或影响他们的人工智能输出，在使用前必须经指定负责人审阅并批准
- [ ] **无敏感信息** — 个人信息、牧养记录、人力资源数据或机密文件不得输入公共人工智能工具
- [ ] **《个人资料（私隐）条例》合规** — 如人工智能工具处理任何个人信息，必须先评估《个人资料（私隐）条例》资料保障原则（DPP）第 3 原则的合规性
- [ ] **繁体中文可读性** — 如使用繁体中文文件，必须在人工智能处理前测试其机器可读性
- [ ] **来源验证** — 人工智能输出中的所有事实、数字、引用及声明在使用前必须经主要来源验证
- [ ] **神学审阅** — 任何具有神学、教义或牧养影响的人工智能辅助内容，必须经牧师或长老审阅

## 8. 数据保护与隐私 — 《个人资料（私隐）条例》合规

所有人工智能使用必须遵守香港《个人资料（私隐）条例》（第 486 章）。以下规则属强制性：

| 《个人资料（私隐）条例》要求 | 我们如何在人工智能使用中合规 |
|---------------------------|---------------------------|
| **DPP 1 — 收集目的** | 我们仅在人工智能工具中使用个人信息，用于与该数据原收集目的一致的用途 — 且仅在明确允许的情况下 |
| **DPP 3 — 使用限制** | 为事工目的收集的个人信息（例如活动报名），不得在未经该人知情或同意的情况下，通过人工智能工具用于不同目的（例如通讯分析） |
| **DPP 4 — 数据安全** | 个人信息不得输入公共人工智能工具。仅匿名化或非个人信息可用于人工智能辅助任务 |
| **DPP 5 — 公开性** | 职员及志愿者获告知本政策及本组织如何使用人工智能工具 |

> [!warning] 在任何涉及会友或受益人数据的任务中使用人工智能前，请询问： **这些数据是否为包含人工智能处理的目的而收集？** 如否，则不得使用。如不确定在人工智能工具中使用特定个人信息是否符合《个人资料（私隐）条例》许可 — 请不要继续。先咨询政策负责人。

## 9. 人工审核与质量控制

人工审核并非可选。它是所有人工智能辅助输出的硬性要求。

| 输出类型             | 所需审核者       | 时机      |
| ---------------- | ----------- | ------- |
| 对外通讯（邮件、通讯、社交媒体） | 负责事工领袖或沟通团队 | 发送或发布前  |
| 内部通知及备忘录         | 发送职员或志愿者    | 发送前     |
| 会议摘要及记录          | 会议主席或秘书     | 分发前     |
| 志愿者材料及入职文件       | 运营经理或事工领袖   | 与志愿者分享前 |
| 翻译内容             | 双语职员或合格审核员  | 发布或发送前  |
| 神学或圣经相关内容        | 主任牧师或指定牧者   | 在任何使用前  |

审核者负责：

- **完整阅读** — 不仅仅是略读
- **验证所有事实** — 姓名、日期及数字
- **纠正错误** — 在内容使用前
- **承担责任** — 对最终内容负责，如同他们自己撰写一样

## 10. 影子人工智能（将个人工具用于教会任务）

影子人工智能意指将个人人工智能订阅用于教会任务，绕过组织批准的工具。

- [ ] **仅消费者条款** — 个人人工智能账户不受企业保护
- [ ] **无教会数据** — 个人人工智能工具不得用于涉及会友数据或机密教会信息的任务
- [ ] **训练风险** — 个人账户可能使用输入进行人工智能训练
- [ ] **提出，而非绕过** — 如需要更好的工具，请向政策负责人提出；不要使用个人账户绕过缺口

## 11. 训练退出要求

许多人工智能工具默认使用输入进行模型训练。当使用任何人工智能工具进行组织相关任务时：

- [ ] **检查默认设置** — 您批准的工具是否允许输入用于训练？
- [ ] **如可能则退出** — 在将工具用于任何组织内容前退出
- [ ] **如无退出选项则不使用** — 如无法退出，则不要将该工具用于任何包含组织信息的内容

这尤其适用于用于教会任务的免费或个人人工智能账户。

## 12. 报告与违规管理

职员或志愿者必须立即向政策负责人报告以下情况：

- **未经审阅的输出已分享** — 任何人工智能输出在所需人工审核前已分享或据此行动
- **个人信息外泄** — 任何个人信息意外输入公共人工智能工具
- **政策违规** — 任何可能违反本政策或适用法律的人工智能使用
- **未涵盖的情况** — 任何关于本政策未涵盖的人工智能使用的疑虑

报告将以保密方式处理，如属善意提出疑虑则不予责备。

如个人信息可能已通过人工智能工具意外外泄，这可能触发《个人资料（私隐）条例》下的通知义务。政策负责人将决定是否需要通知个人资料私隐专员公署（PCPD）。

## 13. 如果出现问题

如人工智能产生已与会众成员或公众分享的错误：

1. **通知领导层** — 立即；不要试图悄悄纠正
2. **透明行动** — 不试图悄悄修复
3. **《个人资料（私隐）条例》评估** — 如涉及个人信息，评估违规通知义务
4. **及时纠正** — 通过适当渠道尽快纠正
5. **更新流程** — 审阅哪个防护措施本应捕捉此问题
