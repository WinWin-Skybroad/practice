## 1. 目的

人工智能工具为效率、沟通及许多工作任务的质量带来真实益处。善用它们，可以腾出时间专注重要的工作；粗心使用，则可能造成损害 — 包括数据隐私违规、客户通讯的事实错误、保密失效，以及声誉或监管风险。

本政策旨在帮助我们的职员及同事：

- **明智使用人工智能** — 在清晰且共识的界限内
- **保护隐私** — 我们的客户、会友及所服事的人
- **维护诚信** — 我们的沟通及专业声誉
- **专业判断保持由人负责** — 影响人员权利、雇佣或福利的决定属于负责的职员
- **履行法律义务** — 遵守香港《个人资料（私隐）条例》（第 486 章）

本政策并不禁止使用人工智能。它确立界限，使人工智能的使用方式符合我们的价值观、法律义务，以及对所服事之人的关顾责任。

## 3. 我们的治理原则

本组织内所有人工智能使用均受以下原则管辖：

| 原则 | 实践中的含义 |
|------|-------------|
| **人工审核属强制性** | 每个用于业务的人工智能输出在使用前必须经负责职员审阅并验证。速度永远不是跳过此步骤的理由。 |
| **客户数据受保护** | 客户个人信息、机密信息及未发布的业务数据绝不得输入公共人工智能工具。 |
| **准确性优先于速度** | 发送至客户或用于业务决策的人工智能辅助内容代表我们组织。准确性比效率更重要。我们不会在未阅读的情况下使用人工智能输出。 |
| **准确性是职员的责任** | 使用或发送人工智能辅助内容的职员对其准确性负责 — 无论其如何产生。「人工智能写的」不是有效的专业辩护。 |
| **仅批准的工具** | 仅组织批准清单上的人工智能工具可用于业务任务，除非已获得政策负责人的事先书面批准。 |
| **《个人资料（私隐）条例》合规不容妥协** | 所有人工智能使用必须遵守香港《个人资料（私隐）条例》（第 486 章）。 |

## 6. 禁止的使用案例 — 红线

以下使用在任何情况下均 **不允许**。这些 **「红线」** 旨在保护我们的组织诚信：

- [ ] **公共人工智能工具中的客户个人信息** — 客户姓名、香港身份证号、联系详情、财务详情、健康信息，或任何个人信息绝不得输入公共或个人人工智能工具。
- [ ] **未经批准工具中的机密业务信息** — 商业秘密、未发布财务数据、客户合同、定价策略或专有业务信息不得输入任何未经批准的人工智能工具。
- [ ] **自动化客户通讯** — 人工智能绝不可在未经每则消息人工审阅及批准的情况下，向客户或外部方发送任何通讯。
- [ ] **人工智能辅助的个人决定** — 招聘决定、纪律事项、绩效评估，或信贷/资格评估不得在无人手判断及问责的情况下由人工智能做出或建议。
- [ ] **未经审阅的法律或合规文件** — 法律文件、合规认证、监管提交及税务申报不得在未经合格人手审阅及签署的情况下由人工智能生成。
- [ ] **生成误导性内容** — 人工智能绝不可用于捏造报价、误述能力或资质，或创建欺骗客户或伙伴的内容。
- [ ] **未经批准的工具** — 未列入第 4 节批准清单的人工智能工具，未经政策负责人事先书面批准，不得用于任何业务目的。

## 7. 所有批准使用的必需防护措施

以下防护措施适用于所有批准的人工智能使用：

- [ ] **人工审核** — 每项与任何外部方分享或影响他们的人工智能输出，在使用前必须经指定负责人审阅并批准
- [ ] **无敏感信息** — 个人信息、人力资源数据或机密文件不得输入公共人工智能工具
- [ ] **《个人资料（私隐）条例》合规** — 如人工智能工具处理任何个人信息，必须先评估《个人资料（私隐）条例》资料保障原则（DPP）第 3 原则的合规性
- [ ] **繁体中文可读性** — 如使用繁体中文文件，必须在人工智能处理前测试其机器可读性
- [ ] **来源验证** — 人工智能输出中的所有事实、数字、引用及声明在使用前必须经主要来源验证
- [ ] **专业审核** — 任何具有法律、合规或监管影响的人工智能辅助内容，必须经合格专业人士审核

## 8. 数据保护与隐私 — 《个人资料（私隐）条例》合规

所有人工智能使用必须遵守香港《个人资料（私隐）条例》（第 486 章）。以下规则属强制性：

| 《个人资料（私隐）条例》要求 | 我们如何在人工智能使用中合规 |
|---------------------------|---------------------------|
| **DPP 1 — 公共人工智能工具中无个人信息** | 客户或职员个人信息不得输入任何公开可访问的人工智能工具。这包括姓名、联系详情、香港身份证号、财务信息及健康数据。 |
| **DPP 3 — 使用限制** | 为某一业务目的收集的个人信息（例如客户入职），未经该人知情或同意，不得通过人工智能工具用于不同目的。 |
| **DPP 4 — 数据最小化** | 当使用人工智能进行起草或分析时，使用完成任务所需的最少数据。如可能，匿名化或移除个人识别信息。 |
| **DPP 4 — 输出安全** | 包含任何客户或职员信息的人工智能生成输出，必须以与其他业务记录相同的保密标准处理。 |
| **DPP 4 — 违规报告** | 任何个人信息意外输入公共人工智能工具必须立即报告给政策负责人。 |

> [!warning] 如不确定特定人工智能使用是否符合《个人资料（私隐）条例》— 请不要继续。在继续前先寻求政策负责人或合格隐私专业人士的指引。

### 数据分类 — 在输入任何内容到人工智能之前

在使用任何数据于人工智能工具前，使用此表进行分类：

| 分类 | 示例 | 我可以在人工智能中使用此数据吗？ |
|------|------|------------------------------|
| **公开** | 已发布信息、营销材料、公开公告 | 一般可以 — 仅限批准的工具 |
| **内部** | 内部程序、非敏感备忘录、一般组织信息 | 可以 — 仅限批准的工具 |
| **机密** | 客户数据、合同、财务详情、业务策略、定价 | 不可以 — 不得在公共人工智能工具中使用 |
| **受限 / 敏感** | 个人信息（香港身份证号、健康、薪金）、密码、法律事项、合规档案 | 绝不可以 |

**公告栏规则：** 在将任何信息输入人工智能工具前，询问：我会愿意将此信息写在公共公告栏上吗？如否 — 不要输入。

## 9. 人工审核与质量控制

人工审核并非可选。它是所有人工智能辅助输出的硬性要求。

| 输出类型         | 所需审核者         | 时机      |
| ------------ | ------------- | ------- |
| 客户邮件及通讯      | 发送职员          | 每次发送前   |
| 客户报告、提案及演示文稿 | 作者 + 经理（重大输出） | 交付客户前   |
| 内部文件及通知      | 发送职员          | 分发前     |
| 会议摘要及记录      | 会议组织者或秘书      | 分享前     |
| 财务数据提取       | 财务团队成员        | 记录任何内容前 |
| 翻译内容         | 双语职员或合格审核员    | 发布或发送前  |
| 法律或合规相关内容    | 合格专业人士        | 任何使用前   |

审核者负责：

- **完整阅读** — 不仅仅是略读
- **验证所有事实** — 姓名、日期及数字
- **纠正错误** — 在内容使用前
- **承担责任** — 「人工智能写的」不是客户面向内容错误的可接受解释

## 10. 影子人工智能（将个人工具用于工作任务）

影子人工智能意指将个人人工智能订阅用于工作任务，绕过组织批准的工具。

- [ ] **仅消费者条款** — 个人人工智能账户不受企业保护
- [ ] **无工作数据** — 个人人工智能工具不得用于涉及客户数据或机密组织信息的任务
- [ ] **训练风险** — 个人账户可能使用输入进行人工智能训练；创建组织无法控制的数据驻留、训练及保密风险
- [ ] **提出，而非绕过** — 如需要更好的工具，请向经理提出；不要使用个人账户绕过缺口

## 11. 训练退出要求

许多人工智能工具默认使用输入进行模型训练。当使用任何人工智能工具进行组织相关任务时：

- [ ] **检查默认设置** — 您批准的工具是否允许输入用于训练？
- [ ] **如可能则退出** — 在将工具用于任何业务内容前退出
- [ ] **如无退出选项则不使用** — 如无法退出，则不要将该工具用于任何包含组织信息的内容

这尤其适用于用于业务任务的免费或个人人工智能账户。

## 12. 报告与违规管理

职员必须立即向政策负责人报告以下情况：

- **未经审阅的输出已发送** — 任何人工智能输出在所需人工审核前已发送给客户或发布
- **个人信息外泄** — 任何个人信息意外输入公共人工智能工具
- **政策违规** — 任何可能违反本政策或适用法律的人工智能使用
- **客户疑虑** — 任何与人工智能生成内容相关的客户投诉或疑虑

善意提出的报告将不予责备。报告的目的是识别及纠正问题 — 而非惩罚提出疑虑的职员。

如可能发生《个人资料（私隐）条例》违规，政策负责人将决定是否需要通知个人资料私隐专员公署（PCPD）并管理该流程。

## 13. 如果出现问题

如人工智能产生已发送给客户或用于业务决策的错误：

1. **告知经理** — 立即；不要试图独自悄悄修复
2. **保留记录** — 保留已发送的内容及错误是什么
3. **评估影响** — 谁收到了它，可能影响了哪些决策
4. **及时纠正** — 通过适当渠道尽快纠正
5. **更新流程** — 审阅哪个防护措施本应捕捉此问题

---

## 14. 不合规的后果

> [!note] 根据您组织的纪律框架及雇佣安排进行调整。志愿者或政府组织应就其背景下适当的后果语言寻求人力资源或法律意见。

违反本政策的职员 — 无论故意或疏忽 — 可能受到纪律处分，最高可至终止雇佣，取决于违规的严重性及性质。

导致数据隐私事件、客户伤害或监管调查的违规，也可能使组织面临法律责任及监管行动。

## 15. 政策审阅

本政策将审阅：

- **年度审阅** — 至少每 12 个月一次
- **建议新工具** — 每当出现重大新人工智能工具或使用案例时
- **法律变更** — 当香港法律或监管指引发生相关变更时
- **范围变更** — 当组织内人工智能使用范围发生重大变更时
- **事件后** — 跟随任何重大人工智能相关事件后

职员可随时向政策负责人提交政策改进建议。
