# 人工智能安全检查清单 — 个人版

> [!info] 使用记录：  
>  
> **任务：** （例如：教会通讯起草、会议纪要摘要）  
> **日期：**  
> **使用的人工智能工具：**  
> **填写人：**   

> [!quote] 为何重要  
> 人工智能工具功能强大 — 但也容易因意外而被误用。  
>  
> 本检查清单帮助你保护自己、你的数据，以及你所服事的人。  
> 每次尝试新的人工智能工具或任务时使用它。

> 将人工智能输出视为起草引擎，而非真相引擎。  
> 每个输出在到达任何重要的人或事物之前，都需要人手阅读。

**适用对象：** 任何个人使用人工智能工具的人士 — 用于工作、学习、事工支援、志愿者服务或副业项目。

**重要提示：** 「较安全的人工智能使用」意指减少常见风险。这并**不**保证安全、准确或合规。

---

## 1. 开始前（3P 检查）

### P1 · 目的 — 这是否适合人工智能处理的任务？

- [ ] **目的清晰？** — 人工智能究竟会产出什么、给谁使用，而你仍会自行决定什么？
- [ ] **任务类型正确？** — 文字密集型、重复性或信息类任务；非高风险判断
- [ ] **工具正确？** — 还是人手更合适？
- [ ] **风险检查** — 人工智能在此是降低风险，还是创造新风险？
- [ ] **人工审核输出** — 我将在使用前审核它
- [ ] **指定负责人？** — 谁对此输出负责？
- [ ] **加速，而非逃避** — 使用人工智能加快起草，而非免除我的责任
- [ ] **不涉及人员决策** — 不影响健康、财务、安全或法律状态

> [!warning] 如果你即将让人工智能对他人做出决策，请停止：  
> 医疗、财务、法律、牧养和福利决策需要真人 — 而非语言模型。

---

### P2 · 权限 — 我可以将什么数据输入此工具？

- [ ] **已批准的工具？** — 适合此任务和数据类型的正确工具
- [ ] **了解限制** — 此工具不允许使用哪些数据？
- [ ] **《个人资料（私隐）条例》检查** — 此数据是否允许用于人工智能处理？香港的《个人资料（私隐）条例》（第 486 章）规定，为某一目的收集的个人信息未经评估不得用于另一目的。如有疑问，请勿输入个人信息。
- [ ] **隐私政策已检查** — 该工具是否允许此类数据？
- [ ] **无个人信息** — 不贴上姓名、身份证号、地址、电话、健康或财务详情
- [ ] **无机密内容** — 不贴上牧养记录、客户记录或敏感信息
- [ ] **无凭证** — 不贴上密码、应用程序编程接口（API）密钥或登录详情
- [ ] **最小数据** — 仅使用完成此任务所需的最少数据
- [ ] **尽可能匿名化** — 移除姓名和识别信息
- [ ] **训练退出** — 检查隐私设置；了解哪些数据会被存储或用于训练

> [!note] 简单规则：  
> 如果您不愿意将其写在明信片上并留在公共公告栏上，就不要将其输入公共人工智能工具。

---

### P3 · 证明 — 我能否验证并对人工智能的产出负责？

- [ ] **阅读完整输出** — 在到达任何人之前
- [ ] **能够为之背书？** — 如果被质疑时感到舒适
- [ ] **验证声明** — 统计数据、日期、姓名和引用已验证
- [ ] **保留记录** — 重要任务记录提示词和输出
- [ ] **能够解释？** — 能够用通俗语言说明为何此输出足够好
- [ ] **能够纠正？**— 如果出现问题，能否快速解释并修复？
- [ ] **预期错误** — 人工智能可能自信地产生幻觉；我知道这一点。

> [!note] 流畅不等于正确。

> [!important] 责任测试：  
> 我是否愿意在此输出上署名并解释人工智能协助产生了什么？  
> 如果是 — 您已经做得足够。如果否 — 请进一步检查。

## 2. 人工智能回应后：幻觉警告信号

留意以下情况，并在信任任何内容前进行验证：

- [ ] **统计数据，无来源** — 具体数字但无指明出处
- [ ] **引用是否存在？** — 论文、案例或参考文献：检查它是否真实存在
- [ ] **网址是否有效？** — 检查它是否指向所声称的位置
- [ ] **近期事件？** — 人工智能训练有截止日期
- [ ] **香港法律声明？** — 香港特定规则在人工智能输出中经常出错
- [ ] **100% 自信语气** — 无不确定性或免责声明：这是一个警告信号
- [ ] **流畅但无证据** — 听起来权威但无具体内容支持

> [!warning] 红旗 — 停止并重新考虑：  
> 如果出现以下情况，请停止并放慢速度：
> - **影响他人权利** — 资格、声誉、财务或福祉
> - **需要专业判断** — 法律、医疗、财务、人力资源、牧养或合规
> - **无意中包含数据** — 个人或机密内容出现在输出中
> - **被催促信任它** — 看起来流畅且自信：仍需验证
> - **无法解释它** — 无法说明来源、限制或可靠性
> - **无进一步审核** — 其他人将依赖此输出而无任何检查

---

### 2.1 三分钟事实核查习惯

当你发现上述警告信号时 — 或在分享任何重要内容之前 — 花三分钟：

- **怀疑问题（30 秒）** — 问人工智能：「你可能会在哪里出错？」
- **搜索一项声明（60 秒）** — 在搜索引擎或官方来源中搜索最具体的声明
- **询问真人（60 秒）** — 如果影响他人，在采取行动前验证

## 3. 保护你的账户和设备

> 这些是一次性设置检查 — 不需要每次人工智能任务都执行。首次使用新工具或每隔几个月检视一次。

- [ ] **独特密码** — 与银行或工作账户不同
- [ ] **双重认证** — 在经常使用的人工智能工具上启用
- [ ] **不保持登录** — 不要在共用或公共电脑上保持登录状态
- [ ] **设置已检视** — 检查隐私设置；了解哪些数据会被存储
- [ ] **训练退出** — 如果不想让数据用于训练，请选择退出

---

## 4. 在我分享或发布任何内容之前

- [ ] **完整输出已阅读** — 不仅仅是开头
- [ ] **自己的声音** — 编辑以反映我自己的声音；纠正错误
- [ ] **语气和影响** — 检查准确性及对他人的影响
- [ ] **移除误导内容** — 移除任何过度自信、令人尴尬或有害的内容
- [ ] **能够负责** — 如果是我自己写的，我会感到舒适
- [ ] **考虑披露** — 如果人工智能有实质性协助，考虑是否注明

## 5. 快速参考

| 情况 | 应该怎么做 |
|------|----------|
| **人工智能给出统计数据** | 在使用前搜索原始来源 |
| **人工智能给出网址** | 检查链接是否真实存在且有效 |
| **人工智能提及真人** | 从官方来源验证 |
| **即将贴上个人信息** | 停止 — 改用匿名示例 |
| **发送输出给外部方** | 完整阅读；编辑；人手签署确认 |
| **香港法律或法规** | 在 elegislation.gov.hk 验证或与律师确认 |
| **不确定人工智能是否合适** | 问：「如果此输出错误而我据此行动会怎样？」 |

---

## 6. 不适合人工智能 — 始终使用人手

- **医疗决策** — 诊断或治疗
- **法律建议** — 合同或合规裁定
- **财务决策** — 投资选择
- **牧养关怀** — 辅导或灵性指导
- **高影响决策** — 显著影响他人生活
- **「人工智能说的」** — 任何以此作为解释不可接受的任务

---

## 7. 高风险类别 — 始终格外谨慎

| 类别 | 风险 | 规则 |
|------|------|------|
| **医疗／健康** | 错误剂量、诊断或治疗 | 与医生或药剂师验证 |
| **法律／监管** | 香港特定法律在人工智能中经常出错 | 在 gov.hk、elegislation.gov.hk 或律师处验证 |
| **财务／投资** | 可能过时或不适用于香港 | 与持牌顾问或证监会／金管局来源验证 |
| **圣经／神学** | 看似合理但神学上错误的内容 | 直接在圣经中验证；咨询你的牧师 |
| **具名个人** | 人工智能可能捏造传记细节 | 从该人士的官方简介或联系方式验证 |
| **近期事件** | 人工智能训练有截止日期 | 搜索即时新闻来源 |
| **教会通讯** | 可能影响关系或声誉 | 发送前进行人手牧养审核 |

---

## 8. 一分钟最终检查

在使用、发送或发布任何人工智能协助创建的内容之前：

- **目的** — 人工智能是否是此任务的正确工具？
- **权限** — 我是否将敏感信息排除在提示词之外？
- **证明** — 我是否已阅读此内容、检查关键声明，并能够为之背书？

如果三者都是「是」— 你已经做了最低限度的负责任之事。
