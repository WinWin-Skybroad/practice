# 人工智能安全检查清单 — 工作版

> [!info] 使用记录：  
>   
> **任务：** （例如：教会通讯起草、会议纪要摘要）  
> **日期：**  
> **使用的人工智能工具：**  
> **填写人：**  

> [!quote] 为何在工作中重要：  
> 在工作中使用人工智能会带来个人使用时可能没有的责任。  
> 你正在处理组织的信息、客户的信任，以及你的专业声誉。  
> 「人工智能说的」不是专业辩护。你对所提交的内容负责。  
>   
> 本检查清单帮助你在工作环境中安全地使用人工智能，符合组织规则，并能够为此负责。  
> 每次尝试新的人工智能工具或任务时使用它。  

> 将人工智能输出视为起草引擎，而非真相引擎。  
> 每个输出在到达任何重要的人或事物之前，都需要人手阅读。

**适用对象：** 在任何工作环境中使用人工智能工具的职员、合同员工及志愿者。

**重要提示：** 「较安全的人工智能使用」意指减少常见风险。这并**不**保证安全、准确或合规。

## 1. 首先了解你组织的规则

- [ ] **了解政策** — 是否有人工智能使用政策？
- [ ] **已批准的工具** — 哪些人工智能工具获批准用于工作？
- [ ] **允许的任务** — 哪些任务可由人工智能协助，哪些是禁止的？
- [ ] **有问题问谁** — 如果对特定人工智能使用有疑问，我应向谁查询？

> [!important] 如果你的组织尚未有人工智能政策：  
> 在政策存在之前，将本检查清单作为你的个人标准。  
> 向你的经理提出需要制定政策。你可以分享 Win.Win@Skybroad 的《人工智能使用政策》模板作为起点。

---

## 2. 每次工作任务前（3P 检查）

### P1 · 目的 — 这是否适合在工作中使用人工智能的任务？

- [ ] **目的清晰？** — 起草、摘要、研究或翻译
- [ ] **人工审核输出** — 在影响任何人或任何事物之前
- [ ] **非决策** — 我不是使用人工智能做出属于人手的决策
- [ ] **符合政策** — 使用案例符合我组织允许的范围
- [ ] **了解成本** — 清楚错误输出可能意味着什么

> [!warning] 人工智能是起草和支援工具 — 而非决策者：  
> 关于人员、合同、合规和客户承诺的最终决策必须由人手做出。

---

### P2 · 权限 — 我可以在工作中使用哪些数据与人工智能？

**数据分类 — 在将任何数据输入人工智能工具之前：**

| 分类 | 示例 | 我可以在人工智能中使用此数据吗？ |
|------|------|------------------------------|
| **公开** | 已发布的政策、公开公告 | 一般可以 — 仅限已批准的工具 |
| **内部** | 内部备忘录、非敏感程序 | 可以 — 仅限已批准的工具 |
| **机密** | 客户数据、合同、财务详情、人力资源记录 | 不可以 — 不可在公共人工智能工具中使用 |
| **受限／敏感** | 个人信息（身份证、健康、薪金）、密码、法律事项、牧养记录 | 绝不可以 |

**绝不可输入公共或个人人工智能工具的内容：**

- [ ] **客户个人信息** — 姓名、联系方式、账户号码、个人记录
- [ ] **人力资源记录** — 薪金、绩效数据、员工信息
- [ ] **机密合同** — 法律协议、受保密协议保护的内容
- [ ] **机密策略** — 业务计划、财务预测、内部定价
- [ ] **标注为机密** — 任何标注为「机密」、「受限」或「内部」的内容
- [ ] **凭证** — 密码、应用程序编程接口（API）密钥、认证令牌
- [ ] **他人的个人信息** — 姓名、香港身份证号、地址、电话、邮件、健康、财务
- [ ] **敏感人力资源／牧养** — 人事事项、牧养披露
- [ ] **不愿公开？** — 如果我不愿公开分享，就不要输入

> [!note] 简单规则：  
> 如果您不愿意将其写在明信片上并留在公共公告栏上，就不要将其输入公共人工智能工具。  
> 这适用于客户数据、内部财务、策略计划和个人详情。

**使用前询问：**

- [ ] **涉及个人信息？** — 先检查《个人资料（私隐）条例》合规性
- [ ] **客户材料？** — 确认你的组织允许在客户工作中使用人工智能
- [ ] **合规文件？** — 确认人工智能工具符合数据处理要求

> [!note] 香港特定 — 《个人资料（私隐）条例》资料保障原则第 3 原则：  
> 为某一目的收集的个人信息，未经同意不得用于实质上不同的目的。  
> 即使数据留在你的组织内，将客户的个人信息输入人工智能工具也可能违反《个人资料（私隐）条例》。  
> 如有疑问 — 请勿输入个人信息。

---

### P3 · 证明 — 我能否验证、追踪并对人工智能的产出负责？

- [ ] **阅读完整输出** — 在任何工作环境中使用之前
- [ ] **能够为之背书？** — 如果被质疑时感到舒适
- [ ] **验证声明** — 事实、数字、引用、法律参考已检查
- [ ] **预期错误** — 人工智能可能自信地产生幻觉；我知道这一点
- [ ] **能够解释？** — 能够向我的经理或客户说明人工智能协助了什么

> [!warning] 「人工智能说的」不是借口：  
> 你对所提交的工作负责。如果人工智能产生了你未发现的错误，该错误就是你的责任。  
> 生成内容的员工是负责人，并负责事实核查和质量控制。

#### 幻觉警告信号 — 相信前验证

在使用或分享任何人工智能输出前验证

- [ ] **统计数据无来源** — 具体数字但无指明出处：使用前搜索原始来源
- [ ] **网址或参考文献** — 检查任何链接或引用是否真实存在且指向所声称的位置
- [ ] **具名个人** — 人工智能可能捏造传记细节：从官方来源验证
- [ ] **香港法律或法规** — 香港特定规则在人工智能中经常出错：在 gov.hk 或 elegislation.gov.hk 验证
- [ ] **100% 自信语气** — 输出中无不确定性或免责声明：这是一个警告信号，而非保证

## 3. 特定工作场景

### 发送邮件给客户或外部方
- [ ] **完整阅读** — 不仅仅是接受并发送
- [ ] **准确详情** — 客户姓名、数字和承诺已验证
- [ ] **正确语气** — 适合关系和背景
- [ ] **无机密数据** — 提示词中未包含敏感内容
- [ ] **披露已检查** — 考虑是否需按政策披露人工智能协助

### 摘要文件或报告
- [ ] **准确性已检查** — 摘要已与原始文件验证
- [ ] **关键数字保留** — 决策、数字、门槛和免责声明未遗失
- [ ] **无受限内容** — 文件未包含机密或受限信息

### 使用人工智能进行研究或分析
- [ ] **来源已验证** — 声明和统计数据已与原始来源检查
- [ ] **无合规依赖** — 不依赖人工智能得出法律、监管或合规结论
- [ ] **标注人工智能协助** — 如果在内部分享，输出应明确标注

### 会议纪要和纪录
- [ ] **准确性已审核** — 纪要在传阅前已检查
- [ ] **正确归属** — 姓名和行动负责人正确分配
- [ ] **无敏感内容** — 会议未涉及人力资源、法律或牧养事项
- [ ] **人手摘要** — 敏感讨论由人手撰写，而非人工智能

### 翻译
- [ ] **双语审核员** — 合格审核员在外部使用前已检查
- [ ] **香港术语** — 法律、财务或技术术语已与官方香港来源验证
- [ ] **语气不变** — 人工智能未加强、弱化或改变超出原始材料的语气

## 4. 代理式及自动化人工智能（较高风险）

> 以下两节适用于你的组织使用自动化人工智能工具或涉及个人人工智能账户的情况。  
>  
> 如果均不适用于你当前的任务，请跳至第 6 节。

如果你的组织正在使用可以采取行动的人工智能工具 — 发送邮件、更新记录、预约会议、提交表格：

- [ ] **了解权限** — 人工智能获准代表我采取哪些行动？
- [ ] **了解批准** — 哪些行动需要我先明确批准？
- [ ] **人工审核关口** — 在任何面向外部的行动之前存在审核步骤
- [ ] **可以暂停或撤销** — 如果出现问题，有方法停止或撤销人工智能的行动
- [ ] **行动已记录** — 人工智能的行动已记录并可审计

> [!warning] 代理式人工智能可以在你注意到之前采取行动：  
> 如果人工智能工具可以发送消息、提交表格或更新数据，请假设它会这样做 — 在启用之前设置明确界限。

---

## 5. 影子人工智能（将个人工具用于工作）

影子人工智能意指将个人人工智能订阅（个人 ChatGPT、Claude 免费账户等）用于工作任务。

- [ ] **仅消费者条款** — 个人人工智能账户不受企业保护
- [ ] **无工作数据** — 不使用个人人工智能工具处理客户数据或机密信息
- [ ] **训练风险** — 个人账户可能将输入用于人工智能训练
- [ ] **提出，而非绕过** — 如果需要更好的工具，向经理提出；不要使用个人账户绕过限制

---

## 6. 输出归档与问责

对于高风险或决策支援任务：

- [ ] **日志已保存** — 提示词和输出已保存到内部记录
- [ ] **完全负责** — 准备好承担专业责任，如同我自己撰写一样
- [ ] **第二审核** — 如果影响客户关系或正式决策，已由第二人审核

---

## 7. 如果出现问题

如果人工智能产生了已经发送、使用或提交的错误：

- **告知经理** — 立即；不要试图独自悄悄修复
- **保留记录** — 保留已发送的内容和错误是什么
- **评估影响** — 谁收到了它，可能影响了哪些决策
- **纠正** — 通过适当渠道尽快纠正
- **从中学习** — 哪个审核步骤本应发现此问题？

如果个人信息可能已通过人工智能工具意外泄露 — 这可能触发《个人资料（私隐）条例》的通知义务。立即向你的经理或合规联系人报告。

## 8. 快速参考

| 情况 | 应该怎么做 |
|------|----------|
| **不确定人工智能是否允许** | 在使用人工智能前询问你的经理 |
| **即将贴上客户数据** | 停止 — 使用匿名示例或公司批准的工具 |
| **人工智能给出错误答案** | 不要使用它；向你的经理报告 |
| **人工智能代表你采取行动** | 检查已发送的内容；如果错误，通知你的经理 |
| **无人工智能政策存在** | 使用本检查清单；标记需要政策 |
| **香港法律或合规** | 在官方香港来源验证；涉及律师 |

## 9. 工作中不适合人工智能 — 始终使用人手

- **就业决策** — 影响薪酬、纪律或就业状态
- **法律建议** — 合同诠释或合规签署
- **财务承诺** — 批准和财务决策
- **医疗决策** — 临床判断
- **客户承诺** — 未经人工审核
- **牧养关怀** — 辅导或敏感个人对话

---

## 10. 高风险类别 — 始终格外谨慎

某些输出类型无论任务多么简单都带有较高风险。在使用或分享前验证这些：

| 类别 | 风险 | 规则 |
|------|------|------|
| **圣经／神学** | 看似合理但神学上错误的内容 | 直接在圣经中验证；咨询你的牧师 |
| **法律／监管** | 香港特定法律在人工智能中经常出错 | 在 gov.hk、elegislation.gov.hk 或律师处验证 |
| **财务／投资** | 可能过时或不适用于香港 | 与持牌顾问或证监会／金管局来源验证 |
| **具名个人** | 人工智能可能捏造传记细节 | 从该人士的官方简介或联系方式验证 |
| **近期事件** | 人工智能训练有截止日期 | 搜索即时新闻来源 |
| **教会／组织通讯** | 可能影响关系或声誉 | 发送前进行人手牧养或管理审核 |

---

## 11. 一分钟最终检查

在使用、发送或发布任何人工智能协助创建的内容之前：

- **目的** — 人工智能是否是此任务的正确工具？
- **权限** — 我是否将敏感信息排除在提示词之外？
- **证明** — 我是否已阅读此内容、检查关键声明，并能够为之背书？

如果三者都是「是」— 你已经做了最低限度的负责任之事。
