## 1. 目的
> [!note] 請調整此開首句以反映您機構特定的信仰承諾與價值觀。

我們相信科技應當服事人並榮耀神。人工智能工具為行政效率、溝通及學習帶來真實益處。善用它們，可以騰出時間專注事工；粗心使用，則可能損害信任、破壞保密性，並以似是而非的事物取代真正的人手關懷。

本政策旨在幫助我們的職員及義工：

- **明智使用人工智能** — 在清晰且共識的界限內
- **保護私隱** — 尊重我們所服事的每個人的尊嚴
- **維護誠信** — 確保我們的事工及溝通的完整性
- **牧養關懷保持由人參與** — 靈性導引與神學教導，專屬蒙召的牧者
- **履行法律義務** — 遵守香港《個人資料（私隱）條例》（第 486 章）

本政策並不禁止使用人工智能。它確立界限，使人工智能的使用方式符合我們的價值觀、法律義務，以及對神託付給我們之人的關顧責任。

## 3. 我們的管治原則

本機構內所有人工智能使用均受以下原則管轄：

| 原則 | 實踐中的含義 |
|------|-------------|
| **人工審核屬強制性** | 任何人工智能輸出在使用、發布、發送或分發前，必須經人手閱讀並批准。速度永遠不是跳過此步驟的理由。 |
| **牧養關懷保持由人參與** | 人工智能在牧養輔導、祈禱事工、靈性指引或任何形式的人靈魂關顧中沒有角色。這些需要真實的人手參與 — 永遠如此。 |
| **神學教導保持由人參與** | 人工智能絕不可被定位為神學權威的來源。聖經詮釋、教義指引及靈性教導屬於蒙召且需負責的牧者。 |
| **個人資料受保護** | 會友、訪客或受益人的個人資料在任何情況下均不得輸入公共人工智能工具。 |
| **真理優先於速度** | 發送或發布的人工智能輔助內容代表我們機構。準確性比效率更重要。我們不會在未閱讀的情況下發布人工智能輸出。 |
| **保持誠實** | 我們不使用人工智能創建欺騙性內容 — 包括人工智能生成的語音、圖像或文本，誤導他人關於我們的領導層、教義或所服事的人。 |

## 6. 禁止的使用案例 — 紅線

以下使用在任何情況下均不允許。這些 **「紅線」** 旨在保護我們的會眾、事工及機構誠信：

- [ ] **透過人工智能進行牧養關懷** — 人工智能絕不可用於提供輔導、祈禱支援、靈性指引或任何形式的牧養關懷。這些需要真實的人手關係。
- [ ] **人工智能進行神學教導** — 人工智能絕不可被呈現為神學權威或聖經詮釋的來源。人工智能產生的神學內容必須明確標註為人工智能生成，並在用於任何用途前經合資格牧者審閱。
- [ ] **公共人工智能工具中的個人資料** — 會友姓名、聯絡詳情、身份證號碼、健康資訊、財務詳情、祈禱事項、輔導筆記，或任何關於個人的資訊，絕不得輸入公共人工智能工具。
- [ ] **機密牧養記錄** — 輔導記錄、個人披露及牧養關懷檔案絕不得與任何人工智能系統分享。
- [ ] **自動化對外通訊** — 人工智能絕不可在未經每則訊息人工審閱及批准的情況下，向會友、訪客或公眾發送任何通訊。
- [ ] **受益人資格決定** — 人工智能絕不可做出或建議關於某人獲得關顧、財務協助或事工參與的決定。
- [ ] **欺騙性人工智能生成內容** — 誤導我們領導層或捏造真實人士言論的人工智能生成語音、圖像或視頻均被禁止。
- [ ] **未經批准的工具** — 未列入第 4 節批准清單的人工智能工具，未經政策負責人事先書面批准，不得用於任何機構相關任務。

## 7. 所有批准使用的必需防護措施

以下防護措施適用於所有批准的人工智能使用：

- [ ] **人工審核** — 每項與會眾成員、公眾或任何外部方分享或影響他們的人工智能輸出，在使用前必須經指定負責人審閱並批准
- [ ] **無敏感資料** — 個人資料、牧養記錄、人力資源數據或機密文件不得輸入公共人工智能工具
- [ ] **《個人資料（私隱）條例》合規** — 如人工智能工具處理任何個人資料，必須先評估《個人資料（私隱）條例》資料保障原則（DPP）第 3 原則的合規性
- [ ] **繁體中文可讀性** — 如使用繁體中文文件，必須在人工智能處理前測試其機器可讀性
- [ ] **來源驗證** — 人工智能輸出中的所有事實、數字、引用及聲明在使用前必須經主要來源驗證
- [ ] **神學審閱** — 任何具有神學、教義或牧養影響的人工智能輔助內容，必須經牧師或長老審閱

## 8. 數據保護與私隱 — 《個人資料（私隱）條例》合規

所有人工智能使用必須遵守香港《個人資料（私隱）條例》（第 486 章）。以下規則屬強制性：

| 《個人資料（私隱）條例》要求   | 我們如何在人工智能使用中合規                                               |
| ---------------- | ------------------------------------------------------------ |
| **DPP 1 — 收集目的** | 我們僅在人工智能工具中使用個人資料，用於與該數據原收集目的一致的用途 — 且僅在明確允許的情況下             |
| **DPP 3 — 使用限制** | 為事工目的收集的個人資料（例如活動報名），不得在未經該人知情或同意的情況下，通過人工智能工具用於不同目的（例如通訊分析） |
| **DPP 4 — 數據安全** | 個人資料不得輸入公共人工智能工具。僅匿名化或非個人資訊可用於人工智能輔助任務                       |
| **DPP 5 — 公開性**  | 職員及義工獲告知本政策及本機構如何使用人工智能工具                                    |

> [!warning] 在任何涉及會友或受益人數據的任務中使用人工智能前，請詢問： **這些數據是否為包含人工智能處理的目的而收集？** 如否，則不得使用。如不確定在人工智能工具中使用特定個人資料是否符合《個人資料（私隱）條例》許可 — 請不要繼續。先諮詢政策負責人。

## 9. 人工審核與品質控制

人工審核並非可選。它是所有人工智能輔助輸出的硬性要求。

| 輸出類型             | 所需審核者       | 時機     |
| ---------------- | ----------- | ------ |
| 對外通訊（電郵、通訊、社交媒體） | 負責事工領袖或溝通團隊 | 發送或發布前 |
| 內部通知及備忘錄         | 發送職員或義工     | 發送前    |
| 會議摘要及記錄          | 會議主席或秘書     | 分發前    |
| 義工材料及入職文件        | 營運經理或事工領袖   | 與義工分享前 |
| 翻譯內容             | 雙語職員或合資格審核員 | 發布或發送前 |
| 神學或聖經相關內容        | 主任牧師或指定牧者   | 在任何使用前 |

審核者負責：

- **完整閱讀** — 不僅僅是略讀
- **驗證所有事實** — 姓名、日期及數字
- **糾正錯誤** — 在內容使用前
- **承擔責任** — 對最終內容負責，如同他們自己撰寫一樣

## 10. 影子人工智能（將個人工具用於教會任務）

影子人工智能意指將個人人工智能訂閱用於教會任務，繞過機構批准的工具。

- [ ] **僅消費者條款** — 個人人工智能帳戶不受企業保護
- [ ] **無教會數據** — 個人人工智能工具不得用於涉及會友數據或機密教會資訊的任務
- [ ] **訓練風險** — 個人帳戶可能使用輸入進行人工智能訓練
- [ ] **提出，而非繞過** — 如需要更好的工具，請向政策負責人提出；不要使用個人帳戶繞過缺口

## 11. 訓練退出要求

許多人工智能工具默認使用輸入進行模型訓練。當使用任何人工智能工具進行機構相關任務時：

- [ ] **檢查默認設定** — 您批准的工具是否允許輸入用於訓練？
- [ ] **如可能則退出** — 在將工具用於任何機構內容前退出
- [ ] **如無退出選項則不使用** — 如無法退出，則不要將該工具用於任何包含機構資訊的內容

這尤其適用於用於教會任務的免費或個人人工智能帳戶。

## 12. 報告與違規管理

職員或義工必須立即向政策負責人報告以下情況：

- **未經審閱的輸出已分享** — 任何人工智能輸出在所需人工審核前已分享或據此行動
- **個人資料外洩** — 任何個人資料意外輸入公共人工智能工具
- **政策違規** — 任何可能違反本政策或適用法律的人工智能使用
- **未涵蓋的情況** — 任何關於本政策未涵蓋的人工智能使用的疑慮

報告將以保密方式處理，如屬善意提出疑慮則不予責備。

如個人資料可能已通過人工智能工具意外外洩，這可能觸發《個人資料（私隱）條例》下的通知義務。政策負責人將決定是否需要通知個人資料私隱專員公署（PCPD）。

## 13. 如果出現問題

如人工智能產生已與會眾成員或公眾分享的錯誤：

1. **通知領導層** — 立即；不要試圖悄悄糾正
2. **透明行動** — 不試圖悄悄修復
3. **《個人資料（私隱）條例》評估** — 如涉及個人資料，評估違規通知義務
4. **及時糾正** — 通過適當渠道盡快糾正
5. **更新流程** — 審閱哪個防護措施本應捕捉此問題

## 15. 政策審閱

本政策將審閱：

- **年度審閱** — 至少每 12 個月一次
- **建議新工具** — 每當出現重大新人工智能工具或使用案例時
- **法律變更** — 當香港法律或監管指引發生相關變更時
- **範圍變更** — 當機構內人工智能使用範圍發生重大變更時
- **事件後** — 跟隨任何重大人工智能相關事件後

政策負責人負責啟動及管理每次審閱。

## 附錄 B — 職員及義工快速參考
