## 1. 目的

人工智能工具為效率、溝通及許多工作任務的質素帶來真實益處。善用它們，可以騰出時間專注重要的工作；粗心使用，則可能造成損害 — 包括數據私隱違規、客戶通訊的事實錯誤、保密失效，以及聲譽或監管風險。

本政策旨在幫助我們的職員及同事：

- **明智使用人工智能** — 在清晰且共識的界限內
- **保護私隱** — 我們的客戶、會友及所服事的人
- **維護誠信** — 我們的溝通及專業聲譽
- **專業判斷保持由人負責** — 影響人員權利、僱傭或福利的決定屬於負責的職員
- **履行法律義務** — 遵守香港《個人資料（私隱）條例》（第 486 章）

本政策並不禁止使用人工智能。它確立界限，使人工智能的使用方式符合我們的價值觀、法律義務，以及對所服事之人的關顧責任。

## 3. 我們的管治原則

本機構內所有人工智能使用均受以下原則管轄：

| 原則 | 實踐中的含義 |
|------|-------------|
| **人工審核屬強制性** | 每個用於業務的人工智能輸出在使用前必須經負責職員審閱並驗證。速度永遠不是跳過此步驟的理由。 |
| **客戶數據受保護** | 客戶個人資料、機密資訊及未發布的業務數據絕不得輸入公共人工智能工具。 |
| **準確性優先於速度** | 發送至客戶或用於業務決策的人工智能輔助內容代表我們機構。準確性比效率更重要。我們不會在未閱讀的情況下使用人工智能輸出。 |
| **準確性是職員的責任** | 使用或發送人工智能輔助內容的職員對其準確性負責 — 無論其如何產生。「人工智能寫的」不是有效的專業辯護。 |
| **僅批准的工具** | 僅機構批准清單上的人工智能工具可用於業務任務，除非已獲得政策負責人的事先書面批准。 |
| **《個人資料（私隱）條例》合規不容妥協** | 所有人工智能使用必須遵守香港《個人資料（私隱）條例》（第 486 章）。 |

## 6. 禁止的使用案例 — 紅線

以下使用在任何情況下均 **不允許**。這些 **「紅線」** 旨在保護我們的機構誠信：

- [ ] **公共人工智能工具中的客戶個人資料** — 客戶姓名、身份證號碼、聯絡詳情、財務詳情、健康資訊，或任何個人資料絕不得輸入公共或個人人工智能工具。
- [ ] **未經批准工具中的機密業務資訊** — 商業秘密、未發布財務數據、客戶合約、定價策略或專有業務資訊不得輸入任何未經批准的人工智能工具。
- [ ] **自動化客戶通訊** — 人工智能絕不可在未經每則訊息人工審閱及批准的情況下，向客戶或外部方發送任何通訊。
- [ ] **人工智能輔助的個人決定** — 招聘決定、紀律事項、績效評估，或信貸/資格評估不得在無人手判斷及問責的情況下由人工智能做出或建議。
- [ ] **未經審閱的法律或合規文件** — 法律文件、合規認證、監管提交及稅務申報不得在未經合格人工審閱及簽署的情況下由人工智能生成。
- [ ] **生成誤導性內容** — 人工智能絕不可用於捏造報價、誤述能力或資質，或創建欺騙客戶或夥伴的內容。
- [ ] **未經批准的工具** — 未列入第 4 節批准清單的人工智能工具，未經政策負責人事先書面批准，不得用於任何業務目的。

## 7. 所有批准使用的必需防護措施

以下防護措施適用於所有批准的人工智能使用：

- [ ] **人工審核** — 每項與任何外部方分享或影響他們的人工智能輸出，在使用前必須經指定負責人審閱並批准
- [ ] **無敏感資料** — 個人資料、人力資源數據或機密文件不得輸入公共人工智能工具
- [ ] **《個人資料（私隱）條例》合規** — 如人工智能工具處理任何個人資料，必須先評估《個人資料（私隱）條例》資料保障原則（DPP）第 3 原則的合規性
- [ ] **繁體中文可讀性** — 如使用繁體中文文件，必須在人工智能處理前測試其機器可讀性
- [ ] **來源驗證** — 人工智能輸出中的所有事實、數字、引用及聲明在使用前必須經主要來源驗證
- [ ] **專業審核** — 任何具有法律、合規或監管影響的人工智能輔助內容，必須經合資格專業人士審核

## 8. 數據保護與私隱 — 《個人資料（私隱）條例》合規

所有人工智能使用必須遵守香港《個人資料（私隱）條例》（第 486 章）。以下規則屬強制性：

| 《個人資料（私隱）條例》要求 | 我們如何在人工智能使用中合規 |
|---------------------------|---------------------------|
| **DPP 1 — 公共人工智能工具中無個人資料** | 客戶或職員個人資料不得輸入任何公開可訪問的人工智能工具。這包括姓名、聯絡詳情、身份證號碼、財務資訊及健康數據。 |
| **DPP 3 — 使用限制** | 為某一業務目的收集的個人資料（例如客戶入職），未經該人知情或同意，不得通過人工智能工具用於不同目的。 |
| **DPP 4 — 數據最小化** | 當使用人工智能進行起草或分析時，使用完成任務所需的最少數據。如可能，匿名化或移除個人識別資訊。 |
| **DPP 4 — 輸出安全** | 包含任何客戶或職員資訊的人工智能生成輸出，必須以與其他業務記錄相同的保密標準處理。 |
| **DPP 4 — 違規報告** | 任何個人資料意外輸入公共人工智能工具必須立即報告給政策負責人。 |

> [!warning] 如不確定特定人工智能使用是否符合《個人資料（私隱）條例》— 請不要繼續。在繼續前先尋求政策負責人或合資格私隱專業人士的指引。

---

### 數據分類 — 在輸入任何內容到人工智能之前

在使用任何數據於人工智能工具前，使用此表進行分類：

| 分類 | 示例 | 我可以在人工智能中使用此數據嗎？ |
|------|------|------------------------------|
| **公開** | 已發布資訊、營銷材料、公開公告 | 一般可以 — 僅限批准的工具 |
| **內部** | 內部程序、非敏感備忘錄、一般機構資訊 | 可以 — 僅限批准的工具 |
| **機密** | 客戶數據、合約、財務詳情、業務策略、定價 | 不可以 — 不得在公共人工智能工具中使用 |
| **受限 / 敏感** | 個人資料（香港身份證、健康、薪金）、密碼、法律事項、合規檔案 | 絕不可以 |

**公告欄規則：** 在將任何資訊輸入人工智能工具前，詢問：我會願意將此資訊寫在公共公告欄上嗎？如否 — 不要輸入。

## 9. 人工審核與品質控制

人工審核並非可選。它是所有人工智能輔助輸出的硬性要求。

| 輸出類型         | 所需審核者         | 時機      |
| ------------ | ------------- | ------- |
| 客戶電郵及通訊      | 發送職員          | 每次發送前   |
| 客戶報告、提案及演示文稿 | 作者 + 經理（重大輸出） | 交付客戶前   |
| 內部文件及通知      | 發送職員          | 分發前     |
| 會議摘要及記錄      | 會議組織者或秘書      | 分享前     |
| 財務數據提取       | 財務團隊成員        | 記錄任何內容前 |
| 翻譯內容         | 雙語職員或合資格審核員   | 發布或發送前  |
| 法律或合規相關內容    | 合資格專業人士       | 任何使用前   |

審核者負責：

- **完整閱讀** — 不僅僅是略讀
- **驗證所有事實** — 姓名、日期及數字
- **糾正錯誤** — 在內容使用前
- **承擔責任** — 「人工智能寫的」不是客戶面向內容錯誤的可接受解釋

## 10. 影子人工智能（將個人工具用於工作任務）

影子人工智能意指將個人人工智能訂閱用於工作任務，繞過機構批准的工具。

- [ ] **僅消費者條款** — 個人人工智能帳戶不受企業保護
- [ ] **無工作數據** — 個人人工智能工具不得用於涉及客戶數據或機密機構資訊的任務
- [ ] **訓練風險** — 個人帳戶可能使用輸入進行人工智能訓練；創建機構無法控制的數據駐留、訓練及保密風險
- [ ] **提出，而非繞過** — 如需要更好的工具，請向經理提出；不要使用個人帳戶繞過缺口

## 11. 訓練退出要求

許多人工智能工具默認使用輸入進行模型訓練。當使用任何人工智能工具進行機構相關任務時：

- [ ] **檢查默認設定** — 您批准的工具是否允許輸入用於訓練？
- [ ] **如可能則退出** — 在將工具用於任何業務內容前退出
- [ ] **如無退出選項則不使用** — 如無法退出，則不要將該工具用於任何包含機構資訊的內容

這尤其適用於用於業務任務的免費或個人人工智能帳戶。

## 12. 報告與違規管理

職員必須立即向政策負責人報告以下情況：

- **未經審閱的輸出已發送** — 任何人工智能輸出在所需人工審核前已發送給客戶或發布
- **個人資料外洩** — 任何個人資料意外輸入公共人工智能工具
- **政策違規** — 任何可能違反本政策或適用法律的人工智能使用
- **客戶疑慮** — 任何與人工智能生成內容相關的客戶投訴或疑慮

善意提出的報告將不予責備。報告的目的是識別及糾正問題 — 而非懲罰提出疑慮的職員。

如可能發生《個人資料（私隱）條例》違規，政策負責人將決定是否需要通知個人資料私隱專員公署（PCPD）並管理該流程。

## 13. 如果出現問題

如人工智能產生已發送給客戶或用於業務決策的錯誤：

1. **告知經理** — 立即；不要試圖獨自悄悄修復
2. **保留記錄** — 保留已發送的內容及錯誤是什麼
3. **評估影響** — 誰收到了它，可能影響了哪些決策
4. **及時糾正** — 通過適當渠道盡快糾正
5. **更新流程** — 審閱哪個防護措施本應捕捉此問題

---

## 14. 不合規的後果

> [!note] 根據您機構的紀律框架及僱傭安排進行調整。義工或政府組織應就其背景下適當的後果語言尋求人力資源或法律意見。

違反本政策的職員 — 無論故意或疏忽 — 可能受到紀律處分，最高可至終止僱傭，取決於違規的嚴重性及性質。

導致數據私隱事件、客戶傷害或監管調查的違規，也可能使機構面臨法律責任及監管行動。

---

## 15. 政策審閱

本政策將審閱：

- **年度審閱** — 至少每 12 個月一次
- **建議新工具** — 每當出現重大新人工智能工具或使用案例時
- **法律變更** — 當香港法律或監管指引發生相關變更時
- **範圍變更** — 當機構內人工智能使用範圍發生重大變更時
- **事件後** — 跟隨任何重大人工智能相關事件後

職員可隨時向政策負責人提交政策改進建議。

## 附錄 B — 職員快速參考

**在使用人工智能進行任何工作任務前，詢問：**
