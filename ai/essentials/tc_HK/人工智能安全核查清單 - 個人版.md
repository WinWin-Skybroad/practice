# 人工智能安全核查清單 — 個人版

> [!info] 使用記錄：  
>  
> **任務：** （例如：教會通訊起草、會議紀要摘要）  
> **日期：**  
> **使用的人工智能工具：**  
> **填寫人：**   

> [!quote] 為何重要  
> 人工智能工具功能強大 — 但也容易因意外而被誤用。  
>  
> 本核查清單幫助你保護自己、你的資料，以及你所服事的人。  
> 每次嘗試新的人工智能工具或任務時使用它。

> 將人工智能輸出視為起草引擎，而非真相引擎。  
> 每個輸出在到達任何重要的人或事物之前，都需要人手閱讀。

**適用對象：** 任何個人使用人工智能工具的人士 — 用於工作、學習、事工支援、義工服務或副業項目。

**重要提示：** 「較安全的人工智能使用」意指減少常見風險。這並**不**保證安全、準確或合規。

---

## 1. 開始前（3P 檢查）

### P1 · 目的 — 這是否適合人工智能處理的任務？

- [ ] **目的清晰？** — 人工智能究竟會產出什麼、給誰使用，而你仍會自行決定什麼？
- [ ] **任務類型正確？** — 文字密集型、重複性或資訊類任務；非高風險判斷
- [ ] **工具正確？** — 還是人手更合適？
- [ ] **風險檢查** — 人工智能在此是降低風險，還是創造新風險？
- [ ] **人工審核輸出** — 我將在使用前審核它
- [ ] **指定負責人？** — 誰對此輸出負責？
- [ ] **加速，而非逃避** — 使用人工智能加快起草，而非免除我的責任
- [ ] **不涉及人員決策** — 不影響健康、財務、安全或法律狀態

> [!warning] 如果你即將讓人工智能對他人做出決策，請停止：  
> 醫療、財務、法律、牧養和福利決策需要真人 — 而非語言模型。

---

### P2 · 權限 — 我可以將什麼資料輸入此工具？

- [ ] **已批准的工具？** — 適合此任務和資料類型的正確工具
- [ ] **了解限制** — 此工具不允許使用哪些資料？
- [ ] **《個人資料（私隱）條例》檢查** — 此資料是否允許用於人工智能處理？香港的《個人資料（私隱）條例》（第 486 章）規定，為某一目的收集的個人資料未經評估不得用於另一目的。如有疑問，請勿輸入個人資料。
- [ ] **私隱政策已檢查** — 該工具是否允許此類資料？
- [ ] **無個人資料** — 不貼上姓名、身份證號碼、地址、電話、健康或財務詳情
- [ ] **無機密內容** — 不貼上牧養記錄、客戶記錄或敏感資訊
- [ ] **無憑證** — 不貼上密碼、應用程式編程介面（API）密鑰或登入詳情
- [ ] **最小資料** — 僅使用完成此任務所需的最少資料
- [ ] **盡可能匿名化** — 移除姓名和識別資訊
- [ ] **訓練退出** — 檢查私隱設定；了解哪些資料會被儲存或用於訓練

> [!note] 簡單規則：  
> 如果您不願意將其寫在明信片上並留在公共公告欄上，就不要將其輸入公共人工智能工具。

---

### P3 · 證明 — 我能否驗證並對人工智能的產出負責？

- [ ] **閱讀完整輸出** — 在到達任何人之前
- [ ] **能夠為之背書？** — 如果被質疑時感到舒適
- [ ] **驗證聲明** — 統計數據、日期、姓名和引用已驗證
- [ ] **保留記錄** — 重要任務記錄提示詞和輸出
- [ ] **能夠解釋？** — 能夠用通俗語言說明為何此輸出足夠好
- [ ] **能夠糾正？**— 如果出現問題，能否快速解釋並修復？
- [ ] **預期錯誤** — 人工智能可能自信地產生幻覺；我知道這一點。

> [!note] 流暢不等於正確。

> [!important] 責任測試：  
> 我是否願意在此輸出上署名並解釋人工智能協助產生了什麼？  
> 如果是 — 您已經做得足夠。如果否 — 請進一步檢查。

## 2. 人工智能回應後：幻覺警告信號

留意以下情況，並在信任任何內容前進行驗證：

- [ ] **統計數據，無來源** — 具體數字但無指明出處
- [ ] **引用是否存在？** — 論文、案例或參考文獻：檢查它是否真實存在
- [ ] **網址是否有效？** — 檢查它是否指向所聲稱的位置
- [ ] **近期事件？** — 人工智能訓練有截止日期
- [ ] **香港法律聲明？** — 香港特定規則在人工智能輸出中經常出錯
- [ ] **100% 自信語氣** — 無不確定性或免責聲明：這是一個警告信號
- [ ] **流暢但無證據** — 聽起來權威但無具體內容支持

> [!warning] 紅旗 — 停止並重新考慮：  
> 如果出現以下情況，請停止並放慢速度：
> - **影響他人權利** — 資格、聲譽、財務或福祉
> - **需要專業判斷** — 法律、醫療、財務、人力資源、牧養或合規
> - **無意中包含資料** — 個人或機密內容出現在輸出中
> - **被催促信任它** — 看起來流暢且自信：仍需驗證
> - **無法解釋它** — 無法說明來源、限制或可靠性
> - **無進一步審核** — 其他人將依賴此輸出而無任何檢查

---

### 2.1 三分鐘事實核查習慣

當你發現上述警告信號時 — 或在分享任何重要內容之前 — 花三分鐘：

- **懷疑問題（30 秒）** — 問人工智能：「你可能會在哪裡出錯？」
- **搜尋一項聲明（60 秒）** — 在搜尋引擎或官方來源中搜尋最具體的聲明
- **詢問真人（60 秒）** — 如果影響他人，在採取行動前驗證

## 3. 保護你的帳戶和裝置

> 這些是一次性設定檢查 — 不需要每次人工智能任務都執行。首次使用新工具或每隔幾個月檢視一次。

- [ ] **獨特密碼** — 與銀行或工作帳戶不同
- [ ] **雙重認證** — 在經常使用的人工智能工具上啟用
- [ ] **不保持登入** — 不要在共用或公共電腦上保持登入狀態
- [ ] **設定已檢視** — 檢查私隱設定；了解哪些資料會被儲存
- [ ] **訓練退出** — 如果不想讓資料用於訓練，請選擇退出

---

## 4. 在我分享或發布任何內容之前

- [ ] **完整輸出已閱讀** — 不僅僅是開頭
- [ ] **自己的聲音** — 編輯以反映我自己的聲音；糾正錯誤
- [ ] **語氣和影響** — 檢查準確性及對他人的影響
- [ ] **移除誤導內容** — 移除任何過度自信、令人尷尬或有害的內容
- [ ] **能夠負責** — 如果是我自己寫的，我會感到舒適
- [ ] **考慮披露** — 如果人工智能有實質性協助，考慮是否註明

---

## 5. 快速參考

| 情況 | 應該怎麼做 |
|------|----------|
| **人工智能給出統計數據** | 在使用前搜尋原始來源 |
| **人工智能給出網址** | 檢查連結是否真實存在且有效 |
| **人工智能提及真人** | 從官方來源驗證 |
| **即將貼上個人資料** | 停止 — 改用匿名示例 |
| **發送輸出給外部方** | 完整閱讀；編輯；人手簽署確認 |
| **香港法律或法規** | 在 elegislation.gov.hk 驗證或與律師確認 |
| **不確定人工智能是否合適** | 問：「如果此輸出錯誤而我據此行動會怎樣？」 |

---

## 6. 不適合人工智能 — 始終使用人手

- **醫療決策** — 診斷或治療
- **法律建議** — 合約或合規裁定
- **財務決策** — 投資選擇
- **牧養關懷** — 輔導或靈性指導
- **高影響決策** — 顯著影響他人生活
- **「人工智能說的」** — 任何以此作為解釋不可接受的任務

---

## 7. 高風險類別 — 始終格外謹慎

| 類別 | 風險 | 規則 |
|------|------|------|
| **醫療／健康** | 錯誤劑量、診斷或治療 | 與醫生或藥劑師驗證 |
| **法律／監管** | 香港特定法律在人工智能中經常出錯 | 在 gov.hk、elegislation.gov.hk 或律師處驗證 |
| **財務／投資** | 可能過時或不適用於香港 | 與持牌顧問或證監會／金管局來源驗證 |
| **聖經／神學** | 看似合理但神學上錯誤的內容 | 直接在聖經中驗證；諮詢你的牧師 |
| **具名個人** | 人工智能可能捏造傳記細節 | 從該人士的官方簡介或聯絡方式驗證 |
| **近期事件** | 人工智能訓練有截止日期 | 搜尋即時新聞來源 |
| **教會通訊** | 可能影響關係或聲譽 | 發送前進行人手牧養審核 |

---

## 8. 一分鐘最終檢查

在使用、發送或發布任何人工智能協助創建的內容之前：

- **目的** — 人工智能是否是此任務的正確工具？
- **權限** — 我是否將敏感資料排除在提示詞之外？
- **證明** — 我是否已閱讀此內容、檢查關鍵聲明，並能夠為之背書？

如果三者都是「是」— 你已經做了最低限度的負責任之事。
