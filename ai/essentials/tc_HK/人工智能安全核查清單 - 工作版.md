# 人工智能安全核查清單 — 工作版

> [!info] 使用記錄：  
>  
> **任務：** （例如：教會通訊起草、會議紀要摘要）  
> **日期：**  
> **使用的人工智能工具：**  
> **填寫人：**  

> [!quote] 為何在工作中重要：  
> 在工作中使用人工智能會帶來個人使用時可能沒有的責任。  
> 你正在處理機構的資訊、客戶的信任，以及你的專業聲譽。  
> 「人工智能說的」不是專業辯護。你對所提交的內容負責。  
>  
> 本核查清單幫助你在工作環境中安全地使用人工智能，符合機構規則，並能夠為此負責。  
> 每次嘗試新的人工智能工具或任務時使用它。  

> 將人工智能輸出視為起草引擎，而非真相引擎。  
> 每個輸出在到達任何重要的人或事物之前，都需要人手閱讀。

**適用對象：** 在任何工作環境中使用人工智能工具的職員、合約員工及義工。

**重要提示：** 「較安全的人工智能使用」意指減少常見風險。這並**不**保證安全、準確或合規。

---

## 1. 首先了解你機構的規則

- [ ] **了解政策** — 是否有人工智能使用政策？
- [ ] **已批准的工具** — 哪些人工智能工具獲批准用於工作？
- [ ] **允許的任務** — 哪些任務可由人工智能協助，哪些是禁止的？
- [ ] **有問題問誰** — 如果對特定人工智能使用有疑問，我應向誰查詢？

> [!important] 如果你的機構尚未有人工智能政策：  
> 在政策存在之前，將本核查清單作為你的個人標準。  
> 向你的經理提出需要制定政策。你可以分享 Win.Win@Skybroad 的《人工智能使用政策》模板作為起點。

---

## 2. 每次工作任務前（3P 檢查）

### P1 · 目的 — 這是否適合在工作中使用人工智能的任務？

- [ ] **目的清晰？** — 起草、摘要、研究或翻譯
- [ ] **人工審核輸出** — 在影響任何人或任何事物之前
- [ ] **非決策** — 我不是使用人工智能做出屬於人手的決策
- [ ] **符合政策** — 使用案例符合我機構允許的範圍
- [ ] **了解成本** — 清楚錯誤輸出可能意味著什麼

> [!warning] 人工智能是起草和支援工具 — 而非決策者：  
> 關於人員、合約、合規和客戶承諾的最終決策必須由人手做出。

---

### P2 · 權限 — 我可以在工作中使用哪些資料與人工智能？

**資料分類 — 在將任何資料輸入人工智能工具之前：**

| 分類 | 示例 | 我可以在人工智能中使用此資料嗎？ |
|------|------|------------------------------|
| **公開** | 已發布的政策、公開公告 | 一般可以 — 僅限已批准的工具 |
| **內部** | 內部備忘錄、非敏感程序 | 可以 — 僅限已批准的工具 |
| **機密** | 客戶資料、合約、財務詳情、人力資源記錄 | 不可以 — 不可在公共人工智能工具中使用 |
| **受限／敏感** | 個人資料（身份證、健康、薪金）、密碼、法律事項、牧養記錄 | 絕不可以 |

**絕不可輸入公共或個人人工智能工具的內容：**

- [ ] **客戶個人資料** — 姓名、聯絡方式、帳戶號碼、個人記錄
- [ ] **人力資源記錄** — 薪金、績效數據、員工資訊
- [ ] **機密合約** — 法律協議、受保密協議保護的內容
- [ ] **機密策略** — 業務計劃、財務預測、內部定價
- [ ] **標註為機密** — 任何標註為「機密」、「受限」或「內部」的內容
- [ ] **憑證** — 密碼、應用程式編程介面（API）密鑰、認證令牌
- [ ] **他人的個人資料** — 姓名、香港身份證、地址、電話、電郵、健康、財務
- [ ] **敏感人力資源／牧養** — 人事事項、牧養披露
- [ ] **不願公開？** — 如果我不願公開分享，就不要輸入

> [!note] 簡單規則：  
> 如果您不願意將其寫在明信片上並留在公共公告欄上，就不要將其輸入公共人工智能工具。  
> 這適用於客戶資料、內部財務、策略計劃和個人詳情。

**使用前詢問：**

- [ ] **涉及個人資料？** — 先檢查《個人資料（私隱）條例》合規性
- [ ] **客戶材料？** — 確認你的機構允許在客戶工作中使用人工智能
- [ ] **合規文件？** — 確認人工智能工具符合資料處理要求

> [!note] 香港特定 — 《個人資料（私隱）條例》資料保障原則第 3 原則：  
> 為某一目的收集的個人資料，未經同意不得用於實質上不同的目的。  
> 即使資料留在你的機構內，將客戶的個人資料輸入人工智能工具也可能違反《個人資料（私隱）條例》。  
> 如有疑問 — 請勿輸入個人資料。

---

### P3 · 證明 — 我能否驗證、追蹤並對人工智能的產出負責？

- [ ] **閱讀完整輸出** — 在任何工作環境中使用之前
- [ ] **能夠為之背書？** — 如果被質疑時感到舒適
- [ ] **驗證聲明** — 事實、數字、引用、法律參考已檢查
- [ ] **預期錯誤** — 人工智能可能自信地產生幻覺；我知道這一點
- [ ] **能夠解釋？** — 能夠向我的經理或客戶說明人工智能協助了什麼

> [!warning] 「人工智能說的」不是藉口：  
> 你對所提交的工作負責。如果人工智能產生了你未發現的錯誤，該錯誤就是你的責任。  
> 生成內容的員工是負責人，並負責事實核查和品質控制。

#### 幻覺警告信號 — 相信前驗證

在使用或分享任何人工智能輸出前驗證

- [ ] **統計數據無來源** — 具體數字但無指明出處：使用前搜尋原始來源
- [ ] **網址或參考文獻** — 檢查任何連結或引用是否真實存在且指向所聲稱的位置
- [ ] **具名個人** — 人工智能可能捏造傳記細節：從官方來源驗證
- [ ] **香港法律或法規** — 香港特定規則在人工智能中經常出錯：在 gov.hk 或 elegislation.gov.hk 驗證
- [ ] **100% 自信語氣** — 輸出中無不確定性或免責聲明：這是一個警告信號，而非保證

## 3. 特定工作場景

### 發送電郵給客戶或外部方
- [ ] **完整閱讀** — 不僅僅是接受並發送
- [ ] **準確詳情** — 客戶姓名、數字和承諾已驗證
- [ ] **正確語氣** — 適合關係和背景
- [ ] **無機密資料** — 提示詞中未包含敏感內容
- [ ] **披露已檢查** — 考慮是否需按政策披露人工智能協助

### 摘要文件或報告
- [ ] **準確性已檢查** — 摘要已與原始文件驗證
- [ ] **關鍵數字保留** — 決策、數字、門檻和免責聲明未遺失
- [ ] **無受限內容** — 文件未包含機密或受限資訊

### 使用人工智能進行研究或分析
- [ ] **來源已驗證** — 聲明和統計數據已與原始來源檢查
- [ ] **無合規依賴** — 不依賴人工智能得出法律、監管或合規結論
- [ ] **標註人工智能協助** — 如果在內部分享，輸出應明確標註

### 會議紀要和紀錄
- [ ] **準確性已審核** — 紀要在傳閱前已檢查
- [ ] **正確歸屬** — 姓名和行動負責人正確分配
- [ ] **無敏感內容** — 會議未涉及人力資源、法律或牧養事項
- [ ] **人手摘要** — 敏感討論由人手撰寫，而非人工智能

### 翻譯
- [ ] **雙語審核員** — 合格審核員在外部使用前已檢查
- [ ] **香港術語** — 法律、財務或技術術語已與官方香港來源驗證
- [ ] **語氣不變** — 人工智能未加強、弱化或改變超出原始材料的語氣

## 4. 代理式及自動化人工智能（較高風險）

> 以下兩節適用於你的機構使用自動化人工智能工具或涉及個人人工智能帳戶的情況。  
>  
> 如果均不適用於你當前的任務，請跳至第 6 節。

如果你的機構正在使用可以採取行動的人工智能工具 — 發送電郵、更新記錄、預約會議、提交表格：

- [ ] **了解權限** — 人工智能獲准代表我採取哪些行動？
- [ ] **了解批准** — 哪些行動需要我先明確批准？
- [ ] **人工審核關口** — 在任何面向外部的行動之前存在審核步驟
- [ ] **可以暫停或撤銷** — 如果出現問題，有方法停止或撤銷人工智能的行動
- [ ] **行動已記錄** — 人工智能的行動已記錄並可審計

> [!warning] 代理式人工智能可以在你注意到之前採取行動：  
> 如果人工智能工具可以發送訊息、提交表格或更新資料，請假設它會這樣做 — 在啟用之前設定明確界限。

---

## 5. 影子人工智能（將個人工具用於工作）

影子人工智能意指將個人人工智能訂閱（個人 ChatGPT、Claude 免費帳戶等）用於工作任務。

- [ ] **僅消費者條款** — 個人人工智能帳戶不受企業保護
- [ ] **無工作資料** — 不使用個人人工智能工具處理客戶資料或機密資訊
- [ ] **訓練風險** — 個人帳戶可能將輸入用於人工智能訓練
- [ ] **提出，而非繞過** — 如果需要更好的工具，向經理提出；不要使用個人帳戶繞過限制

---

## 6. 輸出歸檔與問責

對於高風險或決策支援任務：

- [ ] **日誌已保存** — 提示詞和輸出已保存到內部記錄
- [ ] **完全負責** — 準備好承擔專業責任，如同我自己撰寫一樣
- [ ] **第二審核** — 如果影響客戶關係或正式決策，已由第二人審核

---

## 7. 如果出現問題

如果人工智能產生了已經發送、使用或提交的錯誤：

- **告知經理** — 立即；不要試圖獨自悄悄修復
- **保留記錄** — 保留已發送的內容和錯誤是什麼
- **評估影響** — 誰收到了它，可能影響了哪些決策
- **糾正** — 通過適當渠道盡快糾正
- **從中學習** — 哪個審核步驟本應發現此問題？

如果個人資料可能已通過人工智能工具意外洩露 — 這可能觸發《個人資料（私隱）條例》的通知義務。立即向你的經理或合規聯絡人報告。

## 8. 快速參考

| 情況 | 應該怎麼做 |
|------|----------|
| **不確定人工智能是否允許** | 在使用人工智能前詢問你的經理 |
| **即將貼上客戶資料** | 停止 — 使用匿名示例或公司批准的工具 |
| **人工智能給出錯誤答案** | 不要使用它；向你的經理報告 |
| **人工智能代表你採取行動** | 檢查已發送的內容；如果錯誤，通知你的經理 |
| **無人工智能政策存在** | 使用本核查清單；標記需要政策 |
| **香港法律或合規** | 在官方香港來源驗證；涉及律師 |

## 9. 工作中不適合人工智能 — 始終使用人手

- **就業決策** — 影響薪酬、紀律或就業狀態
- **法律建議** — 合約詮釋或合規簽署
- **財務承諾** — 批准和財務決策
- **醫療決策** — 臨床判斷
- **客戶承諾** — 未經人工審核
- **牧養關懷** — 輔導或敏感個人對話

---

## 10. 高風險類別 — 始終格外謹慎

某些輸出類型無論任務多麼簡單都帶有較高風險。在使用或分享前驗證這些：

| 類別 | 風險 | 規則 |
|------|------|------|
| **聖經／神學** | 看似合理但神學上錯誤的內容 | 直接在聖經中驗證；諮詢你的牧師 |
| **法律／監管** | 香港特定法律在人工智能中經常出錯 | 在 gov.hk、elegislation.gov.hk 或律師處驗證 |
| **財務／投資** | 可能過時或不適用於香港 | 與持牌顧問或證監會／金管局來源驗證 |
| **具名個人** | 人工智能可能捏造傳記細節 | 從該人士的官方簡介或聯絡方式驗證 |
| **近期事件** | 人工智能訓練有截止日期 | 搜尋即時新聞來源 |
| **教會／機構通訊** | 可能影響關係或聲譽 | 發送前進行人手牧養或管理審核 |

---

## 11. 一分鐘最終檢查

在使用、發送或發布任何人工智能協助創建的內容之前：

- **目的** — 人工智能是否是此任務的正確工具？
- **權限** — 我是否將敏感資料排除在提示詞之外？
- **證明** — 我是否已閱讀此內容、檢查關鍵聲明，並能夠為之背書？

如果三者都是「是」— 你已經做了最低限度的負責任之事。
