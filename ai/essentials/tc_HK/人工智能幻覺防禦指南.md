# 人工智能幻覺防禦指南

**如何捕捉自信錯誤與虛構細節**

> [!quote] 核心原則：  
> 將人工智能視為起草引擎，而非真相引擎。  
> 人工智能不知道它何時出錯。它會以同樣自信的語氣產生錯誤答案與正確答案。  
> 防禦幻覺不是為了減少對人工智能的信任——而是為了知道在何處以及如何檢查。  
>  
> **流暢不等於正確**。

**本指南用途：** 建立習慣，在人工智能錯誤造成傷害前捕捉它們。

**本指南非：** 遵循這些步驟就能消除人工智能錯誤的保證。人工智能系統不提供保證答案——它們預測最可能的內容，這意味著即使做法良好，錯誤仍可能發生。人工審核始終是必需的。

---

## 1. 什麼是幻覺？

人工智能幻覺是指模型產生 **事實錯誤、虛構或誤導性的輸出——但以自信的語氣陳述**。

這不是將來會被修復的技術錯誤。這是人工智能系統運作的結構性特徵：它們的設計目的是生成看似合理、邏輯連貫且令人信服的內容，而非用來可靠地驗證這些內容是否真正正確。一個行文流暢的答案與一個錯誤的答案，外觀上可能一模一樣。

### 為何會發生？

| 原因 | 通俗解釋 |
|------|----------|
| **訓練數據缺口** | 模型從未接受過特定事實的訓練——因此它填入看似合理的內容 |
| **無實時知識** | 大多數模型有知識截止日期；該日期後變更的事實可能錯誤 |
| **自信外推** | 模型擴展它識別的模式，即使不應該如此 |
| **提示詞模糊** | 模糊問題產生模糊——且可能虛構——的答案 |
| **長對話記憶限制** | 在長對話中，人工智能可能失去對早期細節的追蹤，後來與之前所說矛盾 |
| **檢索失敗（RAG）** | 在文件問答系統中，如果檢索到錯誤來源，答案就建立在錯誤基礎上 |

**幻覺不是：**
- **不誠實**——人工智能沒有說謊
- **模型故障**——即使強大模型也會發生
- **僅限較弱人工智能**——所有現行模型都可能幻覺

**幻覺也是：**
- **錯誤摘要**——對真實文件
- **虛構引用**——不存在的參考文獻
- **過時事實**——以現在時態陳述
- **遺漏例外條款**——關鍵的限制或例外條件被省略，從而改變原意	
- **無依據的自信**——尤其在小眾或近期主題上

> [!important] 人工智能工具的設計目的是生成回應，而非承認缺少完整背景與情境。與人類專業人士不同——當被問及超出其專業能力範圍的問題時，他們會感到不確定——人工智能工具沒有任何內部信號告訴它應該停下來並請求澄清。無論是否具備足夠的完整背景與情境，它都會嘗試回答——而兩種情況下的回答聽起來會同樣自信。這並非不誠實，而是這些系統運作方式的結構性特徵。

> [!important] **提供足夠的完整背景與情境，並驗證回應是否如實反映該完整背景與情境，此責任完全屬於人類。**

## 2. 為何在香港更為重要

| 香港特定風險 | 為何幻覺風險更高 |
|-------------|----------------|
| **香港法律與法規** | 人工智能訓練以美/英法律為主；香港條例經常錯誤 |
| **繁體中文** | 高質量繁體中文訓練來源較少；翻譯錯誤無聲累積 |
| **近期政策** | 訓練截止日期意味著近期《個人資料（私隱）條例》指引與新法規可能錯誤 |
| **聖經與神學** | 人工智能可能產生看似合理但教義錯誤的詮釋 |
| **具名香港機構** | 人工智能經常混淆相似名稱或虛構細節 |
| **資助與政府表格** | 人工智能可能將海外準則應用於香港特定要求 |

## 3. 五種幻覺模式

### 模式 1 — 自信虛構
人工智能陳述特定事實——統計數據、姓名、日期、案例編號——不存在或錯誤。

**如何識別：** 非常具體的數字但無指明來源。  
**防禦：** 搜尋該具體數字。如果 60 秒內找不到原始來源，不要使用它。

---

### 模式 2 — 看似合理的引用
人工智能虛構聽起來真實的學術論文、法律案例或政府文件，但並不存在。

**如何識別：** 引用格式良好但無處可尋。  
**防禦：** 搜尋確切標題。獨立驗證作者、出版商與日期。絕不引用未確認存在的來源。

---

### 模式 3 — 過時事實
人工智能陳述在訓練截止日期時為真但現已不正確的內容。

**如何識別：** 以現在時態陳述法規或政策資訊但無日期錨點。  
**防禦：** 對於任何法規相關內容，始終在當前官方來源驗證，如 www.pcpd.org.hk, www.elegislation.gov.hk。

---

### 模式 4 — 自信外推
人工智能將來自一個司法管轄區或情境的規則應用於不適用之處。

**如何識別：** 將美/英規則應用於香港情境的建議，或將企業規模指引應用於中小企業。  
**防禦：** 始終檢查司法管轄區。如果涉及合規，請合格專業人士參與。

---

### 模式 5 — 流暢改寫錯誤
人工智能摘要真實文件但微妙改變含義——省略條件、誤述門檻或遺漏例外。

**如何識別：** 複雜文件摘要、政策改寫、法律或財務摘要。  
**防禦：** 對於影響決策的摘要，將人工智能輸出與來源逐節直接比較。

---

## 4. 提示詞層級防禦（錯誤發生前）

減少幻覺的最佳時機是在收到輸出之前。

| 技巧 | 如何使用 | 為何有效 |
|------|----------|----------|
| **來源核對** | 「僅從我的文件回答。不使用外部知識。」 | 無法幻覺未被給予的內容 |
| **不確定性提示** | 「用 [不確定] 標記不確定的聲明。」 | 模型在被要求時表達不確定性 |
| **明確約束** | 「不要虛構。如果缺失，請說明。」 | 對常見幻覺類型的硬性停止 |
| **逐步推理** | 「首先列出章節。然後摘要。然後識別缺口。」 | 使推理可追蹤 |
| **角色框架** | 「你是一位細心的審核員。標記不確定性，不要填補。」 | 使模型行為朝向謹慎 |

**高風險任務的安全回應模式：**
- **從提供文本**——僅摘要你給予的內容
- **分離不確定**——將不確定性與確認事實分開列出
- **選項而非決策**——你決定；人工智能提供選擇
- **缺失時停止**——要求它在證據缺失時停止，而非猜測

## 5. 快速驗證習慣

### 要點檢查

- **步驟 1** — 選取一項 — 最具體的細節：日期、統計數據或研究名稱
- **步驟 2** — 搜尋它 — 僅搜尋那一項
- **步驟 3** — 未找到？ — 將其餘人工智能輸出視為可疑

---

### 退出條款

在任何重要提示詞末尾添加：

- **「我不知道」** — 「如果你不確定，請說『我不知道』而非猜測。」
- **「檢查什麼」** — 「列出我應該複查的 3 件事。」

---

## 6. 三檢查驗證系統

以導航技巧命名：你需要至少三個參考點來確認你的位置。將同樣邏輯應用於人工智能輸出。

### 檢查 1 — 來源檢查（2–5 分鐘）
問人工智能： *「你這個聲明的來源是什麼？指明具體文件、作者、日期，以及我在何處可以找到它。」*  
對於任何進入客戶文件、決策或外部溝通的內容——在原始來源驗證，而非另一個人工智能或摘要。

> [!warning] 人工智能給你來源不代表來源存在：  
> 人工智能可以以與事實同樣的自信幻覺引用。始終獨立驗證——而非再次問人工智能。

**按主題香港主要來源：**

> 如果網站沒有重定向到其正式網站，你可以嘗試在主要來源前加上前綴 "https://www." 。例如，應該是 https://www.gov.hk 而非 gov.hk。

| 主題 | 主要來源 |
|------|----------|
| **《個人資料（私隱）條例》/ 個人資料** | pcpd.org.hk |
| **公司法** | cr.gov.hk |
| **僱傭法** | labour.gov.hk |
| **證監會法規** | sfc.hk |
| **金管局 / 銀行業** | hkma.gov.hk |
| **政府政策** | gov.hk |
| **條例 / 立法** | elegislation.gov.hk |
| **香港生產力促進局人工智能指引** | hkpc.org |
| **個人資料私隱專員公署人工智能指引** | www.pcpd.org.hk/english/artificial_intelligence/index.html |
| **聖經 / 神學** | 聖經本身；你的牧師 |

---

### 檢查 2 — 懷疑問題（30 秒）
問人工智能：「你這個答案中不確定的是什麼？你可能哪裡錯了？」

**提示詞模板：**
```
在我使用這個之前，告訴我：
- 你這個答案中最不確定的部分是哪些？
- 如果我告訴你 [相關情境]，什麼會改變你的答案？
- 是否有香港特定規則可能使這不同？
- 哪些聲明我應該驗證，以及在何處驗證？
```

---

### 檢查 3 — 來源核對與出處檢查（30–60 秒）
在提示詞中直接提供來源材料。要求人工智能僅從你提供的內容工作，並指明哪個章節支持每個聲明。

**使用的提示詞（來源核對）：**
```
僅基於以下文本，回答以下問題。
不要添加任何不在文本中的資訊。
如果答案不在文本中，請說：「我在提供的來源中找不到這個。」
在每個關鍵點之後，指明來源的哪個段落或章節支持它。

問題：[你的問題]
文本：[貼上你的來源文件]
```

**為何有效：** 來源核對迫使模型從你的來源工作，而非其訓練。錯誤變成可見文件的誤讀——可檢測——而非無形虛構。

## 7. S-A-F-E-R 框架

如果你使用人工智能進行技術或項目工作，「逐步思考」不夠。你需要來源核對的框架。

使用 **S-A-F-E-R** 心智檢查清單：

- **S — 來源限定** — 僅使用聲明來源；無自由回憶
- **A — 承認不確定** — 迫使人工智能說「我不知道」
- **F — 事實證據** — 每個聲明連結到具體證據
- **E — 到期意識** — 標記過時數據的風險（對標準至關重要）
- **R — 審核格式** — 使用表格分離事實與推論

**S-A-F-E-R 結構化輸出模板：**
```
將你的答案以具有以下欄位的表格返回：
  聲明 | 證據 | 來源 | 來源日期 | 置信度 | 需要檢查
```

**自我審核提示詞：**
```
「列出你答案中 5 個最重要的事實聲明。對每個聲明，提供：1) 最佳來源，2) 日期，3) 用於驗證的谷歌搜尋查詢。」
```

**為何有效：** 這將舉證責任交還給人工智能。當系統必須明確標註內容出處時，幻覺往往不攻自破。

## 8. 什麼有效——什麼無效

| 有效性 | 提示詞添加 |
|--------|-----------|
| **最有效** | 「僅使用這些來源」· 「如果不確定請說『我不知道』」· 「每個聲明引用來源與日期」· 「標記無支持聲明」· 「先提取確切引用，然後回答」 |
| **中等有效** | 「摘要你的假設」· 「列出可能弱點」· 「對每個聲明給出置信度」 |
| **較不可靠** | 「解釋你的思維鏈」· 「逐步思考」（單獨）· 無來源核對的長推理 |

**關於思維鏈的說明：** 要求思維鏈 **不是** 防禦幻覺的最佳方法。模型可以產生虛構邏輯——解釋聽起來令人信服但仍然錯誤。

更好替代方案：
- **簡短推理** — 要求簡短推理摘要
- **關鍵假設** — 詢問做了哪些假設
- **什麼錯了？** — 詢問「這可能哪裡錯了？」
- **每個聲明的證據** — 要求每個聲明的證據
- **驗證什麼？** — 詢問「什麼需要獨立驗證？」

## 9. 紅旗 — 幻覺警告信號

| 旗標 | 警告信號 |
|------|----------|
| 🔴 **精確數字** | 無給定來源的具體數字 |
| 🔴 **找不到引用** | 無法在谷歌找到 |
| 🔴 **無名專家** | 「研究表明...」或「專家說...」但無姓名 |
| 🔴 **100% 自信語氣** | 在微妙或有爭議的主題上 |
| 🔴 **未知框架** | 「XYZ 七步模型」無人提及 |
| 🔴 **近期事件** | 過去 12–18 個月的任何內容可能過時 |
| 🟡 **看似合理但新穎** | 聽起來正確但你從未聽過 |
| 🟡 **略顯奇怪的混合** | 正確資訊與奇怪聲明混合 |
| 🟡 **過時細節** | 工具、法律、軟件版本或產品功能 |

## 10. 幻覺防禦提示詞模板

### 校準提示詞
在任何研究或事實查找任務前使用：
```
指令（在你回答之前）：
- 告訴我你的置信度（高 / 中 / 低）
- 告訴我最不確定的是什麼
- 標記任何時間敏感或司法管轄區特定的內容
- 告訴我哪些聲明我應該驗證以及在何處驗證
- 告訴我是從一般訓練還是從我提供的來源得出
```

### 香港法律 / 法規提示詞
用於任何法律或法規問題：
```
任務：
我在香港情境中詢問這個。

指令：
- 告訴我是基於香港法律還是海外原則
- 指明你引用的具體香港條例、法規或指引
- 標記香港法律與英國或美國法律顯著不同之處
- 告訴我是否應該在 elegislation.gov.hk 驗證或諮詢香港律師
```

### 摘要檢查提示詞
用於要求人工智能摘要文件時：
```
任務：摘要這個文件。

指令（在你的摘要之後）：
- 列出原始文件中任何複雜、有條件或微妙的部分，並注意你的摘要是否保留了這種複雜性
- 識別不可省略的條件或例外
- 提示我應該複查的任何數字、門檻或日期
```

### 聖經 / 神學安全提示詞
用於任何涉及聖經或神學內容的任務：
```
任務：我需要幫助 [涉及聖經或神學的任務]。

指令：
- 不要將神學詮釋呈現為權威
- 如果不同基督教傳統持有不同觀點，請列出
- 標記任何你不確定的聖經引用
- 我將在使用前在聖經中驗證所有聖經內容
```

## 11. 人工審核關口

在使用任何人工智能輸出前，回答這四個問題：

| 問題 | 如果否 — 在此停止 |
|------|------------------|
| **閱讀完整輸出？** | 不要略讀並假設 |
| **事實與引用已驗證？** | 不要轉發未驗證聲明 |
| **有合資格的人把關嗎？** | 不要依賴人工智能進行專業判斷 |
| **能夠支持它？** | 如果不能 — 檢查更多 |

> [!important] 責任測試：  
> 如果受到質疑，我是否願意支持這個輸出？  
> 如果是 — 你已經做得足夠。如果否 — 在使用前檢查更多。

---

## 12. 按任務類型的幻覺風險

| 任務 | 風險 | 關鍵防禦 |
|------|------|----------|
| **摘要你的文件** | 低–中 | 檢查條件與例外是否保留 |
| **從你的筆記起草** | 低 | 使用前閱讀完整輸出 |
| **研究事實或法律** | 高 | 在主要來源驗證 |
| **生成引用** | 非常高 | 絕不在確認來源存在前使用 |
| **香港法律** / 法規問答 | 非常高 | 在官方香港來源驗證或諮詢律師 |
| **繁體中文翻譯** | 中 | 與合格雙語審核員檢查術語 |
| **聖經詮釋** | 高 | 在聖經中驗證；諮詢你的牧師 |
| **資助統計數據** | 非常高 | 絕不讓人工智能捏造統計數字；指示人工智能使用 [待填寫] 等佔位符代替 |

## 13. 如果幻覺已經發生

- **立即糾正** — 通知任何收到錯誤資訊的人
- **保留記錄** — 保留原始人工智能輸出與你的糾正
- **評估影響** — 誰收到了它，可能影響了哪些決策
- **審查缺口** — 哪個檢查本應發生但沒有？
- **更新你的流程** — 添加本應捕捉這個的具體檢查
