## [EN] English

### What This Guide Is

The **Win.Win AI Use Case Guide** helps people use AI for everyday organisational tasks without handing the decision to AI.

It is arranged around real tasks, such as drafting messages, summarising meeting notes, checking policy questions, translating notices, and reviewing Hong Kong-specific information. For each task, this guide explains what AI can help with, what can go wrong, what a person must check, and when the work should be corrected, stopped, or escalated.

The core message is simple: treat AI output as a **draft, helper, or review aid**. It is not the final decision. A responsible person or organisation is still accountable for what is sent, approved, published, or acted on.

This guide is a companion to **Win.Win AI Essentials**. The Essentials kit explains the foundation. This guide shows how to apply that foundation to everyday tasks.

### Folder Structure

This guide is organised by language and locale. Folder names follow the convention `[language]_[market]` so the scope of each folder is always unambiguous.

Each folder contains a **complete, self-contained set of materials** — quick starts, use-case pages, review patterns, risk references, escalation guidance, and reviewer decision tools — written and contextualised for that audience. Content is intentionally duplicated across folders rather than cross-referenced. This means each folder works on its own, with no dependency on any other folder.

| Folder | Language | Designed For |
|--------|----------|--------------|
| `en_HK/` | English | Hong Kong — individuals and organisations working primarily in English |
| `tc_HK/` | Traditional Chinese / 繁體中文 | Hong Kong — Traditional Chinese readers |
| `sc_HK/` | Simplified Chinese / 简体中文 | Hong Kong — Simplified Chinese readers, primarily Mandarin-speaking with Mainland Chinese background |

> **How to choose:** Use the folder that matches the language your team reads most comfortably. All folders cover the same core use cases, review patterns, escalation principles, and Hong Kong-specific references. Open that folder’s README for the full asset index and getting-started guide.

### Where to Go Next

## [TC] 繁體中文（Traditional Chinese）

### 本指南是甚麼

**Win.Win 人工智能應用案例指南** 協助一般機構在日常工作中使用人工智能，同時保留人的判斷、審查和責任。

本指南按實際任務整理，例如撰寫通訊、整理會議記錄、回答政策問題、翻譯通知，以及查核香港相關資料。每個用例都說明人工智能可以幫助甚麼、可能出現甚麼問題、審查者需要檢查甚麼，以及何時應修正、停止或升級處理。

核心訊息很簡單：人工智能輸出應被視為 **草稿、輔助工具或審查輔助** ，而不是最終決定。凡是被發送、批准、發布或採取行動的內容，仍然由負責的人或機構承擔責任。

本指南是 **Win.Win 人工智能必備** 工具包的配套資源。必備工具包說明基礎原則；本指南則示範如何把這些原則應用到日常任務。

## [SC] 简体中文（Simplified Chinese）

### 本指南是什么

**Win.Win 人工智能应用案例指南**帮助一般机构在日常工作中使用人工智能，同时保留人的判断、审查和责任。

本指南按实际任务整理，例如撰写通讯、整理会议记录、回答政策问题、翻译通知，以及查核香港相关资料。每个用例都会说明人工智能可以帮助什么、可能出现什么问题、审查者需要检查什么，以及何时应修正、停止或升级处理。

核心信息很简单：人工智能输出应被视为**草稿、辅助工具或审查辅助**，而不是最终决定。凡是被发送、批准、发布或采取行动的内容，仍然由负责的人或机构承担责任。

本指南是 **Win.Win 人工智能必备** 工具包的配套资源。必备工具包说明基础原则；本指南则示范如何把这些原则应用到日常任务。

### 文件夹结构

本指南按语言及地区整理。文件夹名称采用 `[语言]_[市场]` 的命名规则，方便清晰识别每个文件夹的适用范围。

每个文件夹均包含一套**完整且独立的资料**——快速入门、用例页面、审查模式、风险参考、升级处理指引及审查者决定工具——并根据对应读者群的语境撰写。各文件夹的内容刻意以复制方式提供，而非采用交叉引用，确保每个文件夹可独立使用，无需依赖其他文件夹。
