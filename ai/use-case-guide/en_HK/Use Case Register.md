# Use Case Register

## 1. Purpose and Scope

Use this file to choose the use-case page that best matches your task.

If your task touches more than one use case, start with the closest use case, check any second page that covers a higher-risk part of the work, and use the stricter review and escalation rule when in doubt.

> **AI Blind Spot prompt/review check:** when choosing a use case, ask whether the task depends on tacit organisational context, relationship history, local practice, authority, or consequences that the AI was not told. Before prompting, give the AI the relevant context where safe. Before use, the reviewer must check the real context, not only the AI output.
