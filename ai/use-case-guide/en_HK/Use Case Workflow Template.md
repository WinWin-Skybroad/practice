# Use Case Workflow Template

## 1. How To Use This Template

A use-case page is not a workflow yet. It tells you what to check, but the organisation still needs to decide who starts the task, what happens before the AI step, what happens after approval, and where the final output goes.

Use this template to turn one use-case page into a repeatable workflow.

---

## 2. Workflow Steps

| Step | Question | Local answer |
|---|---|---|
| 1. Trigger | When does this AI task begin? | |
| 2. Source packet | What must be gathered before prompting? | |
| 3. AI drafting | Who runs the prompt and where? | |
| 4. Human review | Who checks the output, and against what? | |
| 5. Decision | Who may approve as is, correct then approve, or stop and escalate? | |
| 6. Filing / use | Where does the approved output go, and who may send or use it? | |

---

## 3. Workflow Controls

For each workflow, define:

- owner
- backup owner
- reviewer
- escalation contact
- source location
- output location
- record location
- stop rule

---

## 4. Minimum Workflow Rule

Do not rely on a use-case page by itself. For each recurring AI task, name the workflow and the person responsible for it.

A task with no owner becomes everyone’s responsibility and no one’s.
