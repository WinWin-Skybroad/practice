## 这是什么

**Win.Win 人工智能应用案例指南** 是一套实用指南，帮助机构在日常工作中使用人工智能，同时不把最终决定交给人工智能。

本指南按任务整理。您不需要先读完所有内容才开始。请从正在处理的任务开始，打开相应的应用案例页面，并在人工智能输出被发送、分享、批准、发布或采取行动前，使用审核检查。

本指南帮助个人、教会、非营利机构及中小企业，选择合适的人工智能任务、准备更好的提示词、理解风险、采取保障措施、升级处理敏感事项，并决定人工智能输出应被批准、修正或停止。

本指南是 **Win.Win 人工智能必备** 的配套资源。必备材料说明基础；本指南示范如何把这些基础应用到实际任务。

**使用这些材料并不能保证人工智能任务安全、合规或成功。读者及其机构仍需自行负责所有决定。**

这些材料仅供一般信息及独立使用。它们不是咨询服务、法律意见、合规认证、技术实施指引、财务建议、医疗建议、辅导建议、神学建议或牧养咨询。

> [!note] 人工智能盲点
> 本指南在提示词和审核两方面都使用一个重要概念：**人工智能盲点**。人工智能可以令答案看起来仔细、完整，并像是经过周详判断，但仍然可能缺少任务背后的真实处境。它可能不知道关系历史、本地做法、专业直觉、权限限制、验证需要或重要后果。较好的提示词可以降低这个风险，但负责人仍需在使用或批准输出前，检查输出是否符合真实机构、真实人物、真实权限及真实后果。

> [!note] 人工智能盲点指南配套  
> **Win.Win 人工智能盲点指南** 是用于更深入审视人工智能盲点风险的配套指南。这些风险可能涉及任务依据中缺失或未获充分呈现的相关情境、真实或本地理解、专业直觉、权限、问责、独立核实、受众影响、运营记忆，或人工智能无法可靠掌握的后果。
>
> **Win.Win 人工智能盲点指南** 目前的详细重点是识别及引导未明说的语境。未明说的语境是指在任务依据中缺失、不完整或未获充分呈现的相关情境。它可能由人知悉、存在于当前已批准记录、同时存在于两者，或来源不清楚。
>
> 相关指引涵盖在识别或提出情境后，检索当前已批准来源及提取与任务相关的已批准材料、评估可表达性、安全转换、只由人处理、核实、由需问责或专业人员审核、停止及升级处理。**机构情境处理** 为较广泛的当前任务来源及处理问题提供简明方向，但并非完整的知识管理、记录管理、企业检索、保存或检索增强生成（RAG）框架。已提出的情境不会自动输入人工智能或被记录；保存是另一项受治理决定。
>
> 使用 **人工智能盲点控制图** 选择相关控制类别。使用 **机构情境处理** 处理较广泛的当前任务来源及处理问题；当相关情境在任务依据中缺失、不完整或未获充分呈现时，使用 **未明说的语境控制**。

## 应用案例批准级别说明

本节说明本指南各类人工智能应用案例使用的批准级别。

批准级别 **不表示** 某个具体人工智能输出已自动获批准。它只描述这类任务通常是否适合人工智能辅助工作，以及在输出可以使用前需要哪些条件或保障措施。

例如，某个应用案例可能标示为 **一般可批准使用**，因为人工智能通常可以帮助草拟或整理这类工作。然而，实际人工智能输出仍需要在被发送、分享、批准、发布或采取行动前完成人工审核。

简单来说：

- **批准级别** 告诉您这类人工智能任务是否适合尝试。
- **审核者决策** 告诉您某个具体人工智能输出应被批准、修正或升级处理。

某个应用案例被列为可批准使用，并不表示可以省略审核、来源核对、隐私检查、权限检查或必要的升级处理。

| 批准级别 | 实际意思 |
|---|---|
| **一般可批准使用** | 人工智能可按正常应用案例工作流程用于此任务，但指定审核者必须在使用输出前检查输出。 |
| **非机密情况下一般可批准使用** | 只在输入不包含该工具或流程未获批准处理的机密、敏感或个人资料时使用。 |
| **可谨慎使用** | 人工智能可帮助草拟或发现问题，但输出需要更强审核，并可能需要在使用前升级处理。 |
| **仅可作为思考辅助** | 人工智能可帮助构思、整理、比较或检查问题。除非另有由人撰写或批准的结果，否则输出不应直接用作最终消息、决定、政策、建议、批准或记录。 |
| **依赖输出前先升级处理** | 普通审核并不足够。在适当的合资格或获授权人员按已批准流程审核前，不应批准、发送、发布、采取行动或依赖输出。 |

## 选择您的路径

使用本节决定如何进入指南。您不需要在使用前阅读每个文件。请从最符合目前需要的路径开始。

---

### 路径 0 — 初次使用本指南

如果您第一次打开本指南，且不确定从哪里开始，请使用这条路径。

- 打开 [[由此开始]] 作快速导览。
- 如想理解实用层与参考层文件、升级处理指引及记录模板如何配合使用，请打开 [[如何使用本指南]]。
- 然后打开最符合您机构的快速入门页：
  - [[教会快速入门]]
  - [[非营利机构快速入门]]
  - [[中小企业快速入门]]
- 选择一项您的机构已经用人工智能处理的普通任务。
- 打开相应的应用案例页面。
- 在使用人工智能输出前，阅读 **这可能造成什么代价** 及 **如何审核这个输出**。
- 在输出被发送、发布、依赖或使用前，进行审核。

---

### 路径 A — 我已知道应用案例

如果您已知道要审核的人工智能任务，例如草拟通讯、总结会议记录、翻译通知或制作双语版本，请使用这条路径。

- 打开相关应用案例页面。
- 阅读 **这可能造成什么代价**，理解实际风险。
- 使用 **如何审核这个输出**，在批准、修正或升级处理人工智能输出前，引导针对该任务的审核。
- 如输出可能超出审核者的权限、专业知识、证据、已批准流程或责任，请检查 **何时应升级处理而不是批准**。
- 只有在需要理解批准级别、参考层文件、审核者工具、记录保存或应用案例页面如何配合整体指南时，才打开 [[如何使用本指南]]。
- 只有在需要较深入指引时，才使用相关参考文件。

---

### 路径 B — 改善提示词

如果该任务获准使用人工智能处理，但提示词在产生输出前需要更好的结构、更清晰的来源材料或更强的保障措施，请使用这条路径。

- 从相关应用案例页面开始，确保提示词改进仍以真实任务为基础。
- 如任务依赖文件、会议记录、政策、邮件、网页或其他来源材料，请使用 [[提示词前来源资料包]]。
- 打开 [[提示词强化模式]]。
- 只选择与实际风险相符的提示词强化。
- 把提示词强化加入 Win.Win 人工智能必备提示词结构中的合适部分，通常是 **指令**、**规则**、**输出格式** 或 **提醒 / 审核备注**。
- 把来源材料放在提示词最后的 **内容** 部分。
- 如不确定来源准备、提示词强化、人工审核及升级处理如何配合，请打开 [[如何使用本指南]]。
- 不要只依赖更好的提示词。人工智能输出产生后仍要进行人工审核。

---

### 路径 C — 培训审核者

当您正在培训审核者、建立内部人工智能审核流程，或决定机构应如何跨多个应用案例审核人工智能输出时，请使用这条路径。

- 阅读 [[如何使用本指南]]，理解本指南背后的操作方法。
- 从相关应用案例页面开始，确保审核仍以真实任务为基础。
- 阅读 [[人工审核模式]]，理解人工智能输出常见的检查方式。
- 阅读 [[人工审核风险库]]，理解应用案例页面使用的具名人工审核风险。
- 如需要理解应用案例风险背后较大的风险类别，或查找具名风险或失败模式的意思及定义路线，请使用 [[风险分类]]。
- 当问题在人工智能输出产生前已经开始，请使用 [[提示词强化模式]] 及 [[提示词前来源资料包]]。
- 当需要提示词以外的控制，例如来源核对、审核者角色、批准记录或工作流程保障，请使用 [[缓解措施库]]。
- 使用 [[审核者决策卡]] 决定审核者可以批准、应修正，还是必须停止并升级处理。
- 如输出可能超出审核者的权限、专业知识、证据、已批准流程或责任，请使用 [[升级处理指南]]。
- 使用应用案例页面，以真实或接近真实的例子练习针对特定任务的审核。

您不需要为每项人工智能任务打开每个参考文件。请先使用相关应用案例页面，只有在审核问题需要时，才打开较深入的参考文件。

### 路径 D — 为您的机构调整本指南

当您的机构希望把公开指南转化为本地指南、内部工作流程或培训资源时，请使用这条路径。

- 在调整前阅读 [[如何使用本指南]]，理解指南结构。
- 在改变指南结构、措辞、语言、控制、链接或发布文件前，阅读 [[作者及编辑指南]]。
- 阅读 [[应用案例页面模板]]。
- 复制模板结构。
- 清楚保留批准级别、审核方法、升级处理界线及相关参考文件。
- 加入您机构自己的风险、审核者、升级处理路线、来源核对及批准流程。
- 使用 [[审核者决策卡]] 定义谁可以批准、谁必须修正，以及何时需要升级处理。
- 如本地工作流程需要审核轨迹、批准记录或日后审计参考，请使用 [[人工智能输出记录模板]]。

---

### 路径 E — 实施一个应用案例

当您准备在真实工作流程中试点或实施一个人工智能应用案例时，请使用这条路径。

- 如果这是您的机构第一次把应用案例页面转化为真实工作流程，请阅读 [[如何使用本指南]]。
- 在选择试点任务前，阅读 [[选择首个应用案例]]。
- 选择一项机构已经在做、且可管理的任务。
- 在提示人工智能前，先整理 [[提示词前来源资料包]]。
- 使用 [[应用案例工作流程模板]]，把选定的应用案例页面转化为本地工作流程。
- 指定一名具名审核者，并清楚说明谁有批准权限。
- 审核时使用 [[审核者决策卡]]，决定应批准、修正或升级处理。
- 如正在试点，使用 [[试点及停止规则卡]] 决定试点应继续、暂停、改变或停止。
- 对于会对外发送、影响他人或用于支持实际决策的输出，保留简单的 [[人工智能输出记录模板]]。
- 当出现问题或工作流程需要改善时，使用 [[首次错误复盘]]。
