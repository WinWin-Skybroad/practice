# 升级处理指南

## 1. 目的及范围

升级处理是停止一般批准流程，并在使用输出前请适当的最终责任人审核。

升级处理不是失败，而是一项安全控制。

审核者不需要只因提及敏感主题便停止。只有在获明确授权、具备能力、充分掌握资料，而且依照该事项的已批准流程时，审核者才可继续。

---

## 2. 何时一般审核并不足够

如审核者无法在其角色、证据、权限、能力或已批准流程范围内安全批准输出，便应升级处理。

如出现以下任何情况，应升级处理：

- 审核者不是批准该主题的适当人士。
- 审核者缺少核实输出所需的来源材料、语境、来源访问权限、领域知识或已批准流程。
- 输出似乎作出或暗示审核者无权批准的机构决定。
- 输出建立或暗示某项承诺、保证、指示、批准、公开声明、政策立场、期限、退款、付款或义务，而审核者无权或未充分掌握资料去确认。
- 输出涉及法律、财务、人力资源、隐私、法规、安全保障、牧养、神学、医疗、公开或其他专业事项，而审核者缺少确认安全使用所需的权限、能力、语境、来源访问权限或已批准流程。
- 输出涉及个人资料、机密资料、客户资料、会员资料、捐赠者资料、受益人资料、弱势群体、投诉、危机情况或公众声誉，而审核者缺少确认安全使用所需的权限、语境、来源访问权限或已批准流程。
- 输出包含无法通过核对现有来源解决的不确定性。
- 审核者可以修改措辞，但无法确认实质内容是否正确。

升级处理不代表人工智能不能协助，而是输出在由适当的最终责任人审核前，不得获批准、发送、发布、据以行动或依赖。

## 3. 升级处理路径

### 3.1 应升级交由谁处理

| 问题 | 升级交由 |
|---|---|
| 法律、法规、人力资源或合规问题 | 合资格法律、合规、人力资源或管理审核者 |
| 个人资料或机密性问题 | 隐私、资料保护或负责的机构领导人 |
| 财务、资助、退款、付款或拨款问题 | 财务负责人、资助负责人或获授权管理层审核者 |
| 牧养辅导、神学意见、属灵指导或教义问题 | 机构内适当的人类权威；不要把人工智能输出当作权威 |
| 对外通讯或声誉问题 | 通讯责任负责人或机构领导人 |
| 网络安全或工具批准问题 | 信息技术、网络安全或负责的系统负责人 |
| 来源所有权或有争议来源问题 | 来源负责人、记录负责人、会议主席、政策负责人或责任经理 |
| 没有合适审核者 | 暂停任务。不要把人工智能输出当作最终决定 |

---

### 3.2 如果您的机构没有专职专业人员

小型教会、非营利机构及中小企业可能没有内部法律、人力资源、信息技术、网络安全、财务或合规人员。在这种情况下，升级处理是寻求现有最负责任及最具能力的人协助，而不是假装机构内有专家。

升级处理可以是找内部领导、董事会或委员会成员、外部顾问、专业服务提供者，或在找到合适审核者前暂停任务。

| 情况 | 小型机构的实际升级处理路径 |
|---|---|
| 教会或事工事项 | 牧师、长老、执事会、事工领袖、教会议会或指定审核者 |
| 非营利服务或受益人事项 | 项目经理、个案 / 服务主管、董事会主席、负责的委员会成员或外部顾问 |
| 中小企业法律、人力资源或财务事项 | 企业负责人、董事、经理、会计师、人力资源服务提供者、律师或其他合资格顾问 |
| 法律、合规或法规问题 | 暂停任务。不要只依赖人工智能输出继续。寻求合资格专业人士、公益法律服务、管治机构或具相关专业知识的可信外部联系人 |
| 资料保护或机密性问题 | 机构内对资料负责的人。如没有人承担此角色，在找出负责人前，把任务视为已升级处理 |
| 网络安全或工具批准问题 | 信息技术服务提供者、系统负责人、网络安全顾问或负责的机构领导人 |
| 没有合适审核者 | 暂停任务。不要把人工智能输出当作最终决定 |

升级处理可以简单地说：

**“这可能影响权利、金钱、声誉、个人资料、牧养或辅导事项，或正式责任。我不是适合单独批准的人。”**

如有疑问，应停止。延误的任务通常仍可补救；根据错误人工智能输出采取的行动则未必可以。

## 4. 实用停止规则

> [!warning] 无法安全批准时停止
> 如您无法在自己的角色、证据、权限、能力或已批准流程范围内核实或批准输出，不要批准、发送、发布、据以行动或依赖该输出。

- 当人工智能输出听起来很有信心，但您无法核实时，暂停任务。
- 当输出影响权利、义务、照顾、金钱、声誉或服务取得，而您无法在自己的角色范围内安全批准时，暂停任务。
- 当人工智能建立来源材料中没有的声称、承诺、决定或结论时，暂停任务。
- 当审核者没有批准内容所需的权限、能力、来源访问权限、语境或已批准流程时，暂停任务。
- 当工具或账户未获批准处理所涉及资料时，暂停任务。
