# 制作双语版本

## 1. 这个应用案例是什么

如您希望人工智能协助：**制作英文及繁体中文双语版本**，请使用本页。

- 常见使用者：**教会、非营利机构、中小企业**。
- 批准级别：**谨慎使用**。
- 需要人工审核：**是 — 需要双语审核者**。
- 使用人工智能输出协助您草拟或检查工作。不要把它视为最终决定。

---

## 2. 这可能造成什么代价

语气强弱、限制、金额、日期、责任或语气的细微变化，都可能令两个语言版本传达不同义务。如每个版本只独立阅读，这种不一致可能传达给捐赠者、职员、客户、成员或公众，并需要更正、解释，或决定以哪个版本为准。

---

## 3. 如何审核这个输出

批准人工智能输出前，请使用以下检查。不要只因输出读起来流畅便批准。

---

### 3.1 审核设置

1. 以英文为来源，并排打开两个版本。
2. 先阅读英文第 1 句，再阅读繁体中文第 1 句。确认两者意思及条件相同后，才移至第 2 句。
3. 特别留意：条件用语、限制、承诺、法律参考，以及任何产生义务或限制的措辞。
4. 如繁体中文读起来流畅，但与英文的范围、强度或条件不同，应标示该句。

---

### 3.2 批准前 — 一项检查

> **合资格双语审核者是否已把繁体中文输出与英文来源并排逐句阅读 — 不只是检查中文是否流畅，而是确认两个版本的意思、条件及承诺完全一致？**

---

### 3.3 针对风险的审核检查

这些检查把 [[人工审核风险库]] 中的最低审核责任调整至本任务。

- **[[人工审核风险库#4.5 知识差距|知识差距]]：** 确认审核者在两种语言及文件主题方面具备足够能力，可识别意思、术语、权限及文化错误。如专业内容超出双语审核者的专长，应另行取得专业审核。
- **[[人工审核风险库#4.11 流畅度错觉|流畅度错觉]]：** 独立把双语输出与来源比较，检查意思、事实、限制条件、权限、术语、格式及遗漏。不要把自然或润饰良好的措辞视为翻译完整或正确的证据。
- **[[人工审核风险库#4.20 跨文化语域差距|跨文化语域差距]]：** 检查措辞是否为实际受众及情境保留预期语气、正式程度、礼貌、社交含义、暗示及权限程度。使用合适的双语、文化或了解受众的审核者；如涉及专业意思，另行寻求专业审核。

---

### 3.4 审核者决策

完成上述针对本任务的审核检查后，使用 [[审核者决策卡]] 选择一项结果：

- **原样批准**
- **更正后批准**
- **停止并升级处理**

如审核者欠缺本任务所需的角色、证据、权限、能力、来源访问权、语境或已批准流程，不要批准输出。

---

### 3.5 本任务的审核方法

以下审核指示已针对本任务调整。它们把 [[人工审核模式]] 中的可重用方法应用于这里涉及的实际来源、决定、人士及后果。

- **双语 / 本地化审核：** 把每个语言版本与已批准来源及术语比较，检查意思、遗漏、新增内容、字体、名称、格式及香港用法。
  - 留意：翻译流畅但改变意思、混用字体、改变权限、丢失格式或使用不一致术语。
  - 时机：发布或对外使用前。
  - 审核者：熟悉目标受众及香港用法的合资格双语审核者。

- **以人工判断为本的审核：** 检查两种语言的语气、正式程度、礼貌、社交含义、暗示及权限程度是否适合实际受众及关系。
  - 留意：字面准确但文化或社交信号不恰当，或措辞比原意更冷淡、更强硬、更官方或较不尊重。
  - 时间：发布或发送前。
  - 审核者：双语、文化或了解受众的审核者。

- **合资格法律 / 合规审核：** 如涉及专业意思或专业实务，除双语审核者外，也应取得合资格专业人士审核。
  - 留意：技术上流畅，但改变法律、牧养、医疗、财务、技术或其他专业意思的措辞。
  - 时间：专业内容被依赖或发布前。
  - 审核者：相关合资格专业人士及双语审核者。

---

## 4. 何时应升级处理而不是批准

- 如输出影响法律、人力资源、财务、安全保障、医疗、法规、对外或高影响决定，而审核者没有确认安全使用所需的权限、能力、语境、来源访问权或已批准流程，应在使用前升级处理。
- 如审核者没有资格或权限确认专业意思，法律、医疗、财务、技术或公开翻译应升级处理。

## 5. 提示前

使用人工智能处理本任务前，先检查以下基本事项：
- 目的清晰。
- 输入不包含不应输入工具的个人或机密资料。
- 有负责人可在使用人工智能输出前检查它。
- 任务没有要求人工智能作出决定、提供专业意见或充当最终权威。

- 确认本任务符合批准级别：**谨慎使用**。
- 确认计划中的审核者能完成所需人工审核：**是 — 需要双语审核者**。

---

## 6. 人工智能盲点重点

**风险重点：** 跨文化语域差距

**提示词重点：** 提示前，向人工智能提供来源文本、目标受众、地区语言、语域、术语偏好、渠道，以及是否涉及法律、官方或面向公众的措辞。要求人工智能标示需要双语人工确认的术语、惯用语、正式表达及受众敏感措辞。

**人工审核重点：** 并排比较意思。检查语域、受众合适度、香港术语、名称、日期、官方用语，以及流畅措辞有否改变预期意思。

**较深入的盲点审核：** 如双语输出依赖本地术语、正式程度、文化含义、受众期望或机构语域，请依循 [[如何使用本指南#6.1 Win.Win 人工智能盲点指南|Win.Win 人工智能盲点指南路径]]。

**不要只依赖：** 自然流畅度。双语版本可以读起来很好，却改变语气、义务、正式程度或机构含义。

## 8. 主要风险

- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：[[人工审核风险库#4.11 流畅度错觉|流畅度错觉]]（高）** — 人工智能生成的繁体中文可能清晰、自然且专业，使审核者假设内容准确并可使用。除非使用任务所需的双语、本地化、专业及其他审核模式独立检查输出，否则意思漂移、条件弱化、承诺加强、字体错误及语域不匹配仍可能被隐藏。文字流畅并不是文字准确的证据。

---

## 9. 其他需注意风险

- **[[风险分类#3.11 人工智能盲点 / 语境风险|人工智能盲点 / 语境风险]]：[[人工审核风险库#4.20 跨文化语域差距|跨文化语域差距]]（中）** — 人工智能可能产生字面意思准确的双语或跨文化措辞，但其语气、语言语域、正式程度、礼貌、暗示、权限程度或社交信号并不适合实际受众及情境。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：语域不匹配（中）** — 正式英文可能被翻译成不恰当的随意中文，反之亦然。在香港教会及非营利机构通讯中，正式称谓承载关系含义，因此语域错误尤其重要。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：文化框架丧失（中）** — 英文惯用语、比喻或文化参考需要在中文中作文化调整，而不是逐字翻译。人工智能倾向逐字处理。中文输出可能在语言上正确，但在文化上令人困惑或不恰当。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：简繁字混用（中）** — 人工智能可能把简体中文字插入繁体中文文件。在双语文件中，这尤其难以察觉，因为审核者可能专注于中英文对齐，而不是字符层面的准确性。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：[[人工审核风险库#4.5 知识差距|知识差距]]（高）** — 审核者可能细心而且具双语能力，但仍未必有资格确认法律、法规、财务、人力资源、牧养 / 神学或专业术语是否翻译正确。专业术语需要具备能力的审核者，而不只是语言流利的读者。

把来源材料、笔记、政策摘录、数字及文件放在基础提示词最后的 **内容** 部分。
