# 总结会议记录

## 1. 这个应用案例是什么

当您希望人工智能协助**把会议笔记或会议记录总结为结构化摘要**时，请使用本页。

- 常见使用者：**教会、非营利机构、中小企业**。
- 批准级别：**非机密情况下一般可批准使用**。
- 需要人工审核：**是 — 检查准确性、归因及行动负责人**。
- 使用人工智能输出协助您草拟或检查工作。不要把它视为最终决定。

---

## 2. 这可能造成什么代价

会议记录摘要可能把已讨论或延期项目记录为已批准、指派错误负责人、遗漏条件，或把未解决问题变成决定。如团队未把摘要与原始笔记及会议实际权限比较便采取行动，机构可能作出未经授权的承诺，或需要撤回已开始的工作。

---

## 3. 如何审核这个输出

批准人工智能输出前，请使用以下检查。不要只因输出读起来流畅便批准。

---

### 3.1 审核设置

1. 把原始会议笔记与人工智能摘要并排打开。
2. 对摘要中的每项决定、行动项目及行动负责人，在原始笔记中找出相应记录，并确认状态、负责人及范围完全一致。
3. 特别留意延期项目、有条件批准，以及会议只有讨论而没有正式决定的任何项目。
4. 不要凭记忆审核摘要。出席会议的人最有可能遗漏这类错误，而不是最不可能。

---

### 3.2 批准前 — 一项检查

> **是否已有出席本次会议的人在打开原始文件的情况下，把本摘要中的每项决定、行动项目及行动负责人与原始笔记比较 — 而不是凭记忆？**

---

### 3.3 针对风险的审核检查

这些检查把 [[人工审核风险库]] 中的最低审核责任调整至本任务。

- **[[人工审核风险库#4.2 内部人士盲点|内部人士盲点]]：** 把每项决定、限制、行动负责人、到期日、状态、未解决问题及发布边界与原始笔记或录音比较。使用局外人测试：摘要必须让没有出席会议的读者也能理解。
- **[[人工审核风险库#4.4 自动化松懈|自动化松懈]]：** 即使较早摘要准确，也确认仍采用相同的完整来源比较及批准标准。指派具名审核者，不要因工作流程已成例行而减少核查。
- **[[人工审核风险库#4.8 无法感知的缺失语境|无法感知的缺失语境]]：** 检查先前决定、本地限制、关系情境、持份者敏感事项、资料质素疑虑或其他缺失事实，是否可能改变摘要的意思、发布范围或所需行动。决定是否加入安全语境、保留仅供审核者使用的备注、向负责人核对或升级处理。
- **[[人工审核风险库#4.9 先前上下文悄然丢失|先前上下文悄然丢失]]：** 确认当前指示及来源资料包仍包含会议目的、相关先前决定、术语、排除项目、来源限制、发布规则及批准边界。把最终摘要与这些要求比较，不要依赖较早的聊天语境。
- **[[人工审核风险库#4.12 无权批准|无权批准]]：** 把每项所述决定、批准、承诺、义务、期限、退款、政策立场或公开声明与原始笔记及实际决策负责人核对。重新措辞被呈现为已批准决定的建议或提案。

---

### 3.4 审核者决策

完成上述针对本任务的审核检查后，使用 [[审核者决策卡]] 选择一项结果：

- **原样批准**
- **更正后批准**
- **停止并升级处理**

如审核者欠缺本任务所需的角色、证据、权限、能力、来源访问权、语境或已批准流程，不要批准输出。

---

### 3.5 本任务的审核方法

以下审核指示已针对本任务调整。它们把 [[人工审核模式]] 中的可重用方法应用于这里涉及的实际来源、决定、人士及后果。

- **来源比较审核：** 把每项决定、提案、反对、延期、行动负责人、期限及批准状态与原始笔记及任何已批准先前决定摘录比较。
  - 留意：把讨论变成协议、错误归因、遗漏限制、以猜测解决不清晰负责人，或没有来源便引入先前语境。
  - 时间：传阅或用作正式会议记录前。
  - 审核者：会议主席、记录员，或对正式记录负责的人。

- **以人工判断为本的审核：** 检查摘要是否符合实际参与者的理解，包括默认协议、关系情境、目前敏感事项，以及刻意没有定稿或传阅的事项。
  - 留意：文字上看似合理，但内部人士知道具有误导性、不完整、不敏感或与会议实际运作不一致的摘要。
  - 时间：传阅前。
  - 审核者：会议负责人，或具有足够语境及身分的参与者。

- **隐私 / 资料边界审核：** 决定每个版本及受众可出现哪些敏感、人力资源、牧养、受益人、财务或机密内容。
  - 留意：没有获授权理由便把受限制细节带入董事会、职员、志愿者或公开摘要。
  - 时间：提示前及每个版本传阅前。
  - 审核者：资料负责人、会议主席、具人力资源 / 私隐意识的审核者或获授权经理。

- **范围、权限及可行性审核：** 确认摘要没有把建议或讨论变成获授权决定或承诺。
  - 留意：无权批准、暗示已批准预算，或把行动指派至超出具名负责人角色的范围。
  - 时间：摘要被视为正式记录或指示前。
  - 审核者：决策负责人、会议主席或获授权批准者。

## 4. 何时应升级处理而不是批准

- 如输出影响法律、人力资源、财务、安全保障、医疗、法规、对外或高影响决定，而审核者没有确认安全使用所需的权限、能力、语境、来源访问权或已批准流程，应在使用前升级处理。
- 如摘要会影响决策、批准、资助、人力资源、法律或管治行动，而审核者未获授权或没有足够资料确认内容，应升级处理。
- 如来源本身不清晰、过时、缺失或与另一个已批准来源冲突，应升级处理。

## 5. 提示前

使用人工智能处理本任务前，先检查以下基本事项：
- 目的清晰。
- 输入不包含不应输入工具的个人或机密资料。
- 有负责人可在使用人工智能输出前检查它。
- 任务没有要求人工智能作出决定、提供专业意见或充当最终权威。

- 确认本任务符合批准级别：**非机密情况下一般可批准使用**。
- 确认计划中的审核者能完成所需人工审核：**是 — 检查准确性、归因及行动负责人**。

---

## 6. 人工智能盲点重点

**风险重点：** 默认同意差距

**提示词重点：** 提示前，向人工智能提供会议目的、摘要受众、决策规则、行动负责人格式、批准流程，以及未解决项目是否必须维持未解决。要求它标记有关决定、批准、反对、延期及行动负责人的假设。

**人工审核重点：** 审核者应按笔记核对每项决定、行动负责人、期限、反对、延期及批准状态。不要让人工智能把讨论变成协议，或把沉默变成批准。

**较深入的盲点审核：** 如摘要取决于是否真正达成讨论、协议、反对、延期或正式批准，请沿 [[如何使用本指南#6.1 Win.Win 人工智能盲点指南|Win.Win 人工智能盲点指南路径]] 进行。

**不要只依赖：** 会议记录摘要的整洁程度。整洁的行动清单可能隐藏未解决分歧或未获批准的决定。

## 8. 主要风险

- **[[风险分类#3.3 语境 / 细微差别 / 压缩|语境 / 细微差别 / 压缩]]：[[人工审核风险库#4.2 内部人士盲点|内部人士盲点]]（高）** — 审核人工智能会议记录摘要的人曾在会议现场。他们知道原意、知道同意了什么，也知道语境。当人工智能遗漏限制或夸大结论时，审核者会不自觉地从记忆中补正 — 因为他们知道应该有什么。摘要因此通过审核，但错误仍留给所有没有出席会议、也没有记忆填补缺口的其他读者。这不是注意力失误，而是可预期的位置失误：最适合审核摘要的人，反而最难看见其中错误。

## 9. 其他需注意风险

- **[[风险分类#3.11 人工智能盲点 / 语境风险|人工智能盲点 / 语境风险]]：默认同意差距 — 相关审核风险：[[人工审核风险库#4.14 未成文语境差距|未成文语境差距]]（高）** — 除非笔记写得清楚，人工智能可能无法区分讨论、支持、反对、延期及正式批准。会议中的人可能记得差异，但摘要仍必须按记录核对。
- **[[风险分类#3.2 来源依据 / 证据|来源依据 / 证据]]：归因混淆（高）** — 人工智能可能对调姓名或把行动项目指派给错误的人，尤其姓名相似或讨论节奏很快时。认得姓名的审核者可能快速略过而错失错误。
- **牧养 / 神学 / 圣经：资料越界（高）** — 同一次会议的笔记往往同时包含公开更新、内部营运事项，以及敏感的牧养 / 神学或人力资源项目。人工智能未必能按预定受众及存取边界安全而一致地分类这些内容。供广泛传阅的摘要可能包含只应发给特定人士的项目。
- **牧养 / 神学 / 圣经：缺乏责任归属的敏感细节（高）** — 如个人、牧养 / 神学或机密细节未提供给人工智能提示词，必须由具名人士人手把它们加回适合相应受众的正确版本。如没有事先记录隐去什么及由谁负责这一步骤，这项责任便会消失。
- **[[风险分类#3.3 语境 / 细微差别 / 压缩|语境 / 细微差别 / 压缩]]：先前会议的语境差距 — 相关审核风险：[[人工审核风险库#4.14 未成文语境差距|未成文语境差距]]（中）** — 人工智能只知道当前提示词中的内容，不知道先前会议作出的决定。摘要对本次会议在技术上可能准确，却因缺少先前语境而具误导性。
- **[[风险分类#3.6 权限 / 范围 / 承诺|权限 / 范围 / 承诺]]：[[人工审核风险库#4.12 无权批准|无权批准]]（高）** — 审核者可能能够核查摘要是否符合笔记，但仍没有权限批准摘要所暗示的决定、承诺、管治行动或公开通讯。
- **[[风险分类#3.12 运营可行性 / 工作流程|运营可行性 / 工作流程]]：[[人工审核风险库#4.4 自动化松懈|自动化松懈]]（中）** — 当会议记录摘要反覆产生时，因为以往人工智能摘要看似可靠，审核者可能逐渐停止按原始笔记核查每项决定、行动负责人及延期项目。
- **[[风险分类#3.3 语境 / 细微差别 / 压缩|语境 / 细微差别 / 压缩]]：[[人工审核风险库#4.8 无法感知的缺失语境|无法感知的缺失语境]]（高）** — 先前决定、非正式限制、持份者敏感事项或其他事实等重要语境，可能未出现在笔记、提示词或审核基础中。审核者必须判断缺失语境是否改变摘要的适切性、意思、风险或所需处理，以及应否安全加入、保留在仅供审核者使用的备注、向适当负责人核对或升级处理。
- **[[风险分类#3.3 语境 / 细微差别 / 压缩|语境 / 细微差别 / 压缩]]：[[人工审核风险库#4.9 先前上下文悄然丢失|先前上下文悄然丢失]]（高）** — 在用于多份会议记录摘要的长对话中，使用者可能依赖很早之前说明的决定、限制、批准边界或来源限制。如这些内容已不在产生摘要所用的即时指示或来源材料中，后续输出可能遗漏或与之矛盾。

## 10. 要加入的提示词强化

先从 Win.Win 人工智能必备的基础提示词模式开始。以下附加项已针对本任务调整。

只使用与实际情况相符的行。不要只因某项控制出现在 [[提示词强化模式]] 便加入无关控制。对于主要须通过人工审核、已批准工具、专业检查、其他缓解措施或升级处理的风险，不要创建提示词附加项。

把来源材料、笔记、政策摘录、数字及文件放在基础提示词最后的 **内容** 部分。
