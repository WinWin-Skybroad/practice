# 研究香港相关主题

## 1. 这个应用案例是什么

当您希望人工智能协助以下工作时，请使用本页：**研究香港特定主题**。

- 常见使用者：**教会、非营利机构、中小企业**。
- 批准级别：**谨慎使用**。
- 需要人工审核：**是 — 按香港官方来源核实**。
- 使用人工智能输出协助您草拟或检查工作。不要把它视为最终决定。

---

## 2. 这可能造成什么代价

以香港为重点的研究答案可能依赖过时政策立场、遗漏中文官方材料，或混合香港与海外假设。如果未核查官方来源及日期便把答案视为现行资料，机构可能按错误基础规划、申请、沟通或作出决定。

---

## 3. 如何审核这个输出

批准人工智能输出前，请使用以下检查。不要只因输出读起来流畅便批准。

---

### 3.1 审核设置

1. 列出输出中每项具名政策、计划、资格准则及官方机构。
2. 就每一项直接前往相关政府或监管机构网站。
3. 检查任何政策或指引的生效日期或最后更新日期。
4. 如官方网站未能确认资料，把人工智能输出视为未核实。

---

### 3.2 批准前 — 一项检查

> **本输出中的每项政策立场、计划要求及官方指引，是否已直接按现行官方政府或监管机构网站核实 — 而不是按人工智能输出或一般搜寻结果核实？**

---

### 3.3 针对风险的审核检查

这些检查把 [[人工审核风险库]] 中的最低审核责任调整至本任务。

- **[[人工审核风险库#4.23 本地或特定管辖区盲点|本地或特定管辖区盲点]]：** 按现行香港官方或权威来源，以及实际机构、界别、地区、受众及期间，核查每项重要声称。核实双语术语，并排除不适用的中国内地、海外或一般性假设。

---

### 3.4 审核者决策

完成上述针对本任务的审核检查后，使用 [[审核者决策卡]] 选择一项结果：

- **原样批准**
- **更正后批准**
- **停止并升级处理**

如审核者欠缺本任务所需的角色、证据、权限、能力、来源访问权、语境或已批准流程，不要批准输出。

---

### 3.5 本任务的审核方法

以下审核指示已针对本任务调整。它们把 [[人工审核模式]] 中的可重用方法应用于这里涉及的实际来源、决定、人士及后果。

- **来源及事实核实：** 按现行香港官方来源、本地机构、原始记录或可靠香港证据核实重要声称。
  - 留意：中国内地或海外预设、过时香港政策、缺乏支持的本地声称，以及不适用于所述界别或期间的来源。
  - 时机：研究被分享或依赖前。
  - 审核者：香港主题负责人、研究人员或来源核对审核者。

- **双语 / 本地化审核：** 按权威本地来源核查英文及中文名称、官方术语、机构名称、法律 / 法规术语，以及香港语言用法。
  - 留意：中国内地术语、简繁字混用、机构名称误译，或英文与中文术语指向不同概念。
  - 时机：发布或对外使用前。
  - 审核者：熟悉香港术语的合资格双语审核者。

- **以人工判断为本的审核：** 检查研究是否符合实际香港机构、界别、社群、地区、受众及预定用途，而不是只符合一般性的香港描述。
  - 留意：事实上看似合理，却遗漏本地机构实务、现行情境或真正受影响受众的答案。
  - 时机：用于决策前。
  - 审核者：本地主题负责人、机构负责人或具相关香港经验的人员。

## 4. 何时应升级处理而不是批准

- 如输出影响法律、人力资源、财务、安全保障、医疗、法规、对外或高影响决定，而审核者没有确认安全使用所需的权限、能力、语境、来源访问权或已批准流程，应在使用前升级处理。
- 如审核者没有资格或权限确认专业意思，法律、医疗、财务、技术或公开翻译应升级处理。
- 法律、法规、雇佣、PDPO（《个人资料（私隐）条例》）、合同、合规或权利 / 义务问题，除非审核者在已批准流程下明确获授权且有能力确认，否则应升级处理。
- 每当涉及个人资料、人力资源、牧养、神学、医疗、财务、HKID（香港身份证号码）、受益人或机密资料，而审核者没有确认安全使用所需的权限、语境、来源访问权或已批准流程时，均应升级处理。

## 5. 提示前

使用人工智能处理本任务前，先检查以下基本事项：
- 目的清晰。
- 输入不包含不应输入工具的个人或机密资料。
- 有负责人可在使用人工智能输出前检查它。
- 任务没有要求人工智能作出决定、提供专业意见或充当最终权威。

- 确认本任务符合批准级别：**谨慎使用**。
- 确认预定审核者可以完成所需人工审核：**是 — 按香港官方来源核实**。

---

## 6. 人工智能盲点重点

**风险重点：** 本地机构语境差距

**提示词重点：** 提示前，向人工智能提供香港特定问题、管辖区、日期敏感度、首选官方来源、中英文来源要求、机构类型及预定用途。要求它标记香港特定假设，以及需要官方来源核实的项目。

**人工审核重点：** 按现行香港官方或权威来源核实。检查人工智能有否引入非香港假设、遗漏中文材料，或把本地机构问题当作一般主题。

**较深入的盲点审核：** 如答案可能取决于香港特定机构、中文来源、本地实务、现行政府情境或特定管辖区含义，请沿 [[如何使用本指南#6.1 Win.Win 人工智能盲点指南|Win.Win 人工智能盲点指南路径]] 进行。

**不要只依赖：** 一般专业知识。香港特定工作可能取决于本地机构、双语来源、现行实务及官方措辞。

## 8. 主要风险

- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：香港涵盖及时效差距（高）** — 香港特定的政策、机构、法律及法规材料可能分别记录于英文及中文官方来源，并可能随时间改变。人工智能可能提供不完整、过时、误译或跨管辖区的资料而没有标示差距。把香港特定研究视为核查相关语言现行官方来源的起点，而不是最终答案。

## 9. 其他需注意风险

- **[[风险分类#3.11 人工智能盲点 / 语境风险|人工智能盲点 / 语境风险]]：本地机构语境差距 — 相关审核风险：[[人工审核风险库#4.23 本地或特定管辖区盲点|本地或特定管辖区盲点]]（高）** — 人工智能可能知道一般概念，却遗漏香港特定机构实务、双语官方术语、现行政府指引或界别特定解读。
- **[[风险分类#3.9 法律 / 法规 / 合规|法律 / 法规 / 合规]]：中国内地预设 — 相关审核风险：[[人工审核风险库#4.23 本地或特定管辖区盲点|本地或特定管辖区盲点]]（高）** — 法规、法律及文化内容可能引入中国内地术语、假设或机构参考，尤其当查询使用简体中文，或没有明确说明香港情境时。香港与中国内地具有不同的法律、治理及机构情境。
- **[[风险分类#3.4 隐私 / 机密性 / 资料边界|隐私 / 机密性 / 资料边界]]：过时香港政策及法例（高）** — 香港条例及政策会不时改变。人工智能训练资料可能没有反映近期条例修订、新的 PCPD（个人资料私隐专员公署）指引、更新的 证监会或 HKMA（香港金融管理局）要求，或政府架构变动。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：中英文术语不匹配（中）** — 香港官方英文及繁体中文术语，与英国英语对应用语及中国内地中文对应用语均可能不同。人工智能可能使用错误术语，而审核者未必能察觉。

## 11. 其他缓解措施

- 流畅文字可能掩盖意思漂移；双语审核必须比较来源及目标文本，而不是只阅读目标文本。
- 如敏感资料已输入未获批准的工具，审核输出无法撤销泄露。应按照隐私 / 事故处理流程升级处理。
