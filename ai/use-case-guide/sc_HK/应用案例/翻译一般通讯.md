# 翻译一般通讯

## 1. 这个应用案例是什么

当您希望人工智能协助**翻译一般通讯**时，请使用本页。

- 常见使用者：**教会、非营利机构、中小企业**。
- 批准级别：**谨慎使用**。
- 需要人工审核：**是 — 需要合资格双语审核者**。
- 使用人工智能输出协助您草拟或检查工作。不要把它视为最终决定。

---

## 2. 这可能造成什么代价

翻译可能以较广泛的日常用语取代法律、技术、安全保障或机构术语，改变读者必须提供、执行或理解的内容。如没有合资格双语审核者比较来源及目标版本，流程可能需要重做，而机构可能发出不一致或具误导性的指示。

---

## 3. 如何审核这个输出

批准人工智能输出前，请使用以下检查。不要只因输出读起来流畅便批准。

---

### 3.1 审核设置

1. 把来源及翻译并排阅读。
2. 识别每个具有法律、法规或技术意义的术语 — 不要依赖整体流畅度来发现这些问题。
3. 对每个这类术语，确认繁体中文对应词在香港语境中具有正确法律或技术含义。流畅不等于正确。
4. 如文件对收件人具有法律后果，应升级至具相关领域资格的审核者，而不只是具语言能力的人。

---

### 3.2 批准前 — 一项检查

> **是否已有熟悉相关领域的双语审核者 — 而不只是语言流利的人 — 确认每个法律术语、技术术语及具有正式后果的短语，在繁体中文中与英文来源具有相同法律份量及含义？**

---

### 3.3 针对风险的审核检查

这些检查把 [[人工审核风险库]] 中的最低审核责任调整至本任务。

- **[[人工审核风险库#4.11 流畅度错觉|流畅度错觉]]：** 逐行比较翻译与来源的意思、事实、限制、语气、权限、术语、格式及遗漏。不要只因读起来自然或专业便批准。
- **[[人工审核风险库#4.15 读者解读差距|读者解读差距]]：** 检查每个具名读者群体可能如何理解翻译后的语气、确定程度、权限、承诺、拒绝、批准及所需行动。更正可能被理解为与来源意图不同的措辞。
- **[[人工审核风险库#4.23 本地或特定管辖区盲点|本地或特定管辖区盲点]]：** 检查翻译是否取决于香港或另一具名管辖区、界别、机构或本地情境。按现行权威来源或适当本地审核者核实官方术语、本地规则及机构含义。

---

### 3.4 审核者决策

完成上述针对本任务的审核检查后，使用 [[审核者决策卡]] 选择一项结果：

- **原样批准**
- **更正后批准**
- **停止并升级处理**

如审核者欠缺本任务所需的角色、证据、权限、能力、来源访问权、语境或已批准流程，不要批准输出。

---

### 3.5 本任务的审核方法

以下审核指示已针对本任务调整。它们把 [[人工审核模式]] 中的可重用方法应用于这里涉及的实际来源、决定、人士及后果。

- **双语 / 本地化审核：** 逐行比较翻译与来源的意思、遗漏、增加内容、术语、名称、字体、格式及香港用法。
  - 留意：改变意思的流畅措辞、未翻译文字、简繁字混用、术语不一致，或改变讯息的格式。
  - 时间：发送或发布前。
  - 审核者：熟悉受众及香港用法的合资格双语审核者。

- **以人工判断为本的审核：** 以实际收件人的角度阅读翻译，检查语气、正式程度、礼貌程度、暗示的权限、所需行动及可能解读。
  - 留意：对真实关系及渠道而言，听起来过强、冷淡、随便、官方、不敏感或含糊的直译。
  - 时间：发送或发布前。
  - 审核者：双语、文化或了解受众的审核者。

- **合资格法律 / 合规审核：** 如来源包含法律、法规、人力资源、医疗、财务、牧养、技术或其他专业含义，除双语审核外亦须取得相关专业审核。
  - 留意：一般语言正确，但专业含义或管辖区效力错误。
  - 时间：专业内容被依赖或发布前。
  - 审核者：相关合资格专业人士及双语审核者。

- **工具 / 流程治理审核：** 如使用多于一个模型或翻译步骤，确认已批准模型 / 工具、版本、来源档案、术语表及比较工作流程。
  - 留意：模型替换、来源漂移、不同术语基础，或没有记录审核了哪个输出。
  - 时间：翻译工作流程之前及期间。
  - 审核者：翻译负责人、工具负责人或管治审核者。

---

## 4. 何时应升级处理而不是批准

- 如输出影响法律、人力资源、财务、安全保障、医疗、法规、对外或高影响决定，而审核者没有确认安全使用所需的权限、能力、语境、来源访问权或已批准流程，应在使用前升级处理。
- 法律、法规、雇佣、PDPO（《个人资料（私隐）条例》）、合同、合规或权利 / 义务问题，除非审核者在已批准流程下明确获授权且有能力确认，否则应升级处理。
- 如审核者没有资格或权限确认专业意思，法律、医疗、财务、技术或公开翻译应升级处理。

## 5. 提示前

使用人工智能处理本任务前，先检查以下基本事项：
- 目的清晰。
- 输入不包含不应输入工具的个人或机密资料。
- 有负责人可在使用人工智能输出前检查它。
- 任务没有要求人工智能作出决定、提供专业意见或充当最终权威。

- 确认本任务符合批准级别：**谨慎使用**。
- 确认计划中的审核者能完成所需人工审核：**是 — 需要合资格双语审核者**。

---

## 6. 人工智能盲点重点

**风险重点：** 读者解读差距

**提示词重点：** 提示前，向人工智能提供预定受众、渠道、目的、关系、地区版本、语气、术语偏好及所需行动。要求它识别可能被误解、听起来比原意更强、暗示权限或承诺、改变正式程度、显得不敏感或令读者困惑的措辞。

**人工审核重点：** 把来源及翻译并排比较，然后从目标读者角度阅读。检查意思、语域、文化适切性、名称、日期、义务，以及翻译是否改变机构所表达的内容。

**较深入的盲点审核：** 如翻译取决于读者解读、本地语域、机构含义、正式程度，或流利但不了解内情的翻译可能遗漏的术语，请沿 [[如何使用本指南#6.1 Win.Win 人工智能盲点指南|Win.Win 人工智能盲点指南路径]] 进行。

**不要只依赖：** 字面准确或流畅措辞。真实读者对语气、义务或权限的理解可能与发件人原意不同。

## 8. 主要风险

- **[[风险分类#3.9 法律 / 法规 / 合规|法律 / 法规 / 合规]]：[[人工审核风险库#4.11 流畅度错觉|流畅度错觉]]（高）** — 听起来自然的翻译可能被视为正确，即使在需要特定香港法律或法规术语的地方使用了一般中文表达。除非使用任务所需的双语、本地化、法律及其他审核模式独立核查输出，流畅措辞可能掩盖法律份量、义务或权益的改变。

## 9. 其他需注意风险

- **[[风险分类#3.11 人工智能盲点 / 语境风险|人工智能盲点 / 语境风险]]：[[人工审核风险库#4.15 读者解读差距|读者解读差距]]（中）** — 人工智能可能选择技术上正确的自然措辞，却改变读者对语气、义务、正式程度或机构含义的理解。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：简繁字混用（中）** — 人工智能可能把简体中文字加入繁体中文文件，反之亦然。不能流利分辨两种字体的审核者可能看不到这个问题。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：翻译过程格式丧失（低）** — 翻译模型会把语义准确性优先于结构保留。标题、项目符号、粗体文字及表格格式可能遗失或改变。除内容核查外，还需要另行按原文检查格式。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：未翻译的英文词语（低）** — 人工智能可能把英文词语留在中文文字中而没有翻译。快速阅读时很容易遗漏，因为周围中文看似正确，视线会跳过熟悉的英文词语。
- **[[风险分类#3.9 法律 / 法规 / 合规|法律 / 法规 / 合规]]：管辖权不匹配 — 相关审核风险：[[人工审核风险库#4.23 本地或特定管辖区盲点|本地或特定管辖区盲点]]（高）** — 简体中文输出可能引入中国内地术语、法律假设或机构参考，尤其没有明确说明香港管辖区时。即使是供香港使用的简体中文内容，也应说明香港管辖区；如法律或法规含义重要，应按香港官方术语及现行来源核查。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：术语不一致（中）** — 提供术语翻译表可减少不一致，但不能完全消除。模型会解读指示 — 并非机械式执行。翻译后需要逐项针对术语核实。
- **[[风险分类#3.8 双语 / 本地化 / 香港语境|双语 / 本地化 / 香港语境]]：多模型审查期间的模型替换（中）** — 如同时向审核模型提供多份来源文件，模型可能自行选择权威来源，而不是指定来源，令格式正确但术语错误。

## 11. 其他缓解措施

- 流畅文字可能掩盖意思漂移；双语审核必须比较来源及目标文本，而不是只阅读目标文本。
- 内容审核无法修正错误的工具、账户或资料流程。使用输出前先修正流程。
