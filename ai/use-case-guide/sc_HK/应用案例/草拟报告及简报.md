# 草拟报告及简报

## 1. 这个应用案例是什么

当您希望人工智能协助**草拟报告、建议书或简报**时，请使用本页。

- 常见用户：**中小企业、非营利机构**。
- 批准级别：**非机密情况下一般可批准使用**。
- 需要人工审核：**是 — 作者在定稿前审核**。
- 使用人工智能输出协助您草拟或检查工作。不要把它视为最终决定。

---

## 2. 这可能造成什么代价

报告或简报可能把数字错置、加入缺乏依据的统计数据、遗漏限制条件，或令建议听起来比证据更确定。由于结构及总数看似合理，在有人把每项重要声称追溯至来源之前，错误可能已影响董事会、客户、资助方或管理层决定。

---

## 3. 如何审核这个输出

批准人工智能输出前，请使用以下检查。不要只因输出读起来流畅便批准。

---

### 3.1 审核设置

1. 把来源资料与报告并排打开。
2. 按来源逐格核对每个表格中的每项数字。不要只阅读整体意思。
3. 检查叙述文字中的数字与表格中的数字一致。人工智能有时会令正文与表格之间出现不一致。
4. 对任何无法追溯至特定来源的数字，在传阅前标记为未核实。

---

### 3.2 批准前 — 一项检查

> **本报告中的每项数字是否已按来源资料逐格比较 — 不是只阅读整体是否合理，而是逐栏核查？**

---

### 3.3 针对风险的审核检查

这些检查把 [[人工审核风险库]] 中的最低审核责任调整至本任务。

- **[[人工审核风险库#4.13 人工智能盲点|人工智能盲点]]：** 输出是否符合任务背后真实的人、真实情况、真实权限及真实后果，包括人工智能未获告知的默会情境，以及无法完全化约为提示词的生活经验或专业判断。
  - **就本应用案例而言：** 按实际持份者、决策目的、机构语境、批准权限、政治或关系敏感度，以及决策者依赖简报的后果核查报告。
- **[[人工审核风险库#4.18 重要性判断差距|重要性判断差距]]：** 识别可能改变决定的数字、条件、限制、差异、不确定性、门槛及遗漏。检查重要资料仍然清晰可见并获适当权重，且次要资料没有被视为决定性因素。

---

### 3.4 审核者决策

完成上述针对本任务的审核检查后，使用 [[审核者决策卡]] 选择一项结果：

- **原样批准**
- **更正后批准**
- **停止并升级处理**

如审核者欠缺本任务所需的角色、证据、权限、能力、来源访问权、语境或已批准流程，不要批准输出。

---

### 3.5 本任务的审核方法

以下审核指示已针对本任务调整。它们把 [[人工审核模式]] 中的可重用方法应用于这里涉及的实际来源、决定、人士及后果。

- **来源及事实核实：** 按已批准证据核实每项事实声称、统计数据、日期、引文、比较及引用来源。
  - 留意：捏造或过时的统计数据、缺乏依据的因果声称，以及强于来源所支持程度的结论。
  - 时间：传阅、简报或用于决策前。
  - 审核者：作者、主题负责人或来源核查审核者。

- **提取资料核实：** 把数字、总额、百分比、标签、期间及图表输入与已批准试算表或来源记录核对一致。
  - 留意：分母错误、期间混合、栏位错置、总额不一致，或图表标签与资料不符。
  - 时间：图表或数字定稿前。
  - 审核者：资料负责人、财务审核者、分析员或负责作者。

- **一般输出审核：** 检查报告或简报是否回答预定问题、适合受众、区分事实与解读，并清楚保留重要限制。
  - 留意：看似完善的叙述是否隐藏不确定性、夸大信心，或给予次要事项比重要事项更高权重。
  - 时间：批准或简报前。
  - 审核者：报告负责人、决策负责人或负责简报者。

- **隐私 / 资料边界审核：** 检查来源档案、摘录、图表、引文、图片及发布范围有否个人、机密、受限制或第三方内容。
  - 留意：可识别资料、机密细节、未经许可复制的材料，或超出批准范围的传阅。
  - 时间：提示前及传阅前。
  - 审核者：资料负责人、具私隐意识的审核者或获授权发布者。

## 4. 何时应升级处理而不是批准

- 如输出影响法律、人力资源、财务、安全保障、医疗、法规、对外或高影响决定，而审核者没有确认安全使用所需的权限、能力、语境、来源访问权或已批准流程，应在使用前升级处理。
- 如输出可能影响雇佣、薪酬、发票、福利、安全保障、医疗、牧养 / 神学、财务或专业责任，而审核者未获授权或没有能力确认有关事项，应升级处理。
- 如措辞涉及弱势群体、文化、危机、投诉或公众声誉，而审核者欠缺确认安全使用所需的语境、权限或已批准流程，应升级处理。
- 如声称影响法律、财务、牧养、神学、公众或外部决策，而审核者未获授权或不具能力确认，应升级处理。
- 如输出可能约束机构、影响权利 / 义务，或看似官方批准，而审核者没有权限确认该效果，应升级处理。
- 每当涉及个人资料、人力资源、牧养、神学、医疗、财务、HKID（香港身份证号码）、受益人或机密资料，而审核者没有确认安全使用所需的权限、语境、来源访问权或已批准流程时，均应升级处理。

## 5. 提示前

使用人工智能处理本任务前，先检查以下基本事项：
- 目的清晰。
- 输入不包含不应输入工具的个人或机密资料。
- 有负责人可在使用人工智能输出前检查它。
- 任务没有要求人工智能作出决定、提供专业意见或充当最终权威。

- 确认本任务符合批准级别：**非机密情况下一般可批准使用**。
- 确认计划中的审核者能完成所需人工审核：**是 — 作者在定稿前审核**。

## 6. 人工智能盲点重点

**风险重点：** 重要性判断差距

**提示词重点：** 提示前，向人工智能提供受众、决策目的、来源资料、日期范围、限制条件、批准状态，以及不得夸大的事项。要求它识别假设、缺失证据，以及需要确认的决策关键数字、限制条件或局限。

**人工审核重点：** 审核者应检查数字、限制条件、局限、来源日期、重要遗漏，以及草稿是否改变决策者会相信或批准的内容。

**较深入的盲点审核：** 如报告支援决策，并可能取决于限制条件、缺失数字、受众政治因素，或只有相关领域审核者才能判断的重要细节，请沿 [[如何使用本指南#6.1 Win.Win 人工智能盲点指南|Win.Win 人工智能盲点指南路径]] 进行。

**不要只依赖：** 完善外观或结构。报告可能看似完整，却遗漏会改变决定的细节。

## 8. 主要风险

- **[[风险分类#3.10 专业 / 人力资源 / 财务边界|专业 / 人力资源 / 财务边界]]：缺乏支持或误读的统计数据（高）** — 在报告及简报中，人工智能可能从一般模型知识产生看似合理但不在所提供来源中的统计数据，或把来源材料中的数字错置、误读或前后不一致地重复。只检查论点及格式的审核者可能遗漏错误。每项重要数字都必须追溯至已批准来源。

## 9. 其他需注意风险

- **[[风险分类#3.11 人工智能盲点 / 语境风险|人工智能盲点 / 语境风险]]：[[人工审核风险库#4.18 重要性判断差距|重要性判断差距]]（高）** — 人工智能可能错判数字、条件、限制、差异、不确定性或持份者关注的重要程度。它可能遗漏或弱化重要事项、给予次要事项过高权重，或把不确定资料视为决定性因素，令报告的重点、结论、建议、语气、批准路线或下一步行动不合适。
- **[[风险分类#3.7 语气 / 表述 / 文化敏感度|语气 / 表述 / 文化敏感度]]：虚假自信语气（高）** — 人工智能草拟的报告及建议书倾向以自信措辞呈现不确定资料。人工智能产生的专业文件往往不足以呈现不确定性、风险限制及限定条件。
- **[[风险分类#3.1 准确性 / 幻觉|准确性 / 幻觉]]：缺失机构语境 — 相关审核风险：[[人工审核风险库#4.14 未成文语境差距|未成文语境差距]]（中）** — 除非通过已批准来源提供相关语境，否则不应假定人工智能知道内部优先事项、预算限制、政治动态或关系历史。建议书在逻辑上可能合理，却不适合它所针对的特定机构情况。
- **[[风险分类#3.6 权限 / 范围 / 承诺|权限 / 范围 / 承诺]]：无法履行的承诺（高）** — 人工智能可能草拟包括机构无法履行的承诺 — 时间表、资源、输出。审核者可能集中于内容质素而忽略可行性。
- **[[风险分类#3.4 隐私 / 机密性 / 资料边界|隐私 / 机密性 / 资料边界]]：知识产权及署名风险（中）** — 人工智能可能产生与来源材料非常相似的措辞、结构、图片或意念，却没有可靠的署名或许可资料。因此，已发布或面向客户的内容可能产生署名、许可、合约、声誉或法律疑虑；如属重要事项，需进行来源核查及合资格审核。

先从 Win.Win 人工智能必备的基础提示词模式开始。以下附加项已针对本任务调整。

把来源材料、笔记、政策摘录、数字及文件放在基础提示词最后的 **内容** 部分。

## 11. 其他缓解措施

- 人工审核必须包括欺诈 / 真实性核查；不得只依赖人工智能提取来判断文件是否已被篡改。
- 审核的强度取决于所核对的来源。对法律、医疗、财务或法规声称，应升级至合资格审核。
- 人工审核可降低风险，但不能保证准确。保留记录并使用已批准工具。
- 如敏感资料已输入未获批准的工具，审核输出无法撤销泄露。应按照隐私 / 事故处理流程升级处理。
