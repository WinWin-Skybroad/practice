# 草拟资助申请

## 1. 这个应用案例是什么

当您希望人工智能协助**草拟资助申请或资助报告章节**时，请使用本页。

- 常见使用者：**教会、非营利机构、中小企业**。
- 批准级别：**谨慎使用**。
- 需要人工审核：**是 — 核实资助方规则、统计数据及成效声称**。
- 使用人工智能输出协助您草拟或检查工作。不要把它视为最终决定。

---

## 2. 这可能造成什么代价

资助申请草稿可能使用缺乏依据的指标、一般资助申请写作假设或过时的资助方要求，而不是现行申请材料及机构本身的证据。申请因而可能包含不准确声称、遗漏必要项目，或承诺机构无法支援的交付，导致延误、被拒、重做或损害可信度。

---

## 3. 如何审核这个输出

批准人工智能输出前，请使用以下检查。不要只因输出读起来流畅便批准。

---

### 3.1 审核设置

1. 把资助方现行申请指引与草稿并排打开。
2. 按指引核对每个必要章节、字数限制、资格准则及提交格式。
3. 按机构本身记录或公开可得的香港资料核实每项指标及统计数据 — 不要按人工智能输出核实。
4. 移除任何无法追溯至特定可核实来源的数字或声称。

---

### 3.2 批准前 — 一项检查

> **本申请中的每项指标、资格声称、资助方规则及必要章节，是否已按资助方现行已发布指引及机构本身的计划资料核实 — 而不是取自人工智能的一般知识？**

---

### 3.3 审核者决策

完成上述针对本任务的审核检查后，使用 [[审核者决策卡]] 选择一项结果：

- **原样批准**
- **更正后批准**
- **停止并升级处理**

如审核者欠缺本任务所需的角色、证据、权限、能力、来源访问权、语境或已批准流程，不要批准输出。

---

### 3.4 本任务的审核方法

以下审核指示已针对本任务调整。它们把 [[人工审核模式]] 中的可重用方法应用于这里涉及的实际来源、决定、人士及后果。

- **来源及事实核实：** 按资助方现行文件及已批准记录，核查每项资格声明、资助方规则、期限、成果声称、统计数据、引文及机构事实。
  - 留意：虚构的资助方偏好、缺乏依据的成效声称、过时期限，以及强于证据所支持程度的声称。
  - 时间：提交前。
  - 审核者：资助申请负责人、来源核查审核者，或对申请负责的人。

- **提取资料核实：** 把每项预算数字、总额、日期、受益人人数、目标及已报告结果与已批准试算表或记录核对一致。
  - 留意：数字错置、期间错误、重复计算、无法对数的总额，或把预测数字呈现为实际数字。
  - 时间：提交前，以及任何财务报告签署前。
  - 审核者：财务审核者、资助行政人员或责任资料负责人。

- **一般输出审核：** 检查申请是否回答资助方的实际问题、符合字数限制、区分证据与愿景，并且没有夸大机构能力或关系。
  - 留意：看似完善但通用的答案、缺乏依据的确定语气、不切实际的承诺，或遗漏必要准则。
  - 时间：最终签核前。
  - 审核者：建议书负责人及项目主管。

- **合资格法律 / 合规审核：** 在需要时确认声明、资格、受限制资助条件、资料 / 私隐声明，以及合约或法规承诺。
  - 留意：机构未获授权或不具资格作出的声明或合规陈述。
  - 时间：如涉及法律、法规、合约或合规后果，须在提交前。
  - 审核者：合资格法律 / 合规审核者或获授权机构负责人。

## 4. 何时应升级处理而不是批准

- 如输出影响法律、人力资源、财务、安全保障、医疗、法规、对外或高影响决定，而审核者没有确认安全使用所需的权限、能力、语境、来源访问权或已批准流程，应在使用前升级处理。
- 如来源本身不清晰、过时、缺失或与另一个已批准来源冲突，应升级处理。
- 每当涉及个人资料、人力资源、牧养、神学、医疗、财务、HKID（香港身份证号码）、受益人或机密资料，而审核者没有确认安全使用所需的权限、语境、来源访问权或已批准流程时，均应升级处理。
- 法律、法规、雇佣、PDPO（《个人资料（私隐）条例》）、合同、合规或权利 / 义务问题，除非审核者在已批准流程下明确获授权且有能力确认，否则应升级处理。

---

## 5. 提示前

使用人工智能处理本任务前，先检查以下基本事项：
- 目的清晰。
- 输入不包含不应输入工具的个人或机密资料。
- 有负责人可在使用人工智能输出前检查它。
- 任务没有要求人工智能作出决定、提供专业意见或充当最终权威。

- 确认本任务符合批准级别：**谨慎使用**。
- 确认计划中的审核者能完成所需人工审核：**是 — 核实资助方规则、统计数据及成效声称**。

---

## 6. 人工智能盲点重点

**风险重点：** 资助方关系与申请可行性差距

**提示词重点：** 提示前，向人工智能提供资助方指引、项目事实、预算来源、时间表状态、证据、已确认承诺，以及任何已知资助方关系或过往回馈。要求它标记假设、暂定声称，以及需要来源或负责人确认的项目。

**人工审核重点：** 审核者应检查申请是否反映真实能力、资助方期望、已确认数字及现行承诺。不要让具说服力的措辞把暂定计划变成已确认声称。

**较深入的盲点审核：** 如草稿取决于资助方关系历史、过往回馈、非正式期望、本地评审文化或现实交付限制，请沿 [[如何使用本指南#6.1 Win.Win 人工智能盲点指南|Win.Win 人工智能盲点指南路径]] 进行。

**不要只依赖：** 具说服力的写作。资助申请草稿可以看似值得资助，却同时夸大能力、证据或承诺。

## 8. 主要风险

- **[[风险分类#3.2 来源依据 / 证据|来源依据 / 证据]]：资助方规则捏造（高）** — 资助申请必须遵循就该机会提供的特定现行资助方材料，而不是一般资助申请写作惯例。人工智能可能从其他计划或情境虚构或引入资格规则、优先事项、必要章节、评审准则或指标。建立在缺乏依据要求上的完善申请可能延误、被拒，或需要大量重做。

---

## 9. 其他需注意风险

- **[[风险分类#3.3 语境 / 细微差别 / 压缩|语境 / 细微差别 / 压缩]]：资助方关系与申请可行性差距（高）** — 人工智能可能写出具说服力的内容，却遗漏资助方历史、非正式回馈、现行优先事项，或建议时间表及预算对必须交付项目的人而言是否现实。
- **[[风险分类#3.2 来源依据 / 证据|来源依据 / 证据]]：成效声称夸大（高）** — 人工智能可能从有限资料外推、把数字取整，或把计划成果呈现为已达成结果，因而产生强于证据所支持程度的成效声称。这可能向资助方错误表述机构的证据、能力或往绩。
- **[[风险分类#3.4 隐私 / 机密性 / 资料边界|隐私 / 机密性 / 资料边界]]：统计数据捏造（高）** — 人工智能可能虚构支持资助论点的统计数据 — 受益人人数、成果百分比、比较数字。这些数据在专业文件中看似可信，如没有来源核实便难以察觉。
- **[[风险分类#3.9 法律 / 法规 / 合规|法律 / 法规 / 合规]]：合规差距（高）** — 资助合规要求因资助方而异，并会随每个资助周期改变。除非现行要求由已批准的现行来源提供或检索，否则不应假定人工智能知道这些要求。遗漏强制项目可能令申请失去资格。

## 11. 其他缓解措施

- 审核的强度取决于所核对的来源。对法律、医疗、财务或法规声称，应升级至合资格审核。
- 人工审核可降低风险，但不能保证准确。保留记录并使用已批准工具。
- 人工审核必须包括欺诈 / 真实性核查；不得只依赖人工智能提取来判断文件是否已被篡改。
- 一般人工审核并不足够。最终依赖需要合资格专业判断及现行权威来源。
