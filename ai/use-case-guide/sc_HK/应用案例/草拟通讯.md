# 草拟通讯

## 1. 这个应用案例是什么

如您希望人工智能协助草拟或改善日常机构通讯，包括电邮、通讯、公告、通知、简报、活动通讯及社交媒体贴文，请使用本页。

- 常见使用者：**教会、非营利机构、中小企业**。
- 批准级别：**一般可批准使用**。
- 需要人工审核：**是 — 发送或发布前**。
- 使用人工智能输出协助草拟或检查工作。在负责人审核前，不要把它视为最终信息。

---

## 2. 这可能造成什么代价

一则通讯可以听起来亲切、清晰并似乎可直接发送，却带有背景笔记中的旧日期、错误地点、错误姓名、缺乏支持的数字或非预期承诺。如审核者只检查语气及流畅度，信息可能带着影响出席、期望、信任或机构履行所述事项能力的错误传达给读者。

---

## 3. 如何审核这个输出

批准人工智能输出前，请使用以下检查。不要只因输出读起来流畅便批准。

---

### 3.1 审核设置

1. 并排打开来源材料及草稿。
2. 对照来源核对草稿中的每个日期、地点、姓名、数字、截止日期及链接 — 不要依赖记忆。
3. 检查每项隐含承诺、许诺、道歉、批准、立场或截止日期。询问机构是否确实已授权。
4. 以收件人角度阅读草稿，而不只是以作者角度阅读。作者会读到自己原本想表达的意思；收件人只会读到实际写出的内容。
5. 检查草稿是否包含或暗示不应分享的个人、机密、牧养、人力资源、财务、捐赠者、客户、受益人或其他敏感资料。
6. 确认所使用的工具、账户及工作流程已获批准处理该来源材料。

---

### 3.2 批准前 — 一项检查

> **负责人是否已把这份草稿当作首次收到般阅读 — 对照来源核对每个日期、姓名、数字、地点、截止日期、链接及隐含承诺，而不只是检查整体语气？**

---

### 3.3 针对风险的审核检查

这些检查把 [[人工审核风险库]] 中的最低审核责任调整至本任务。

- **[[人工审核风险库#4.1 低风险假设陷阱|低风险假设陷阱]]：** 对照已批准简介及目前来源材料，而不是记忆，核对每个收件人姓名、日期、时间、地点、连结、联络资料、数字、截止日期、所要求行动及隐含许诺或承诺。更正或升级处理审核者无法确认的任何项目。
- **[[人工审核风险库#4.7 提示词过度信任|提示词过度信任]]：** 独立执行这则讯息所需的来源与事实、权限、隐私、收件人影响及批准检查。不要因提示词经过测试、获批准、很详细或看似已被遵从而批准讯息。
- **[[人工审核风险库#4.10 指令漂移|指令漂移]]：** 每轮修订后，把最终版本与原本目的、已批准事实、受众、语气、仅限来源边界、隐私限制、禁止声称及批准边界比较。恢复或升级处理任何被削弱或遗失的要求。
- **[[人工审核风险库#4.13 人工智能盲点|人工智能盲点]]：** 输出是否符合任务背后真实的人、真实情况、真实权限及真实后果，包括人工智能未获告知的默会情境，以及无法完全化约为提示词的生活经验或专业判断。
  - **就本应用案例而言：** 对照实际收件人、关系情境、时机、近期事件、发送者权限、机构立场，以及误解讯息或据此行动的后果检查草稿。
- **[[人工审核风险库#4.16 受众影响盲点|受众影响盲点]]：** 检查谁可能受影响，以及时机、语气、披露、所要求行动或隐含压力是否可能造成混淆、尴尬、排斥、困扰、信任损失或声誉伤害。如影响敏感，使用了解受众的审核者。

---

### 3.4 审核者决策

完成上述针对本任务的审核检查后，使用 [[审核者决策卡]] 选择一项结果：

- **原样批准**
- **更正后批准**
- **停止并升级处理**

如审核者欠缺本任务所需的角色、证据、权限、能力、来源访问权、语境或已批准流程，不要批准输出。

---

### 3.5 本任务的审核方法

以下审核指示已针对本任务调整。它们把 [[人工审核模式]] 中的可重用方法应用于这里涉及的实际来源、决定、人士及后果。

- **一般输出审核：** 检查每则讯息是否达到所述目的、适合其渠道及受众、包含所需行动，并维持在已批准长度及格式内。
  - 留意：缺少行动呼吁、受众错误、格式漂移、下一步不清楚，或经修订后已不再符合简介的讯息。
  - 时间：发送或发布前。
  - 审核者：通讯负责人或负责发送者。

- **来源及事实核实：** 对照已批准来源核实每个姓名、日期、时间、地点、金额、连结、截止日期、容量及事实声称。
  - 留意：从记忆或旧活动材料复制的日常细节、虚构连结及缺乏支持的声称。
  - 时间：发送或发布前。
  - 审核者：来源负责人或能存取已批准事实的通讯审核者。

- **以人工判断为本的审核：** 以实际收件人角度阅读讯息，考虑时机、关系、近期事件、可能解读及可能影响。
  - 留意：技术上清晰，但对实际收件人不敏感、令人不安、具误导性或不恰当的措辞。
  - 时间：最终批准前。
  - 审核者：了解受众的审核者、项目负责人，或了解收件人及目前语境的人。

- **范围、权限及可行性审核：** 确认发送者获授权作出讯息中的每项许诺、承诺、道歉、例外、政策陈述或行动呼吁。
  - 留意：边界软化、非官方机构声音、无法履行的承诺或隐含批准。
  - 时间：发送或发布前。
  - 审核者：获授权通讯负责人或决策负责人。

## 4. 何时应升级处理而不是批准

- 如输出影响法律、人力资源、财务、安全保障、医疗、法规、对外或高影响决定，而审核者没有确认安全使用所需的权限、能力、语境、来源访问权或已批准流程，应在使用前升级处理。
- 如声称影响法律、财务、牧养、神学、公众或外部决策，而审核者未获授权或不具能力确认，应升级处理。
- 如措辞涉及弱势群体、文化、危机、投诉或公众声誉，而审核者欠缺确认安全使用所需的语境、权限或已批准流程，应升级处理。
- 如输出可能约束机构、影响权利或义务，或看似正式批准，应升级处理。
- 如涉及机密资料、第三方系统、财务处理或自动化，而工具、账户、审核者或流程未获批准作该用途，应在使用工具前升级处理。

## 5. 提示前

使用人工智能处理本任务前，先检查以下基本事项：

- 目的清晰。
- 输入不包含不应输入工具的个人或机密资料。
- 工具、帐户及工作流程已获批准处理所使用的材料。
- 有负责人可在使用人工智能输出前检查它。
- 任务没有要求人工智能作出决定、提供专业意见或充当最终权威。
- 确认本任务符合批准级别：**一般可批准使用**。
- 确认计划中的审核者能完成所需人工审核：**是 — 发送或发布前**。

---

## 6. 人工智能盲点重点

**风险重点：** 受众影响盲点

**提示词重点：** 提示前，向人工智能提供预期受众、渠道、目的、关系情境、已批准事实、敏感程度、发送者权限、时机，以及讯息不得暗示的事项。要求人工智能识别可能被误解、比原意更强硬、暗示批准或权限、产生非预期承诺、显得不敏感或令读者混淆的措辞。

**人工审核重点：** 审核者应以实际收件人角度阅读，而不只是以发送者角度。检查真实受众、时机、关系、机构立场及语境是否可能令讯息产生与发送者原意不同的效果。

**较深入的盲点审核：** 如讯息依赖未明说的关系历史、近期事件、内部张力、受众敏感度或某人可能的反应，请依循 [[如何使用本指南#6.1 Win.Win 人工智能盲点指南|Win.Win 人工智能盲点指南路径]]。

**不要只依赖：** 清晰措辞本身。讯息在文法上可以很清楚，却仍可能在社交、机构或实务上被误解。

## 8. 主要风险

- **[[风险分类#3.1 准确性 / 幻觉|准确性 / 幻觉]]：[[人工审核风险库#4.1 低风险假设陷阱|低风险假设陷阱]]（高）** — 草拟通讯、通知或公告感觉很例行。这种熟悉感本身就是风险。因为任务看似简单，审核者可能只检查明显错误便迅速批准。通讯中具体而隐蔽的失败 — 由贴上语境带入的错误日期、并非原意的隐含承诺、由笔记带入的个人细节 — 正是快速阅读最容易漏过的问题。对机构造成最大损害的事件，往往不是来自人人都很小心的任务，而是来自没有人预期会出问题的熟悉任务。


- **[[风险分类#3.1 准确性 / 幻觉|准确性 / 幻觉]]：[[人工审核风险库#4.7 提示词过度信任|提示词过度信任]]（中）** — 使用者或审核者可能把设计良好、经测试或获批准的提示词，以及人工智能看似遵从提示词，视为讯息安全、准确或可使用的证据。即使提示词不能取代本任务所需的审核模式、核实、权限检查或升级处理，所需审核仍可能因此被缩减或跳过。

## 9. 其他需注意风险

- **[[风险分类#3.11 人工智能盲点 / 语境风险|人工智能盲点 / 语境风险]]：[[人工审核风险库#4.16 受众影响盲点|受众影响盲点]]（高）** — 人工智能可能写出清晰有礼的讯息，却忽略真实收件人会如何因时机、关系、近期事件或受众期望而感受、误解或反应。
- **[[风险分类#3.1 准确性 / 幻觉|准确性 / 幻觉]]：格式不一致（低）** — 人工智能不能可靠复制以往通讯的确切格式。审核者可能检查内容但不检查版面忠实度，令不同期数之间的格式漂移未被发现。
- **[[风险分类#3.1 准确性 / 幻觉|准确性 / 幻觉]]：工作阶段记忆差距（中）** — 人工智能不会记得以往通讯或讯息。它无法识别不同期数之间的不一致，也无法察觉模式中断。每个工作阶段都由零开始。
- **[[风险分类#3.7 语气 / 表述 / 文化敏感度|语气 / 表述 / 文化敏感度]]：语气漂移（中）** — 人工智能可能逐步把语气移离原本要求。语气漂移比事实错误更难察觉，因为它主观而且渐进。输出可能错误代表机构声音。
- **[[风险分类#3.6 权限 / 范围 / 承诺|权限 / 范围 / 承诺]]：边界软化（高）** — 人工智能可能暗示承诺，或软化原本笔记并未明确意图放宽的界线。输出可能通过事实核对，却作出未经授权的机构承诺。
- **牧养 / 神学 / 圣经：提示词中的敏感资料（高）** — 使用者可能把敏感成员资料、机密细节或牧养内容贴入提示词。提示词模式本身无法防止这种情况 — 这是使用者纪律失效，而不是人工智能输出失效。
- **[[风险分类#3.5 工具 / 安全 / 流程治理|工具 / 安全 / 流程治理]]：影子人工智能风险（高）** — 所使用的工具可能是个人消费者帐户，而不是已批准的机构帐户。消费者帐户未必具有机构的资料保护设定、审核工作流程或退出模型训练保障。
- **[[风险分类#3.6 权限 / 范围 / 承诺|权限 / 范围 / 承诺]]：未经授权代表机构发声（高）** — 对公开贴文、正式通知或社交媒体而言，人工智能可能产生听起来具权威、并代表机构对未经领导层批准事项立场的内容。读者无法分辨人工智能草拟措辞与领导层批准措辞。
- **[[风险分类#3.3 语境 / 细微差别 / 压缩|语境 / 细微差别 / 压缩]]：[[人工审核风险库#4.10 指令漂移|指令漂移]]（中）** — 在反覆修订期间，即使人工智能最初已确认指示，也可能逐步偏离原本边界、语气、仅限来源规则或批准限制。最终讯息必须对照原本指示检查，而不只是对照最新草稿。

## 10. 要加入的提示词强化

先从 Win.Win 人工智能必备的基础提示词模式开始。以下附加项已针对本任务调整。

只使用与实际情况相符的行。不要只因某项控制出现在 [[提示词强化模式]] 便加入无关控制。对于主要须通过人工审核、已批准工具、专业检查、其他缓解措施或升级处理的风险，不要创建提示词附加项。

把来源材料、笔记、政策摘录、数字及文件放在基础提示词最后的 **内容** 部分。

## 12. 其他缓解措施

- 人工审核可降低风险，但不能保证准确。保留记录并使用已批准工具。
- 审核的强度取决于所核对的来源。对法律、医疗、财务或法规声称，应升级至合资格审核。
- 内容审核无法修正错误的工具、账户或资料流程。使用输出前先修正流程。
- 人工审核应由能批准范围及承诺的人进行，而不是只由检查拼写或语法的人进行。
- 如通讯依赖近期事件、本地历史、内部张力或受众敏感度，使用 **Win.Win 人工智能盲点指南**进行更深入的盲点识别及控制选择。只披露或撷取目前任务所需的语境。在合适情况下使用安全转换或仅由人处理；如语境不适合，应停止、升级处理，或不要使用或记录。把任何记录或保存视为独立的受管治决定。
