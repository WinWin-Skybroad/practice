# 应用案例工作流程模板

## 1. 如何使用本模板

应用案例页面本身还不是工作流程。它会告诉您要检查什么，但机构仍需决定由谁开始任务、人工智能步骤前要做什么、批准后要做什么，以及最终输出要放在哪里。

使用本模板，把一个应用案例页面转化为可重复使用的工作流程。

---

## 2. 工作流程步骤

| 步骤 | 问题 | 本地答案 |
|---|---|---|
| 1. 触发条件 | 这项人工智能任务何时开始？ | |
| 2. 来源资料包 | 输入提示词前必须收集什么？ | |
| 3. 人工智能草拟 | 谁在哪里执行提示词？ | |
| 4. 人工审核 | 谁检查输出？对照什么检查？ | |
| 5. 决定 | 谁可以原样批准、更正后批准，或停止并升级处理？ | |
| 6. 归档 / 使用 | 已批准输出要放在哪里？谁可以发送或使用？ | |

---

## 3. 工作流程控制

每个工作流程都要界定：

- 负责人
- 后备负责人
- 审核者
- 升级处理联系人
- 来源位置
- 输出位置
- 记录位置
- 停止规则

---

## 4. 最低工作流程规则

不要只依赖应用案例页面。对每项重复进行的人工智能任务，都要为工作流程命名，并指定负责人。

没有负责人的任务，会变成人人都有责任，结果却没有人真正负责。
