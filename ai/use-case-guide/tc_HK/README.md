## 這是什麼

**Win.Win 人工智能應用案例指南** 是一套實用指南，協助機構在日常工作中使用人工智能，同時不把最終決定交給人工智能。

本指南按任務整理。您不需要先讀完所有內容才開始。請從正在處理的任務開始，打開相應的應用案例頁面，並在人工智能輸出被發送、分享、批准、發布或採取行動前，使用審核檢查。

本指南協助個人、教會、非牟利機構及中小企業，選擇合適的人工智能任務、準備更好的提示詞、理解風險、採取保障措施、升級處理敏感事項，並決定人工智能輸出應被批准、修正或停止。

本指南是 **Win.Win 人工智能必備** 的配套資源。必備材料說明基礎；本指南示範如何把這些基礎應用到實際任務。

**使用這些材料並不能保證人工智能任務安全、合規或成功。讀者及其機構仍需自行負責所有決定。**

這些材料僅供一般資訊及獨立使用。它們不是諮詢服務、法律意見、合規認證、技術實施指引、財務建議、醫療建議、輔導建議、神學建議或牧養諮詢。

> [!note] 人工智能盲點
> 本指南在提示詞和審核兩方面都使用一個重要概念：**人工智能盲點**。人工智能可以令答案看起來仔細、完整，並像是經過周詳判斷，但仍然可能缺少任務背後的真實處境。它可能不知道關係歷史、本地做法、專業直覺、權限限制、驗證需要或重要後果。較好的提示詞可以降低這個風險，但負責人仍需在使用或批准輸出前，檢查輸出是否符合真實機構、真實人物、真實權限及真實後果。

> [!note] 人工智能盲點指南配套  
> **Win.Win 人工智能盲點指南** 是用於更深入審視人工智能盲點風險的配套指南。這些風險可能涉及任務依據中缺失或未獲充分呈現的相關情境、真實或本地理解、專業直覺、權限、問責、獨立核實、受眾影響、營運記憶，或人工智能無法可靠掌握的後果。
>
> **Win.Win 人工智能盲點指南** 目前的詳細重點是識別及引導未明說的語境。未明說的語境是指在任務依據中缺失、不完整或未獲充分呈現的相關情境。它可能由人知悉、存在於當前已批准記錄、同時存在於兩者，或來源不清楚。
>
> 相關指引涵蓋在識別或提出情境後，檢索當前已批准來源及提取與任務相關的已批准材料、評估可表達性、安全轉換、只由人處理、核實、由須問責或專業人員審核、停止及升級處理。**機構情境處理** 為較廣泛的當前任務來源及處理問題提供簡明方向，但並非完整的知識管理、記錄管理、企業檢索、保存或檢索增強生成（RAG）框架。已提出的情境不會自動輸入人工智能或被記錄；保存是另一項受管治決定。
>
> 使用 **人工智能盲點控制圖** 選擇相關控制類別。使用 **機構情境處理** 處理較廣泛的當前任務來源及處理問題；當相關情境在任務依據中缺失、不完整或未獲充分呈現時，使用 **未明說的語境控制**。

## 應用案例批准級別說明

本節說明本指南各類人工智能應用案例使用的批准級別。

批准級別 **不表示** 某個具體人工智能輸出已自動獲批准。它只描述這類任務通常是否適合人工智能輔助工作，以及在輸出可以使用前需要哪些條件或保障措施。

例如，某個應用案例可能標示為 **一般可批准使用**，因為人工智能通常可以協助草擬或整理這類工作。然而，實際人工智能輸出仍需要在被發送、分享、批准、發布或採取行動前完成人工審核。

簡單來說：

- **批准級別** 告訴您這類人工智能任務是否適合嘗試。
- **審核者決策** 告訴您某個具體人工智能輸出應被批准、修正或升級處理。

某個應用案例被列為可批准使用，並不表示可以省略審核、來源核對、私隱檢查、權限檢查或必要的升級處理。

| 批准級別 | 實際意思 |
|---|---|
| **一般可批准使用** | 人工智能可按正常應用案例工作流程用於此任務，但指定審核者必須在使用輸出前檢查輸出。 |
| **非機密情況下一般可批准使用** | 只在輸入不包含該工具或流程未獲批准處理的機密、敏感或個人資料時使用。 |
| **可謹慎使用** | 人工智能可協助草擬或發現問題，但輸出需要更強審核，並可能需要在使用前升級處理。 |
| **僅可作為思考輔助** | 人工智能可協助構思、整理、比較或檢查問題。除非另有由人撰寫或批准的結果，否則輸出不應直接用作最終訊息、決定、政策、建議、批准或記錄。 |
| **依賴輸出前先升級處理** | 普通審核並不足夠。在適當的合資格或獲授權人員按已批准流程審核前，不應批准、發送、發布、採取行動或依賴輸出。 |

## 選擇您的路徑

使用本節決定如何進入指南。您不需要在使用前閱讀每個文件。請從最符合目前需要的路徑開始。

---

### 路徑 0 — 初次使用本指南

如果您第一次打開本指南，且不確定從哪裏開始，請使用這條路徑。

- 打開 [[由此開始]] 作快速導覽。
- 如想理解實用層與參考層文件、升級處理指引及記錄範本如何配合使用，請打開 [[如何使用本指南]]。
- 然後打開最符合您機構的快速入門頁：
  - [[教會快速入門]]
  - [[非牟利機構快速入門]]
  - [[中小企業快速入門]]
- 選擇一項您的機構已經用人工智能處理的普通任務。
- 打開相應的應用案例頁面。
- 在使用人工智能輸出前，閱讀 **這可能造成甚麼代價** 及 **如何審核這個輸出**。
- 在輸出被發送、發布、依賴或使用前，進行審核。

---

### 路徑 A — 我已知道應用案例

如果您已知道要審核的人工智能任務，例如草擬通訊、總結會議記錄、翻譯通知或製作雙語版本，請使用這條路徑。

- 打開相關應用案例頁面。
- 閱讀 **這可能造成甚麼代價**，理解實際風險。
- 使用 **如何審核這個輸出**，在批准、修正或升級處理人工智能輸出前，引導針對該任務的審核。
- 如輸出可能超出審核者的權限、專業知識、證據、已批准流程或責任，請檢查 **何時應升級處理而不是批准**。
- 只有在需要理解批准級別、參考層文件、審核者工具、記錄保存或應用案例頁面如何配合整體指南時，才打開 [[如何使用本指南]]。
- 只有在需要較深入指引時，才使用相關參考文件。

---

### 路徑 B — 改善提示詞

如果該任務獲准使用人工智能處理，但提示詞在產生輸出前需要更好的結構、更清晰的來源材料或更強的保障措施，請使用這條路徑。

- 從相關應用案例頁面開始，確保提示詞改善仍以真實任務為本。
- 如任務依賴文件、會議記錄、政策、電郵、網頁或其他來源材料，請使用 [[提示詞前來源資料包]]。
- 打開 [[提示詞強化模式]]。
- 只選擇與實際風險相符的提示詞強化。
- 把提示詞強化加入 Win.Win 人工智能必備提示詞結構中的合適部分，通常是 **指令**、**規則**、**輸出格式** 或 **提醒 / 審核備註**。
- 把來源材料放在提示詞最後的 **內容** 部分。
- 如不確定來源準備、提示詞強化、人工審核及升級處理如何配合，請打開 [[如何使用本指南]]。
- 不要只依賴更好的提示詞。人工智能輸出產生後仍要進行人工審核。

---

### 路徑 C — 培訓審核者

當您正在培訓審核者、建立內部人工智能審核流程，或決定機構應如何跨多個應用案例審核人工智能輸出時，請使用這條路徑。

- 閱讀 [[如何使用本指南]]，理解本指南背後的操作方法。
- 從相關應用案例頁面開始，確保審核仍以真實任務為本。
- 閱讀 [[人工審核模式]]，理解人工智能輸出常見的檢查方式。
- 閱讀 [[人工審核風險庫]]，理解應用案例頁面使用的具名人工審核風險。
- 如需要理解應用案例風險背後較大的風險類別，或查找具名風險或失敗模式的意思及定義路線，請使用 [[風險分類]]。
- 當問題在人工智能輸出產生前已經開始，請使用 [[提示詞強化模式]] 及 [[提示詞前來源資料包]]。
- 當需要提示詞以外的控制，例如來源核對、審核者角色、批准記錄或工作流程保障，請使用 [[緩解措施庫]]。
- 使用 [[審核者決策卡]] 決定審核者可以批准、應修正，還是必須停止並升級處理。
- 如輸出可能超出審核者的權限、專業知識、證據、已批准流程或責任，請使用 [[升級處理指南]]。
- 使用應用案例頁面，以真實或接近真實的例子練習針對特定任務的審核。

您不需要為每項人工智能任務打開每個參考文件。請先使用相關應用案例頁面，只有在審核問題需要時，才打開較深入的參考文件。

### 路徑 D — 為您的機構調整本指南

當您的機構希望把公開指南轉化為本地指南、內部工作流程或培訓資源時，請使用這條路徑。

- 在調整前閱讀 [[如何使用本指南]]，理解指南結構。
- 在改變指南結構、措辭、語言、控制、連結或發布文件前，閱讀 [[作者及編輯指南]]。
- 閱讀 [[應用案例頁面範本]]。
- 複製範本結構。
- 清楚保留批准級別、審核方法、升級處理界線及相關參考文件。
- 加入您機構自己的風險、審核者、升級處理路線、來源核對及批准流程。
- 使用 [[審核者決策卡]] 定義誰可以批准、誰必須修正，以及何時需要升級處理。
- 如本地工作流程需要審核軌跡、批准記錄或日後審計參考，請使用 [[人工智能輸出記錄範本]]。

### 路徑 E — 實施一個應用案例

當您準備在真實工作流程中試點或實施一個人工智能應用案例時，請使用這條路徑。

- 如果這是您的機構第一次把應用案例頁面轉化為真實工作流程，請閱讀 [[如何使用本指南]]。
- 在選擇試點任務前，閱讀 [[選擇首個應用案例]]。
- 選擇一項機構已經在做、且可管理的任務。
- 在提示人工智能前，先整理 [[提示詞前來源資料包]]。
- 使用 [[應用案例工作流程範本]]，把選定的應用案例頁面轉化為本地工作流程。
- 指定一名具名審核者，並清楚說明誰有批准權限。
- 審核時使用 [[審核者決策卡]]，決定應批准、修正或升級處理。
- 如正在試點，使用 [[試點及停止規則卡]] 決定試點應繼續、暫停、改變或停止。
- 對於會對外發送、影響他人或用於支援實際決策的輸出，保留簡單的 [[人工智能輸出記錄範本]]。
- 當出現問題或工作流程需要改善時，使用 [[首次錯誤檢討]]。
