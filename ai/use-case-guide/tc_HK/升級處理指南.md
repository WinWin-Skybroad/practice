# 升級處理指南

## 1. 目的及範圍

升級處理是停止一般批准流程，並在使用輸出前請適當的最終責任人審核。

升級處理不是失敗，而是一項安全控制。

審核者不需要只因提及敏感主題便停止。只有在獲明確授權、具備能力、充分掌握資料，而且依照該事項的已批准流程時，審核者才可繼續。

---

## 2. 何時一般審核並不足夠

如審核者無法在其角色、證據、權限、能力或已批准流程範圍內安全批准輸出，便應升級處理。

如出現以下任何情況，應升級處理：

- 審核者不是批准該主題的適當人士。
- 審核者缺少核實輸出所需的來源材料、語境、來源存取權、領域知識或已批准流程。
- 輸出似乎作出或暗示審核者無權批准的機構決定。
- 輸出建立或暗示某項承諾、保證、指示、批准、公開聲明、政策立場、期限、退款、付款或義務，而審核者無權或未充分掌握資料去確認。
- 輸出涉及法律、財務、人力資源、私隱、法規、安全保障、牧養、神學、醫療、公開或其他專業事項，而審核者缺少確認安全使用所需的權限、能力、語境、來源存取權或已批准流程。
- 輸出涉及個人資料、機密資料、客戶資料、會員資料、捐贈者資料、受益人資料、弱勢群體、投訴、危機情況或公眾聲譽，而審核者缺少確認安全使用所需的權限、語境、來源存取權或已批准流程。
- 輸出包含無法透過核對現有來源解決的不確定性。
- 審核者可以修改措辭，但無法確認實質內容是否正確。

升級處理不代表人工智能不能協助，而是輸出在由適當的最終責任人審核前，不得獲批准、發送、發布、據以行動或依賴。

## 3. 升級處理路徑

### 3.1 應升級交由誰處理

| 問題 | 升級交由 |
|---|---|
| 法律、法規、人力資源或合規問題 | 合資格法律、合規、人力資源或管理審核者 |
| 個人資料或機密性問題 | 私隱、資料保障或負責的機構領導人 |
| 財務、資助、退款、付款或撥款問題 | 財務負責人、資助負責人或獲授權管理層審核者 |
| 牧養輔導、神學意見、屬靈指導或教義問題 | 機構內適當的人類權威；不要把人工智能輸出當作權威 |
| 對外通訊或聲譽問題 | 通訊責任負責人或機構領導人 |
| 網絡安全或工具批准問題 | 資訊科技、網絡安全或負責的系統負責人 |
| 來源擁有權或有爭議來源問題 | 來源負責人、記錄負責人、會議主席、政策負責人或責任經理 |
| 沒有合適審核者 | 暫停任務。不要把人工智能輸出當作最終決定 |

---

### 3.2 如果您的機構沒有專職專業人員

小型教會、非牟利機構及中小企業可能沒有內部法律、人力資源、資訊科技、網絡安全、財務或合規人員。在這種情況下，升級處理是尋求現有最負責任及最具能力的人協助，而不是假裝機構內有專家。

升級處理可以是找內部領導、董事會或委員會成員、外部顧問、專業服務提供者，或在找到合適審核者前暫停任務。

| 情況 | 小型機構的實際升級處理路徑 |
|---|---|
| 教會或事工事項 | 牧師、長老、執事會、事工領袖、教會議會或指定審核者 |
| 非牟利服務或受益人事項 | 項目經理、個案 / 服務主管、董事會主席、負責的委員會成員或外部顧問 |
| 中小企業法律、人力資源或財務事項 | 企業負責人、董事、經理、會計師、人力資源服務提供者、律師或其他合資格顧問 |
| 法律、合規或法規問題 | 暫停任務。不要只依賴人工智能輸出繼續。尋求合資格專業人士、義務法律服務、管治機構或具相關專業知識的可信外部聯絡人 |
| 資料保障或機密性問題 | 機構內對資料負責的人。如沒有人承擔此角色，在找出負責人前，把任務視為已升級處理 |
| 網絡安全或工具批准問題 | 資訊科技服務提供者、系統負責人、網絡安全顧問或負責的機構領導人 |
| 沒有合適審核者 | 暫停任務。不要把人工智能輸出當作最終決定 |

升級處理可以簡單地說：

**「這可能影響權利、金錢、聲譽、個人資料、牧養或輔導事項，或正式責任。我不是適合單獨批准的人。」**

如有疑問，應停止。延誤的任務通常仍可補救；根據錯誤人工智能輸出採取的行動則未必可以。

## 4. 實用停止規則

> [!warning] 無法安全批准時停止
> 如您無法在自己的角色、證據、權限、能力或已批准流程範圍內核實或批准輸出，不要批准、發送、發布、據以行動或依賴該輸出。

- 當人工智能輸出聽起來很有信心，但您無法核實時，暫停任務。
- 當輸出影響權利、義務、照顧、金錢、聲譽或服務取得，而您無法在自己的角色範圍內安全批准時，暫停任務。
- 當人工智能建立來源材料中沒有的聲稱、承諾、決定或結論時，暫停任務。
- 當審核者沒有批准內容所需的權限、能力、來源存取權、語境或已批准流程時，暫停任務。
- 當工具或帳戶未獲批准處理所涉及資料時，暫停任務。
