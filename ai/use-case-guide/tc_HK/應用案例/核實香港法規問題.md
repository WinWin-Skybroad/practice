# 核實香港法規問題

## 1. 這個應用案例是甚麼

當您希望人工智能協助以下工作時，請使用本頁：**核實香港法律、法規或合規問題**。

- 常見使用者：**教會、非牟利機構、中小企業**。
- 批准級別：**依賴輸出前先升級處理**。
- 需要人工審核：**是 — 以官方來源或合資格專業人士核實**。
- 使用人工智能輸出協助您草擬或核查工作。不要把它視為最終決定。

---

## 2. 這可能造成甚麼代價

法規答案可能正確解釋一般框架，卻遺漏現行官方要求、因具體事實而異的條件，或監管機構對擬議安排的立場。如果機構把人工智能答案當作放行依據而採取行動，便可能提交不準確資料、遺漏適用要求、延誤活動，或面對整改及監管風險。

---

## 3. 如何審核這個輸出

批准人工智能輸出前，請使用以下核查。不要只因內容讀起來順暢便批准。

---

### 3.1 審核設定

1. 識別與問題相關的特定監管機構及條例。
2. 直接前往監管機構的官方網站，搜尋有關此主題的現行指引。
3. 把人工智能答案視為待核實事項清單，而不是答案本身。
4. 任何會帶來財務或營運後果的法規結論，在採取行動前均應升級處理並交由合資格專業人士審核。

---

### 3.2 批准前 — 一項檢查

> **具備相關監管機構現行立場知識的合資格法律或合規專業人士，是否已確認這項結論 — 不是閱讀人工智能答案後表示同意，而是獨立核對現行官方指引？**

---

### 3.3 針對風險的審核檢查

以下核查把 [[人工審核風險庫]] 中的最低審核責任調整至本任務。

- **[[人工審核風險庫#4.13 人工智能盲點|人工智能盲點]]：** 輸出是否符合任務背後真實的人、真實情況、真實權限及真實後果，包括人工智能未獲告知的默會情境，以及無法完全化約為提示詞的生活經驗或專業判斷。
  - **就本應用案例而言：** 按實際機構、活動、日期、香港管轄區、專業責任、決策權限，以及依賴該法規解讀採取行動的後果，核查答案。
- **[[人工審核風險庫#4.23 本地或特定管轄區盲點|本地或特定管轄區盲點]]：** 按現行香港法例、監管機構指引、官方來源及具適當資格的本地專業知識，核實每項重要立場。檢查有否以中國內地、海外或一般性法規假設取代香港要求，或把不同要求混在一起。

---

### 3.4 審核者決策

完成上述任務專用審核核查後，使用 [[審核者決策卡]] 選擇一項結果：

- **原樣批准**
- **更正後批准**
- **停止並升級處理**

如果審核者欠缺本任務所需的角色、證據、權限、能力、來源存取權、語境或已批准流程，不要批准輸出。

---

### 3.5 本任務的審核方法

以下審核指示已按本任務調整。它們把 [[人工審核模式]] 中的可重用方法應用於此處的實際來源、決策、人員及後果。

- **合資格法律 / 合規審核：** 只把人工智能輸出視為問題識別。就具體問題獨立核對現行香港官方法律、監管機構指引及合資格專業判斷。
  - 留意：缺乏支持的法律結論、過時的監管機構立場、遺漏要求，或在未經專業確認下看似具權威性的答案。
  - 時機：依賴、分享或按答案採取行動前。
  - 審核者：具備相應資格的香港法律、合規、私隱、人力資源、稅務、監管或其他相關專業審核者。

- **來源及事實核實：** 按現行官方來源核實每項條例、條文、監管機構名稱、指引文件、生效日期、門檻、截止日期及事實陳述。
  - 留意：錯誤引用、已被取代的指引、版本混用，或無法在所稱官方來源找到的聲稱。
  - 時機：專業簽核或用於決策前。
  - 審核者：可存取現行官方來源的來源核對審核者或合資格專業人士。

- **範圍、權限及可行性審核：** 確認確切的管轄區、機構、活動、決策及權限界線，並確保輸出沒有給予最終放行或批准。
  - 留意：把不同管轄區的規則疊加、把一般規則套用於錯誤機構，或繞過負責的決策負責人。
  - 時機：採取行動前。
  - 審核者：合規負責人、決策負責人或獲授權經理。

---

## 4. 何時應升級處理而不是批准

- 如輸出影響法律、人力資源、財務、安全保障、醫療、法規、公開使用或其他高影響決策，而審核者欠缺確認安全使用所需的權限、能力、語境、來源存取權或已批准流程，應在使用前升級處理。
- 法律、法規、僱傭、PDPO（《個人資料（私隱）條例》）、合約、合規或權利 / 義務問題應升級處理，除非審核者已獲明確授權，並有能力按已批准流程確認有關事項。
- 如涉及個人資料、人力資源、牧養、神學、醫療、財務、HKID（香港身份證）、受益人或機密資料，而審核者欠缺確認安全使用所需的權限、語境、來源存取權或已批准流程，應升級處理。

---

## 5. 提示前

使用人工智能處理本任務前，先檢查以下基本事項：
- 目的清晰。
- 輸入不包含不應輸入工具的個人或機密資料。
- 有負責人可在人工智能輸出使用前檢查輸出。
- 任務不要求人工智能作出決定、提供專業意見或擔任最終權威。

- 確認本任務符合批准級別：**依賴輸出前先升級處理**。
- 確認預定審核者可以完成所需人工審核：**是 — 以官方來源或合資格專業人士核實**。

---

## 6. 人工智能盲點重點

**風險重點：** 問責差距

**提示詞重點：** 提示前，向人工智能提供確切的香港法規問題、日期、機構類型、預定用途及所需官方來源。要求它識別假設、需要核查的官方來源、不確定性，以及需要由合適的合資格或負責人士審核的項目。

**人工審核重點：** 按現行香港官方來源核實；如答案影響合規、金錢、權利、義務、個人資料、公開陳述、牧養 / 神學事項或機構責任，應升級處理。

**較深入的盲點審核：** 如問題取決於未明說的本地慣例、為何需要該法規答案、專業責任，或審核者無權作出的決定，請沿 [[如何使用本指南#6.1 Win.Win 人工智能盲點指南|Win.Win 人工智能盲點指南路徑]] 進行。法規準確性的主要控制應是現行香港官方來源及合資格審核。

**不要只依賴：** 人工智能的信心或看似有來源依據的措辭。法規責任仍由負責人及合資格審核者承擔，而不是模型。

## 8. 主要風險

- **[[風險分類#3.9 法律 / 法規 / 合規|法律 / 法規 / 合規]]：以人工智能取代法律或法規專業意見（高）** — 法規答案可能取決於現行法例、官方指引、常見問題、牌照或註冊條件、日期、機構類型，以及擬議活動的確切事實。人工智能可能正確描述一般框架，但仍可能對現行或因具體事實而異的立場出錯。只把輸出視為問題識別；獨立核查現行官方來源，並在依賴輸出作出具後果的決定前取得合資格意見。

---

## 9. 其他需注意風險

- **[[風險分類#3.9 法律 / 法規 / 合規|法律 / 法規 / 合規]]：問責差距（高）** — 人工智能可能有信心地總結法規資料，但它沒有與意見相連的專業牌照、職責、聲譽或法律責任。信心並不等於問責。
- **[[風險分類#3.9 法律 / 法規 / 合規|法律 / 法規 / 合規]]：管轄區及範圍錯誤 — 相關審核風險：[[人工審核風險庫#4.23 本地或特定管轄區盲點|本地或特定管轄區盲點]]（高）** — 人工智能可能混合不同管轄區的規則、把一般規則套用於錯誤機構或活動，或忽略因具體事實而異的例外、批准路徑或監管機構立場。
- **[[風險分類#3.4 私隱 / 機密性 / 資料邊界|私隱 / 機密性 / 資料邊界]]：法規時效差距（高）** — 官方要求、指引、表格、門檻及行政立場可能改變。人工智能可能沒有反映現行或目前實際採用的版本。依賴答案前，記錄官方來源及核查日期。
- **[[風險分類#3.9 法律 / 法規 / 合規|法律 / 法規 / 合規]]：繞過合資格審核者（高）** — 使用者把人工智能對法律及合規問題的輸出視為足以作出決策，而沒有專業審核。本應用案例正是為防止這種失敗模式而設 — 而當人工智能答案聽起來具權威性時，這種情況最可能發生。

## 11. 其他緩解措施

- 普通人工審核並不足夠。最終依賴需要合資格專業判斷及現行權威來源。
- 如果敏感資料已輸入未獲批准的工具，輸出審核無法撤銷資料外洩。應按私隱 / 事故處理流程升級處理。
