# 研究香港相關主題

## 1. 這個應用案例是甚麼

當您希望人工智能協助以下工作時，請使用本頁：**研究香港特定主題**。

- 常見使用者：**教會、非牟利機構、中小企業**。
- 批准級別：**謹慎使用**。
- 需要人工審核：**是 — 按香港官方來源核實**。
- 使用人工智能輸出協助您草擬或檢查工作。不要把它視為最終決定。

---

## 2. 這可能造成甚麼代價

以香港為重點的研究答案可能依賴過時政策立場、遺漏中文官方材料，或混合香港與海外假設。如果未核查官方來源及日期便把答案視為現行資料，機構可能按錯誤基礎規劃、申請、溝通或作出決定。

---

## 3. 如何審核這個輸出

批准人工智能輸出前，請使用以下檢查。不要只因輸出讀起來流暢便批准。

---

### 3.1 審核設定

1. 列出輸出中每項具名政策、計劃、資格準則及官方機構。
2. 就每一項直接前往相關政府或監管機構網站。
3. 檢查任何政策或指引的生效日期或最後更新日期。
4. 如官方網站未能確認資料，把人工智能輸出視為未核實。

---

### 3.2 批准前 — 一項檢查

> **本輸出中的每項政策立場、計劃要求及官方指引，是否已直接按現行官方政府或監管機構網站核實 — 而不是按人工智能輸出或一般搜尋結果核實？**

---

### 3.3 針對風險的審核檢查

這些檢查把 [[人工審核風險庫]] 中的最低審核責任調整至本任務。

- **[[人工審核風險庫#4.23 本地或特定管轄區盲點|本地或特定管轄區盲點]]：** 按現行香港官方或權威來源，以及實際機構、界別、地區、受眾及期間，核查每項重要聲稱。核實雙語術語，並排除不適用的中國內地、海外或一般性假設。

---

### 3.4 審核者決策

完成上述針對本任務的審核檢查後，使用 [[審核者決策卡]] 選擇一項結果：

- **原樣批准**
- **更正後批准**
- **停止並升級處理**

如審核者欠缺本任務所需的角色、證據、權限、能力、來源存取權、語境或已批准流程，不要批准輸出。

---

### 3.5 本任務的審核方法

以下審核指示已針對本任務調整。它們把 [[人工審核模式]] 中的可重用方法應用於這裏涉及的實際來源、決定、人士及後果。

- **來源及事實核實：** 按現行香港官方來源、本地機構、原始記錄或可靠香港證據核實重要聲稱。
  - 留意：中國內地或海外預設、過時香港政策、缺乏支持的本地聲稱，以及不適用於所述界別或期間的來源。
  - 時機：研究被分享或依賴前。
  - 審核者：香港主題負責人、研究人員或來源核對審核者。

- **雙語 / 本地化審核：** 按權威本地來源核查英文及中文名稱、官方術語、機構名稱、法律 / 法規術語，以及香港語言用法。
  - 留意：中國內地術語、繁簡字混用、機構名稱誤譯，或英文與中文術語指向不同概念。
  - 時機：發布或對外使用前。
  - 審核者：熟悉香港術語的合資格雙語審核者。

- **以人工判斷為本的審核：** 檢查研究是否符合實際香港機構、界別、社群、地區、受眾及預定用途，而不是只符合一般性的香港描述。
  - 留意：事實上看似合理，卻遺漏本地機構實務、現行情境或真正受影響受眾的答案。
  - 時機：用於決策前。
  - 審核者：本地主題負責人、機構負責人或具相關香港經驗的人員。

---

## 4. 何時應升級處理而不是批准

- 如輸出影響法律、人力資源、財務、安全保障、醫療、法規、對外或高影響決定，而審核者沒有確認安全使用所需的權限、能力、語境、來源存取權或已批准流程，應在使用前升級處理。
- 如審核者沒有資格或權限確認專業意思，法律、醫療、財務、技術或公開翻譯應升級處理。
- 法律、法規、僱傭、PDPO（《個人資料（私隱）條例》）、合約、合規或權利 / 義務問題，除非審核者在已批准流程下明確獲授權且有能力確認，否則應升級處理。
- 每當涉及個人資料、人力資源、牧養、神學、醫療、財務、HKID（香港身份證號碼）、受益人或機密資料，而審核者沒有確認安全使用所需的權限、語境、來源存取權或已批准流程時，均應升級處理。

---

## 5. 提示前

使用人工智能處理本任務前，先檢查以下基本事項：
- 目的清晰。
- 輸入不包含不應輸入工具的個人或機密資料。
- 有負責人可在使用人工智能輸出前檢查它。
- 任務沒有要求人工智能作出決定、提供專業意見或充當最終權威。

- 確認本任務符合批准級別：**謹慎使用**。
- 確認預定審核者可以完成所需人工審核：**是 — 按香港官方來源核實**。

---

## 6. 人工智能盲點重點

**風險重點：** 本地機構語境差距

**提示詞重點：** 提示前，向人工智能提供香港特定問題、管轄區、日期敏感度、首選官方來源、中英文來源要求、機構類型及預定用途。要求它標記香港特定假設，以及需要官方來源核實的項目。

**人工審核重點：** 按現行香港官方或權威來源核實。檢查人工智能有否引入非香港假設、遺漏中文材料，或把本地機構問題當作一般主題。

**較深入的盲點審核：** 如答案可能取決於香港特定機構、中文來源、本地實務、現行政府情境或特定管轄區含義，請沿 [[如何使用本指南#6.1 Win.Win 人工智能盲點指南|Win.Win 人工智能盲點指南路徑]] 進行。

**不要只依賴：** 一般專業知識。香港特定工作可能取決於本地機構、雙語來源、現行實務及官方措辭。

## 8. 主要風險

- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：香港涵蓋及時效差距（高）** — 香港特定的政策、機構、法律及法規材料可能分別記錄於英文及中文官方來源，並可能隨時間改變。人工智能可能提供不完整、過時、誤譯或跨管轄區的資料而沒有標示差距。把香港特定研究視為核查相關語言現行官方來源的起點，而不是最終答案。

---

## 9. 其他需注意風險

- **[[風險分類#3.11 人工智能盲點 / 語境風險|人工智能盲點 / 語境風險]]：本地機構語境差距 — 相關審核風險：[[人工審核風險庫#4.23 本地或特定管轄區盲點|本地或特定管轄區盲點]]（高）** — 人工智能可能知道一般概念，卻遺漏香港特定機構實務、雙語官方術語、現行政府指引或界別特定解讀。
- **[[風險分類#3.9 法律 / 法規 / 合規|法律 / 法規 / 合規]]：中國內地預設 — 相關審核風險：[[人工審核風險庫#4.23 本地或特定管轄區盲點|本地或特定管轄區盲點]]（高）** — 法規、法律及文化內容可能引入中國內地術語、假設或機構參考，尤其當查詢使用簡體中文，或沒有明確說明香港情境時。香港與中國內地具有不同的法律、管治及機構情境。
- **[[風險分類#3.4 私隱 / 機密性 / 資料邊界|私隱 / 機密性 / 資料邊界]]：過時香港政策及法例（高）** — 香港條例及政策會不時改變。人工智能訓練資料可能沒有反映近期條例修訂、新的 PCPD（個人資料私隱專員公署）指引、更新的 證監會或 HKMA（香港金融管理局）要求，或政府架構變動。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：中英文術語不匹配（中）** — 香港官方英文及繁體中文術語，與英國英語對應用語及中國內地中文對應用語均可能不同。人工智能可能使用錯誤術語，而審核者未必能察覺。

## 11. 其他緩解措施

- 流暢文字可能掩蓋意思漂移；雙語審核必須比較來源及目標文本，而不是只閱讀目標文本。
- 如敏感資料已輸入未獲批准的工具，審核輸出無法撤銷外洩。應按照私隱 / 事故處理流程升級處理。
