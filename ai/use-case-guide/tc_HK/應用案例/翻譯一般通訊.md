# 翻譯一般通訊

## 1. 這個應用案例是甚麼

當您希望人工智能協助**翻譯一般通訊**時，請使用本頁。

- 常見使用者：**教會、非牟利機構、中小企業**。
- 批准級別：**謹慎使用**。
- 需要人工審核：**是 — 需要合資格雙語審核者**。
- 使用人工智能輸出協助您草擬或檢查工作。不要把它視為最終決定。

---

## 2. 這可能造成甚麼代價

翻譯可能以較廣泛的日常用語取代法律、技術、安全保障或機構術語，改變讀者必須提供、執行或理解的內容。如沒有合資格雙語審核者比較來源及目標版本，流程可能需要重做，而機構可能發出不一致或具誤導性的指示。

---

## 3. 如何審核這個輸出

批准人工智能輸出前，請使用以下檢查。不要只因輸出讀起來流暢便批准。

---

### 3.1 審核設定

1. 把來源及翻譯並排閱讀。
2. 識別每個具有法律、法規或技術意義的術語 — 不要依賴整體流暢度來發現這些問題。
3. 對每個這類術語，確認繁體中文對應詞在香港語境中具有正確法律或技術含義。流暢不等於正確。
4. 如文件對收件人具有法律後果，應升級至具相關領域資格的審核者，而不只是具語言能力的人。

---

### 3.2 批准前 — 一項檢查

> **是否已有熟悉相關領域的雙語審核者 — 而不只是語言流利的人 — 確認每個法律術語、技術術語及具有正式後果的短語，在繁體中文中與英文來源具有相同法律份量及含義？**

---

### 3.3 針對風險的審核檢查

這些檢查把 [[人工審核風險庫]] 中的最低審核責任調整至本任務。

- **[[人工審核風險庫#4.11 流暢度錯覺|流暢度錯覺]]：** 逐行比較翻譯與來源的意思、事實、限制、語氣、權限、術語、格式及遺漏。不要只因讀起來自然或專業便批准。
- **[[人工審核風險庫#4.15 讀者解讀差距|讀者解讀差距]]：** 檢查每個具名讀者群體可能如何理解翻譯後的語氣、確定程度、權限、承諾、拒絕、批准及所需行動。更正可能被理解為與來源意圖不同的措辭。
- **[[人工審核風險庫#4.23 本地或特定管轄區盲點|本地或特定管轄區盲點]]：** 檢查翻譯是否取決於香港或另一具名管轄區、界別、機構或本地情境。按現行權威來源或適當本地審核者核實官方術語、本地規則及機構含義。

---

### 3.4 審核者決策

完成上述針對本任務的審核檢查後，使用 [[審核者決策卡]] 選擇一項結果：

- **原樣批准**
- **更正後批准**
- **停止並升級處理**

如審核者欠缺本任務所需的角色、證據、權限、能力、來源存取權、語境或已批准流程，不要批准輸出。

---

### 3.5 本任務的審核方法

以下審核指示已針對本任務調整。它們把 [[人工審核模式]] 中的可重用方法應用於這裏涉及的實際來源、決定、人士及後果。

- **雙語 / 本地化審核：** 逐行比較翻譯與來源的意思、遺漏、增加內容、術語、名稱、字體、格式及香港用法。
  - 留意：改變意思的流暢措辭、未翻譯文字、繁簡字混用、術語不一致，或改變訊息的格式。
  - 時間：發送或發布前。
  - 審核者：熟悉受眾及香港用法的合資格雙語審核者。

- **以人工判斷為本的審核：** 以實際收件人的角度閱讀翻譯，檢查語氣、正式程度、禮貌程度、暗示的權限、所需行動及可能解讀。
  - 留意：對真實關係及渠道而言，聽起來過強、冷淡、隨便、官方、不敏感或含糊的直譯。
  - 時間：發送或發布前。
  - 審核者：雙語、文化或了解受眾的審核者。

- **合資格法律 / 合規審核：** 如來源包含法律、法規、人力資源、醫療、財務、牧養、技術或其他專業含義，除雙語審核外亦須取得相關專業審核。
  - 留意：一般語言正確，但專業含義或管轄區效力錯誤。
  - 時間：專業內容被依賴或發布前。
  - 審核者：相關合資格專業人士及雙語審核者。

- **工具 / 流程管治審核：** 如使用多於一個模型或翻譯步驟，確認已批准模型 / 工具、版本、來源檔案、術語表及比較工作流程。
  - 留意：模型替換、來源漂移、不同術語基礎，或沒有記錄審核了哪個輸出。
  - 時間：翻譯工作流程之前及期間。
  - 審核者：翻譯負責人、工具負責人或管治審核者。

---

## 4. 何時應升級處理而不是批准

- 如輸出影響法律、人力資源、財務、安全保障、醫療、法規、對外或高影響決定，而審核者沒有確認安全使用所需的權限、能力、語境、來源存取權或已批准流程，應在使用前升級處理。
- 法律、法規、僱傭、PDPO（《個人資料（私隱）條例》）、合約、合規或權利 / 義務問題，除非審核者在已批准流程下明確獲授權且有能力確認，否則應升級處理。
- 如審核者沒有資格或權限確認專業意思，法律、醫療、財務、技術或公開翻譯應升級處理。

---

## 5. 提示前

使用人工智能處理本任務前，先檢查以下基本事項：
- 目的清晰。
- 輸入不包含不應輸入工具的個人或機密資料。
- 有負責人可在使用人工智能輸出前檢查它。
- 任務沒有要求人工智能作出決定、提供專業意見或充當最終權威。

- 確認本任務符合批准級別：**謹慎使用**。
- 確認計劃中的審核者能完成所需人工審核：**是 — 需要合資格雙語審核者**。

---

## 6. 人工智能盲點重點

**風險重點：** 讀者解讀差距

**提示詞重點：** 提示前，向人工智能提供預定受眾、渠道、目的、關係、地區版本、語氣、術語偏好及所需行動。要求它識別可能被誤解、聽起來比原意更強、暗示權限或承諾、改變正式程度、顯得不敏感或令讀者困惑的措辭。

**人工審核重點：** 把來源及翻譯並排比較，然後從目標讀者角度閱讀。檢查意思、語域、文化適切性、名稱、日期、義務，以及翻譯是否改變機構所表達的內容。

**較深入的盲點審核：** 如翻譯取決於讀者解讀、本地語域、機構含義、正式程度，或流利但不了解內情的翻譯可能遺漏的術語，請沿 [[如何使用本指南#6.1 Win.Win 人工智能盲點指南|Win.Win 人工智能盲點指南路徑]] 進行。

**不要只依賴：** 字面準確或流暢措辭。真實讀者對語氣、義務或權限的理解可能與發件人原意不同。

## 8. 主要風險

- **[[風險分類#3.9 法律 / 法規 / 合規|法律 / 法規 / 合規]]：[[人工審核風險庫#4.11 流暢度錯覺|流暢度錯覺]]（高）** — 聽起來自然的翻譯可能被視為正確，即使在需要特定香港法律或法規術語的地方使用了一般中文表達。除非使用任務所需的雙語、本地化、法律及其他審核模式獨立核查輸出，流暢措辭可能掩蓋法律份量、義務或權益的改變。

## 9. 其他需注意風險

- **[[風險分類#3.11 人工智能盲點 / 語境風險|人工智能盲點 / 語境風險]]：[[人工審核風險庫#4.15 讀者解讀差距|讀者解讀差距]]（中）** — 人工智能可能選擇技術上正確的自然措辭，卻改變讀者對語氣、義務、正式程度或機構含義的理解。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：繁簡字混用（中）** — 人工智能可能把簡體中文字加入繁體中文文件，反之亦然。不能流利分辨兩種字體的審核者可能看不到這個問題。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：翻譯過程格式喪失（低）** — 翻譯模型會把語義準確性優先於結構保留。標題、項目符號、粗體文字及表格格式可能遺失或改變。除內容核查外，還需要另行按原文檢查格式。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：未翻譯的英文詞語（低）** — 人工智能可能把英文詞語留在中文文字中而沒有翻譯。快速閱讀時很容易遺漏，因為周圍中文看似正確，視線會跳過熟悉的英文詞語。
- **[[風險分類#3.9 法律 / 法規 / 合規|法律 / 法規 / 合規]]：管轄權不匹配 — 相關審核風險：[[人工審核風險庫#4.23 本地或特定管轄區盲點|本地或特定管轄區盲點]]（高）** — 簡體中文輸出可能引入中國內地術語、法律假設或機構參考，尤其沒有明確說明香港管轄區時。即使是供香港使用的簡體中文內容，也應說明香港管轄區；如法律或法規含義重要，應按香港官方術語及現行來源核查。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：術語不一致（中）** — 提供術語翻譯表可減少不一致，但不能完全消除。模型會解讀指示 — 並非機械式執行。翻譯後需要逐項針對術語核實。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：多模型審查期間的模型替換（中）** — 如同時向審核模型提供多份來源文件，模型可能自行選擇權威來源，而不是指定來源，令格式正確但術語錯誤。

## 11. 其他緩解措施

- 流暢文字可能掩蓋意思漂移；雙語審核必須比較來源及目標文本，而不是只閱讀目標文本。
- 內容審核無法修正錯誤的工具、帳戶或資料流程。使用輸出前先修正流程。
