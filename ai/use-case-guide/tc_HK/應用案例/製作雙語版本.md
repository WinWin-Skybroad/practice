# 製作雙語版本

## 1. 這個應用案例是甚麼

如您希望人工智能協助：**製作英文及繁體中文雙語版本**，請使用本頁。

- 常見使用者：**教會、非牟利機構、中小企業**。
- 批准級別：**謹慎使用**。
- 需要人工審核：**是 — 需要雙語審核者**。
- 使用人工智能輸出協助您草擬或檢查工作。不要把它視為最終決定。

---

## 2. 這可能造成甚麼代價

語氣強弱、限制、金額、日期、責任或語氣的細微變化，都可能令兩個語言版本傳達不同義務。如每個版本只獨立閱讀，這種不一致可能傳達給捐贈者、職員、客戶、成員或公眾，並需要更正、解釋，或決定以哪個版本為準。

---

## 3. 如何審核這個輸出

批准人工智能輸出前，請使用以下檢查。不要只因輸出讀起來流暢便批准。

---

### 3.1 審核設定

1. 以英文為來源，並排開啟兩個版本。
2. 先閱讀英文第 1 句，再閱讀繁體中文第 1 句。確認兩者意思及條件相同後，才移至第 2 句。
3. 特別留意：條件用語、限制、承諾、法律參考，以及任何產生義務或限制的措辭。
4. 如繁體中文讀起來流暢，但與英文的範圍、強度或條件不同，應標示該句。

---

### 3.2 批准前 — 一項檢查

> **合資格雙語審核者是否已把繁體中文輸出與英文來源並排逐句閱讀 — 不只是檢查中文是否流暢，而是確認兩個版本的意思、條件及承諾完全一致？**

---

### 3.3 針對風險的審核檢查

這些檢查把 [[人工審核風險庫]] 中的最低審核責任調整至本任務。

- **[[人工審核風險庫#4.5 知識差距|知識差距]]：** 確認審核者在兩種語言及文件主題方面具備足夠能力，可識別意思、術語、權限及文化錯誤。如專業內容超出雙語審核者的專長，應另行取得專業審核。
- **[[人工審核風險庫#4.11 流暢度錯覺|流暢度錯覺]]：** 獨立把雙語輸出與來源比較，檢查意思、事實、限制條件、權限、術語、格式及遺漏。不要把自然或潤飾良好的措辭視為翻譯完整或正確的證據。
- **[[人工審核風險庫#4.20 跨文化語域差距|跨文化語域差距]]：** 檢查措辭是否為實際受眾及情境保留預期語氣、正式程度、禮貌、社交含義、暗示及權限程度。使用合適的雙語、文化或了解受眾的審核者；如涉及專業意思，另行尋求專業審核。

---

### 3.4 審核者決策

完成上述針對本任務的審核檢查後，使用 [[審核者決策卡]] 選擇一項結果：

- **原樣批准**
- **更正後批准**
- **停止並升級處理**

如審核者欠缺本任務所需的角色、證據、權限、能力、來源存取權、語境或已批准流程，不要批准輸出。

---

### 3.5 本任務的審核方法

以下審核指示已針對本任務調整。它們把 [[人工審核模式]] 中的可重用方法應用於這裏涉及的實際來源、決定、人士及後果。

- **雙語 / 本地化審核：** 把每個語言版本與已批准來源及術語比較，檢查意思、遺漏、新增內容、字體、名稱、格式及香港用法。
  - 留意：翻譯流暢但改變意思、混用字體、改變權限、遺失格式或使用不一致術語。
  - 時機：發布或對外使用前。
  - 審核者：熟悉目標受眾及香港用法的合資格雙語審核者。

- **以人工判斷為本的審核：** 檢查兩種語言的語氣、正式程度、禮貌、社交含義、暗示及權限程度是否適合實際受眾及關係。
  - 留意：字面準確但文化或社交訊號不恰當，或措辭比原意更冷淡、更強硬、更官方或較不尊重。
  - 時間：發布或發送前。
  - 審核者：雙語、文化或了解受眾的審核者。

- **合資格法律 / 合規審核：** 如涉及專業意思或專業實務，除雙語審核者外，亦應取得合資格專業人士審核。
  - 留意：技術上流暢，但改變法律、牧養、醫療、財務、技術或其他專業意思的措辭。
  - 時間：專業內容被依賴或發布前。
  - 審核者：相關合資格專業人士及雙語審核者。

---

## 4. 何時應升級處理而不是批准

- 如輸出影響法律、人力資源、財務、安全保障、醫療、法規、對外或高影響決定，而審核者沒有確認安全使用所需的權限、能力、語境、來源存取權或已批准流程，應在使用前升級處理。
- 如審核者沒有資格或權限確認專業意思，法律、醫療、財務、技術或公開翻譯應升級處理。

---

## 5. 提示前

使用人工智能處理本任務前，先檢查以下基本事項：
- 目的清晰。
- 輸入不包含不應輸入工具的個人或機密資料。
- 有負責人可在使用人工智能輸出前檢查它。
- 任務沒有要求人工智能作出決定、提供專業意見或充當最終權威。

- 確認本任務符合批准級別：**謹慎使用**。
- 確認計劃中的審核者能完成所需人工審核：**是 — 需要雙語審核者**。

---

## 6. 人工智能盲點重點

**風險重點：** 跨文化語域差距

**提示詞重點：** 提示前，向人工智能提供來源文本、目標受眾、地區語言、語域、術語偏好、渠道，以及是否涉及法律、官方或面向公眾的措辭。要求人工智能標示需要雙語人工確認的術語、慣用語、正式表達及受眾敏感措辭。

**人工審核重點：** 並排比較意思。檢查語域、受眾合適度、香港術語、名稱、日期、官方用語，以及流暢措辭有否改變預期意思。

**較深入的盲點審核：** 如雙語輸出依賴本地術語、正式程度、文化含義、受眾期望或機構語域，請依循 [[如何使用本指南#6.1 Win.Win 人工智能盲點指南|Win.Win 人工智能盲點指南路徑]]。

**不要只依賴：** 自然流暢度。雙語版本可以讀起來很好，卻改變語氣、義務、正式程度或機構含義。

## 8. 主要風險

- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：[[人工審核風險庫#4.11 流暢度錯覺|流暢度錯覺]]（高）** — 人工智能生成的繁體中文可能清晰、自然且專業，使審核者假設內容準確並可使用。除非使用任務所需的雙語、本地化、專業及其他審核模式獨立檢查輸出，否則意思漂移、條件弱化、承諾加強、字體錯誤及語域不匹配仍可能被隱藏。文字流暢並不是文字準確的證據。

---

## 9. 其他需注意風險

- **[[風險分類#3.11 人工智能盲點 / 語境風險|人工智能盲點 / 語境風險]]：[[人工審核風險庫#4.20 跨文化語域差距|跨文化語域差距]]（中）** — 人工智能可能產生字面意思準確的雙語或跨文化措辭，但其語氣、語言語域、正式程度、禮貌、暗示、權限程度或社交訊號並不適合實際受眾及情境。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：語域不匹配（中）** — 正式英文可能被翻譯成不恰當的隨意中文，反之亦然。在香港教會及非牟利機構通訊中，正式稱謂承載關係含義，因此語域錯誤尤其重要。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：文化框架喪失（中）** — 英文慣用語、比喻或文化參考需要在中文中作文化調整，而不是逐字翻譯。人工智能傾向逐字處理。中文輸出可能在語言上正確，但在文化上令人困惑或不恰當。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：繁簡字混用（中）** — 人工智能可能把簡體中文字插入繁體中文文件。在雙語文件中，這尤其難以察覺，因為審核者可能專注於中英文對齊，而不是字元層面的準確性。
- **[[風險分類#3.8 雙語 / 本地化 / 香港語境|雙語 / 本地化 / 香港語境]]：[[人工審核風險庫#4.5 知識差距|知識差距]]（高）** — 審核者可能細心而且具雙語能力，但仍未必有資格確認法律、法規、財務、人力資源、牧養 / 神學或專業術語是否翻譯正確。專業術語需要具備能力的審核者，而不只是語言流利的讀者。

## 10. 要加入的提示詞強化

先從 Win.Win 人工智能必備的基礎提示詞模式開始。以下附加項已針對本任務調整。

只使用與實際情況相符的列。不要只因某項控制出現在 [[提示詞強化模式]] 便加入無關控制。對於主要須透過人工審核、已批准工具、專業檢查、其他緩解措施或升級處理的風險，不要建立提示詞附加項。

把來源材料、筆記、政策摘錄、數字及文件放在基礎提示詞最後的 **內容** 部分。
