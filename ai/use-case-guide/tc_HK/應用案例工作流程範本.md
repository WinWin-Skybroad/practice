# 應用案例工作流程範本

## 1. 如何使用本範本

應用案例頁面本身還不是工作流程。它會告訴您要檢查甚麼，但機構仍需決定由誰開始任務、人工智能步驟前要做甚麼、批准後要做甚麼，以及最終輸出要放在哪裏。

使用本範本，把一個應用案例頁面轉化為可重複使用的工作流程。

---

## 2. 工作流程步驟

| 步驟 | 問題 | 本地答案 |
|---|---|---|
| 1. 觸發條件 | 這項人工智能任務何時開始？ | |
| 2. 來源資料包 | 輸入提示詞前必須收集甚麼？ | |
| 3. 人工智能草擬 | 誰在哪裏執行提示詞？ | |
| 4. 人工審核 | 誰檢查輸出？對照甚麼檢查？ | |
| 5. 決定 | 誰可以原樣批准、更正後批准，或停止並升級處理？ | |
| 6. 歸檔 / 使用 | 已批准輸出要放在哪裏？誰可以發送或使用？ | |

---

## 3. 工作流程控制

每個工作流程都要界定：

- 負責人
- 後備負責人
- 審核者
- 升級處理聯絡人
- 來源位置
- 輸出位置
- 記錄位置
- 停止規則

---

## 4. 最低工作流程規則

不要只依賴應用案例頁面。對每項重複進行的人工智能任務，都要為工作流程命名，並指定負責人。

沒有負責人的任務，會變成人人都有責任，結果卻沒有人真正負責。
